  METHOD GET_PKOND.

    CLEAR RV_PKOND.

*   기준일자 >= DBERVON(계산 기간 시작) 것 중 가장 빠른 최신일의 PKOND (이자율)을 추출                   &nb
    SELECT RFHA, DBERVON, PKOND INTO TABLE @DATA(LT_PKOND)
      FROM VTBFHAPO
     WHERE BUKRS    = @IV_BUKRS
       AND RFHA     = @IV_RFHA
       AND SSPRGRD  = '0'
       AND SFHAZBA  = '1200'
       AND DBERVON <= @IV_DATE.    "기준일

    CHECK SY-SUBRC = 0.

    SORT LT_PKOND BY DBERVON DESCENDING.

    READ TABLE LT_PKOND INTO DATA(LS_PKOND) INDEX 1.
    RV_PKOND = LS_PKOND-PKOND.

  ENDMETHOD.
