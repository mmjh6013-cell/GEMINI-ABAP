 EVENT
 This Event is reached prior to the update posting module for FI
 (POST_DOCUMENT) and also following callup of the interface part.
 INTERFACE
 All current data, all document data required for the update, and
 various control parameters are transferred to the additional component.
 The indicator I_XVBUP is used for information purposes only - that the
 SAP standard system carries out an update posting asynchronously.
 It follows that no database activities involving the writing of data
 may be carried out in the additional component.
 The update posting (including tables specific to Add-ons) are carried
 out by the COMMIT WORK of the standard process. If your function module
 is not accessed via RFC, you should always initiate asynchronous update
 posting using the ABAP statement:
 IN UPDATE TASK.
