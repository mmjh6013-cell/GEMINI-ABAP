*
* Purpose: Change of alternative unit of measure (AU0M) with or without
* change of total quantity.
* E.g. Change from 10 x C06 (carton of 6 eaches) to
* 10 x C05 (carton of 5 eaches)
* E.g. Change from 1 x C06 (AUoM) to 4 x PC (Base unit of measure)
* For difference postings we need an exception code and the business
* context and execution step. If there is no exception code given in
* the interface, we trigger internal exception code SC01 and use the
* assigned exception code.
* You can assign it in customizing: Extended Warehouse Management ->
* Cross-Process Settings -> Exception Handling -> Assign Internal
* Exception Codes to Exception Code
* The function module creates change documents (confirmed warehouse tasks)
* - One for the change of the AUoM
* - One for the posting of the difference
* The function module checks authorization for warehouse task creation
* - Authority-object /SCWM/TOCR

* Callers:
* - Monitor method
* - RF transaction
* - Customer development

* Input parameters:
* - GUID_STOCK of a quant
* - GUID_PARENT of a quant
* - ALTME new alternative unit of measure
* - QUANTITY total quantity in new AUoM
* - Exception code, incl. BusCon and Exec.Step
