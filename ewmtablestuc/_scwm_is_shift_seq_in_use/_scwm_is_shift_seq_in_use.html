Code listing for function /SCWM/IS_SHIFT_SEQ_IN_USE

Description : Is a shift sequence in use in EWM
FUNCTION /scwm/is_shift_seq_in_use.
*"----------------------------------------------------------------------
*"*"Local Interface:
*" IMPORTING
*" REFERENCE(IV_SHIFT_SEQ) TYPE /SCWM/DE_SHIFT_SEQ
*" REFERENCE(IV_SHIFT_SEQ_DAY_NUMBER) TYPE
*" /SCWM/DE_SHIFT_SEQ_DNUMBER_FR
*" EXPORTING
*" REFERENCE(EV_RESULT) TYPE C
*"----------------------------------------------------------------------
* Global data declarations

  DATA:           lt_shift_leads  TYPE  /scwm/tt_shift_lead.

  FIELD-SYMBOLS: <fs_shift_lead> TYPE /scwm/s_shift_lead.



  CALL FUNCTION '/SCWM/GET_SHIFT_LEAD'
    IMPORTING
      et_shift_leads = lt_shift_leads.

  CLEAR ev_result.

  LOOP AT lt_shift_leads ASSIGNING <fs_shift_lead> WHERE shift_seq = iv_shift_seq
                                                   AND doffset = iv_shift_seq_day_number.
    ev_result = 'X'.
    EXIT.
  ENDLOOP.


ENDFUNCTION.
