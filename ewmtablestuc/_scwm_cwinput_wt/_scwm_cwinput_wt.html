Description : CW Entry Is Required When Confirming WT
FUNCTION /scwm/cwinput_wt.
*"----------------------------------------------------------------------
*"*"Lokale Schnittstelle:
*" CHANGING
*" REFERENCE(CS_LTAP) TYPE /SCWM/LTAP OPTIONAL
*" REFERENCE(CT_LTAP) TYPE /SCWM/TT_LTAP_VB OPTIONAL
*" EXCEPTIONS
*" INTERFACE_ERROR
*"----------------------------------------------------------------------
* Global data declarations

  DATA: lv_error TYPE xfeld.

  FIELD-SYMBOLS: <fs_ltap>  TYPE /scwm/ltap.

  IF cs_ltap IS INITIAL AND
     ct_ltap IS INITIAL.
    RAISE interface_error.
  ENDIF.

  IF NOT cs_ltap IS INITIAL.
    PERFORM required_fields_filled USING cs_ltap CHANGING lv_error.
    IF lv_error EQ abap_false.
      PERFORM check_cwinput_wt CHANGING cs_ltap.
    ELSE.
      MESSAGE e009(/scwm/cwquan) WITH cs_ltap-tanum cs_ltap-tapos.
    ENDIF.
  ENDIF.

  IF NOT ct_ltap IS INITIAL.
    LOOP AT ct_ltap ASSIGNING <fs_ltap>.
      CLEAR lv_error.
      PERFORM required_fields_filled USING <fs_ltap> CHANGING lv_error.
      IF lv_error EQ abap_false.
        PERFORM check_cwinput_wt CHANGING <fs_ltap>.
      ELSE.
        MESSAGE e009(/scwm/cwquan) WITH <fs_ltap>-tanum <fs_ltap>-tapos.
      ENDIF.
    ENDLOOP.
  ENDIF.

ENDFUNCTION.
