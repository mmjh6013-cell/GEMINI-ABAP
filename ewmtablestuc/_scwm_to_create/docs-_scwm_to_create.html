Code listing for : Documentation - /SCWM/TO_CREATE

Description :

SHORT TEXT
 Generate Warehouse Task with Multiple Items

FUNCTIONALITY
 With this function module product warehouse tasks can be created. The
 creation process can be influenced using various parameters. Detailed
 information can be found in the documentation for the individual
 parameters.
 At the beginning the parameters supplied checked for plausibility. Then
 the actual warehouse task creation takes place.
EXAMPLE
 
HINTS
 In general this function module should be called once with many items
 instead of many times with single items.
 However, if you need to call this function module multiple times in a
 program flow to operate on the same data, you have ensure proper COMMIT,
 enqueue and cleanup handling.
 If you want to create warehouse tasks with reference to warehouse
 requests, you should use the function module
  <DS:FU./SCWM/TO_CREATE_WHR>/SCWM/TO_CREATE_WHR</> instead. If you want
 to create handling unit warehouse tasks, you should use the function
 module
  <DS:FU./SCWM/TO_CREATE_MOVE_HU>/SCWM/TO_CREATE_MOVE_HU</> instead.
FURTHER_SOURCES_OF_INF
 For more information see the Warehousing area under SAP Supply Chain
 Management, which is part of the SAP Business Suite Applications, on the
 SAP Service Marketplace. There you can find information on Extended
 Warehouse Management in SAP SCM containing further implementation hints
 in an area called Technical Information.
