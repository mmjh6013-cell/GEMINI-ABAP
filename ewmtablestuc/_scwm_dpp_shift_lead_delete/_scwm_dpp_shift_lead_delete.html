Code listing for function /SCWM/DPP_SHIFT_LEAD_DELETE

Description : Delete entries for BP upon BP archiving
FUNCTION /scwm/dpp_shift_lead_delete.
*"----------------------------------------------------------------------
*"*"Local Interface:
*" IMPORTING
*" REFERENCE(IT_PARTNER) TYPE BUP_PARTNER_GUID_T
*"----------------------------------------------------------------------

* Global data declarations

  "/SCWM/TSHIFTLEAD is seen as dependent table on /SCWM/EWRKL
  "with inserts in /SCWM/EWRKL with a shift lead the retention
  "period of the shift lead will be enhanced (BUTSORT)
  "thus, shift leads with recent executed workloads will not reach
  "end of purpose (EoP). Only if no executed workloads are written
  "and after the retention period corresponding shift lead BPs can
  "be deleted. At this point in time, this coding will also remove
  "corresponding entries in /SCWM/THSIFTLEAD because they are
  "outdated.

  DATA: lt_shiftlead TYPE /scwm/tt_shift_lead.

  DATA(lt_partner) = it_partner.
  DELETE lt_partner WHERE partner IS INITIAL.
  IF lt_partner IS INITIAL.
    RETURN.
  ENDIF.

  SELECT * FROM /scwm/tshiftlead INTO TABLE lt_shiftlead
    FOR ALL ENTRIES IN lt_partner
    WHERE shift_lead = lt_partner-partner.

  IF lt_shiftlead IS NOT INITIAL.
    CALL FUNCTION '/SCWM/SHIFT_LEAD_POST'
      EXPORTING
        it_shift_lead_del = lt_shiftlead.
  ENDIF.
ENDFUNCTION.
