Code listing for function /SCWM/REMOVE_SHIFTLEAD_BY_SHSE

Description : Remove Shift Leads for a given Shift Sequence
FUNCTION /scwm/remove_shiftlead_by_shse.
*"----------------------------------------------------------------------
*"*"Local Interface:
*" IMPORTING
*" REFERENCE(IV_SHIFT_SEQ) TYPE /SCWM/DE_SHIFT_SEQ
*"----------------------------------------------------------------------
* Global data declarations

  DATA: lt_records_to_delete TYPE /scwm/tt_shift_lead.

  IF iv_shift_seq IS INITIAL.
    RETURN.
  ENDIF.

  SELECT * FROM /scwm/tshiftlead INTO TABLE lt_records_to_delete WHERE shift_seq = iv_shift_seq.

  IF lt_records_to_delete IS INITIAL.
    RETURN.
  ENDIF.

  DELETE /scwm/tshiftlead FROM TABLE @lt_records_to_delete.

ENDFUNCTION.
