*----------------------------------------------------------------------*
* PBO-Module for MRP area input field
* Usage:
* - Mark all screen fields which depend on MRP area flag of client
*   customizing with SCREEN-GROUP4 = 'DBR'
* - use this module in PBO
*----------------------------------------------------------------------*


MODULE SHOW_MRP_AREA OUTPUT.                                    "#EC *
*--> Ermittelt bei Erstaufruf die Belegung von Werk und DB
*--> nuetzlich fuer Alt/Neu-Vergleich in Mrp_Area_Plant_Check
*--> Hat keine Nebenwirkungen
  PERFORM MRP_AREA_INITIALIZE_0100.
*--> check MRP area function active in client
* PERFORM READ_T000MD.
*  IF T000MD-DISFG IS INITIAL.
**--> only display plant
*    LOOP AT SCREEN.
*      CHECK SCREEN-GROUP4 = 'DBR'.
*      SCREEN-ACTIVE    = 0.
*      SCREEN-INVISIBLE = 1.
*      MODIFY SCREEN.
*    ENDLOOP.
*  ELSE.
*--> display plant and mrp area
    LOOP AT SCREEN.
      CHECK SCREEN-GROUP4 = 'WRK'.
      SCREEN-ACTIVE    = 0.
      SCREEN-INVISIBLE = 1.
      MODIFY SCREEN.
    ENDLOOP.
* ENDIF.
ENDMODULE.
