FORM CHECK_SERNR_PA USING    SERNR
                             WERKS
                    CHANGING PALTR.

*--> Seriennummer lesen
  PERFORM READ_SNUM USING SERNR.
  IF SY-SUBRC NE 0.
    MESSAGE E358 WITH SERNR.
  ENDIF.
*--> Seriennummer prüfen
  IF NOT SNUM-XLOEK IS INITIAL.
    MESSAGE E367 WITH SERNR.          "SERNR ist zum Löschen vorgemerkt
  ENDIF.
  IF SNUM-SNSTA = SNSTA_INACTIVE.
    MESSAGE E341 WITH SERNR.          "SERNR ist nicht aktiv
  ENDIF.
  IF NOT SNUM-WERKS IS INITIAL AND WERKS NE SNUM-WERKS.
    MESSAGE E342 WITH SERNR SNUM-WERKS. "SERNR ist nur in Werk & gültig
  ENDIF.
*--> Bruttoauflösungstermin uebernehmen
  MOVE SNUM-BRUTR TO PALTR.
ENDFORM.                    " CHECK_SERNR_PA
