* Texte zu allen Feswerten einer Domaene aus dem DDIC lesen           *

FORM DOMVAL_GET_ALL TABLES DD07V_TAB STRUCTURE DD07V
                    USING  FLG01 TYPE C
                           LANGU LIKE SY-LANGU
                           DNAME LIKE DD07L-DOMNAME.
*--> Lesen Domaene
  CALL FUNCTION 'DD_DOMVALUES_GET'
       EXPORTING  DOMNAME   = DNAME
                  TEXT      = FLG01
                  LANGU     = LANGU
       TABLES     DD07V_TAB = DD07V_TAB
       EXCEPTIONS WRONG_TEXTFLAG = 01.
*--> Nicht erfolgreich
  IF SY-SUBRC NE 0.
    CLEAR DD07V_TAB.
    REFRESH DD07V_TAB.
  ENDIF.

ENDFORM.
