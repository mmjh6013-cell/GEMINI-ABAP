Program listing for: MM61XF80_CHECK_BANF_FIX01 
*----------------------------------------------------------------------*
* Fixierungskennzeichen Banf ueberpruefen
*----------------------------------------------------------------------*


FORM CHECK_BANF_FIX01.

  DATA: FIX_FLAG(1) TYPE C.

*--> Banf-Fixierung pruefen
  CHECK MDPSX-FIX01 EQ XFLAG.
  CHECK MDPSX-VSTAT NE VSTATV.
  CLEAR FIX_FLAG.
*--> Banf nachlesen
  PERFORM READ_EBAN USING MDPSX-DELNR MDPSX-DELPS+1(5).
  IF SY-SUBRC NE 0.
    IF MDPSX-VSTAT EQ VSTATN.
      CLEAR MDPSX-FIX01.
    ENDIF.
    EXIT.
  ENDIF.
  MOVE EBAN-FIXKZ TO FIX_FLAG.
*--> Kontierung ueberpruefen
  IF NOT EBAN-KNTTP IS INITIAL.
    IF CM61M-WERTU NE SPACE.
      MOVE XFLAG TO FIX_FLAG.
    ENDIF.
  ENDIF.
*--> Direktbanf ist nicht verfügbar und fixiert
  IF NOT EBAN-ARSNR IS INITIAL
  AND    EBAN-VORAB IS INITIAL.
    MOVE XFLAG TO FIX_FLAG.
  ENDIF.
*--> Erstellungskennzeichen
  IF  EBAN-ESTKZ NE CHARB
  AND EBAN-ESTKZ NE CHARU.
    MOVE XFLAG TO FIX_FLAG.
  ENDIF.
*--> Bearbeitungsstatus
  IF  EBAN-STATU EQ CHARB
  AND EBAN-BSMNG GT 0.
    MOVE XFLAG TO FIX_FLAG.
  ENDIF.
  IF EBAN-STATU EQ CHARA
  OR EBAN-STATU EQ CHARL.
    MOVE XFLAG TO FIX_FLAG.
  ENDIF.
*--> Status Bestellanforderung ueberpruefen
  IF EBAN-FRGKZ NE SPACE.
    PERFORM READ_T161S USING EBAN-FRGKZ EBAN-BANFN.
    IF T161S-FIXBP EQ XFLAG.
      MOVE XFLAG TO MDPSX-FIX01.
      MOVE XFLAG TO MDPSX-FIX02.
    ENDIF.
  ENDIF.
*--> physische Fixierung pruefen
  IF FIX_FLAG IS INITIAL.
    CLEAR MDPSX-FIX01.
  ENDIF.

ENDFORM.                    " CHECK_BANF_FIX01
