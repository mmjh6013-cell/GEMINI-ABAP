Program listing for: MM61XF57_SET_MDEZX_EXTRA 
*----------------------------------------------------------------------*
* Extrakt fuer MDEZX neu setzen
*----------------------------------------------------------------------*


FORM SET_MDEZX_EXTRA.
*--> Clear Extrakt
  MOVE SPACE TO MDEZX-EXTRA.
*--> Daten neu setzen
  CASE MDPS-DELKZ.
*--> Planauftrag
    WHEN PLAUF.
      MOVE MDPS-DELNR  TO MDEZX-EXTRA.
      MOVE '/'         TO MDEZX-EXTRA+10.
      PERFORM READ_T457P USING MDPS-BAART.
      MOVE T457P-EXTPA TO MDEZX-EXTRA+11(4).
      IF MDPS-FIX01 NE SPACE.
        MOVE '*' TO MDEZX-EXTRA+15.
      ENDIF.
      CONDENSE MDEZX-EXTRA.
*--> Simulationsauftrag
    WHEN SAAUF.
      MOVE MDPS-DELNR TO MDEZX-EXTRA.
      MOVE '/'         TO MDEZX-EXTRA+10.
      PERFORM READ_T457P USING MDPS-BAART.
      MOVE T457P-EXTPA TO MDEZX-EXTRA+11(4).
      IF MDPS-FIX01 NE SPACE.
        MOVE '*' TO MDEZX-EXTRA+15.
      ENDIF.
      CONDENSE MDEZX-EXTRA.
*--> Fertigungsauftrag
    WHEN FEAUF.
      MOVE MDPS-DEL12 TO MDEZX-EXTRA.
      MOVE '/'        TO MDEZX-EXTRA+12.
      MOVE MDPS-BAART TO MDEZX-EXTRA+13.
*--> Prozeﬂauftrag
    WHEN BAREZ.
      MOVE MDPS-DEL12 TO MDEZX-EXTRA.
      MOVE '/'        TO MDEZX-EXTRA+12.
      MOVE MDPS-BAART TO MDEZX-EXTRA+13.
*--> Bestellanforderung
    WHEN BSANF.
      MOVE MDPS-DELNR    TO MDEZX-EXTRA.
       MOVE '/'          TO MDEZX-EXTRA+10.
       MOVE MDPS-DELPS+1 TO MDEZX-EXTRA+11.
       IF MDPS-FIX01 NE SPACE.
         MOVE '*' TO MDEZX-EXTRA+16.
       ENDIF.
*--> Lieferplaneinteilung
    WHEN LPEIN.
      MOVE MDPS-DELNR   TO MDEZX-EXTRA.
      MOVE '/'          TO MDEZX-EXTRA+10.
      MOVE MDPS-DELPS+1 TO MDEZX-EXTRA+11.
  ENDCASE.
*--> Ausnahmemeldung
  PERFORM READ_T458A_01 USING MDPS-AUSSL.
  MOVE T458A-AUSKT TO MDEZX-EXTRA+23.
ENDFORM.
