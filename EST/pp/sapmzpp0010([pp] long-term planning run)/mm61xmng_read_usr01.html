FORM READ_USR01 USING UNAME TYPE SYUNAME
                      DCPFM TYPE XUDCPFM.
*TABLES: USR01.
  IF UNAME = USR01-BNAME.
    MOVE USR01-DCPFM TO DCPFM.
    EXIT.
  ENDIF.
  SELECT SINGLE * FROM USR01 WHERE BNAME = SY-UNAME.
  MOVE USR01-DCPFM TO DCPFM.
ENDFORM.
