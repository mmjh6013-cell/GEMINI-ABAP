Program listing for: MM61XF20_READ_MARC 
*----------------------------------------------------------------------*
* Lesen Material direkt aus Datenbank                                  *
*----------------------------------------------------------------------*


FORM READ_MARC USING MATNR LIKE MARC-MATNR
                     WERKS LIKE MARC-WERKS.
*--> Prüfen Tabelleninhalt
  IF  MATNR EQ MARC-MATNR
  AND WERKS EQ MARC-WERKS.
    SY-SUBRC = 0. EXIT.
  ENDIF.
*--> Kommunikationsworkaera fuellen
  CLEAR MTCOM.
  MOVE 'MARCE'     TO MTCOM-KENNG.
  MOVE MATNR       TO MTCOM-MATNR.
  MOVE WERKS       TO MTCOM-WERKS.
*--> Materialstamm fuer Disposition lesen
* MMACCESS_2015W1_ADJUSTED
  CALL FUNCTION   'MATERIAL_READ'
       EXPORTING  SCHLUESSEL = MTCOM
       IMPORTING  MATDATEN   = MARC
       EXCEPTIONS MATERIAL_NOT_FOUND = 04
                  PLANT_NOT_FOUND    = 08
                  ACCOUNT_NOT_FOUND  = 12.
ENDFORM.
