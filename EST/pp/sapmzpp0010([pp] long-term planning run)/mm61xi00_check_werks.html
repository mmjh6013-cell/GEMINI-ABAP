Program listing for: MM61XI00_CHECK_WERKS 
*----------------------------------------------------------------------*
* Pruefen Werksdaten                                                   *
*----------------------------------------------------------------------*


MODULE CHECK_WERKS INPUT.
*--> Werkseingabe statt Planungsumfang
  IF  NOT RM61X-PUWNR IS INITIAL
  AND NOT RM61X-WERKS IS INITIAL.
*   Planung mit Planungsumfang
    CLEAR RM61X-WERKS.
    CLEAR T001W-NAME1.
    MESSAGE W314(61).
  ENDIF.
  CHECK RM61X-PUWNR IS INITIAL.
*--> Dispobereiche aktiv -> Planungsumfang verwenden  "HW 211851
  PERFORM READ_T000MD.                                "
  IF NOT T000MD-DISFG IS INITIAL                      "
  AND (    T450N-MDATY EQ MRPPL                       "
        OR T450N-MDATY EQ MPSPL                       "
        OR T450N-MDATY EQ LFRPL ).                    "
    MESSAGE W335(MD).                                 "
  ENDIF.                                              "HW 211851
*--> Werkstabelle prüfen
  PERFORM READ_T001W USING RM61X-WERKS.
  IF SY-SUBRC NE 0.
     MESSAGE E272 WITH RM61X-WERKS.
  ENDIF.
**--> Sammelplanung: Bedarfsplanung im gewählten Werk aktiv ?
*  IF  T450N-MDATY NE MRPEP
*  AND T450N-MDATY NE MPSEP
*  AND T450N-MDATY NE LFREP
*  AND T001W-BEDPL NE XFLAG.
*    MESSAGE E139 WITH RM61X-WERKS.
*  ENDIF.
*--> Authority-Check
    IF T450N-MDOBJ EQ MDOBJB
    OR T450N-MDOBJ EQ MDOBJM.
      PERFORM CHECK_AUTHORITY_D_02
              USING T450N-MDAKT T450N-MDATY RM61X-WERKS.
    ENDIF.
*--> Authority-Check
    IF T450N-MDOBJ EQ MDOBJL.
      PERFORM CHECK_AUTHORITY_L_01 USING T450N-MDATY
                                         RM61X-PLSCN
                                         RM61X-WERKS.
    ENDIF.
*--> Fabrikkalender setzen fuer F4 auf Datum
  PERFORM CALENDER_FOR_F4_DATE USING T001W-FABKL.
ENDMODULE.
