Program listing for: MM61XF59_DELETE_MDPSS_01 
*----------------------------------------------------------------------*
* Bestellvorschlag loeschen (FCODE: BVDL)
*----------------------------------------------------------------------*


FORM delete_mdpss_01.
*--> Planauftraege mit WE-menge duerfen nicht geloescht werden
  IF  mdpss-delkz EQ plauf
  AND mdpss-mdmng GT 0.
* Teilrückgemeldeter Planauftrag &1 darf nicht gelöscht werden.
    MESSAGE e243 WITH mdpss-delnr.
  ENDIF.
*--> Prüfen Bei Neuanlage Auftrag nix zu tun
  CHECK NOT mdpss-xline IS INITIAL.                      "HW 153219
*--> Zeile loeschen
  DELETE mdpsx INDEX mdpss-xline.
*--> Reset aktuelle Aufloesung
  IF mdpss-aktal EQ xflag OR cm61x-inmem = gc_true.
    CALL FUNCTION 'MD_FREE_MDPMI_MEMORY'
         EXPORTING ersnum = mdpss-rsnum.
  ENDIF.
*--> Reset Quotierung
  PERFORM reset_quotierung_mdpss.
*--> Verarbeitungskennzeichen ueberpruefen
*--> Rel. 2.2: Wenn ein Planauftrag neu hinzugefuegt wurde, dann
*--> terminiert wurde (im Dialog - Kapa-Planung), dann geloescht
*--> wird, muessen hier die zugeh. Kapa-Bedarfe geloescht werden.
*--> Fuer geaend./orig. Plaufs laeuft Kapa-Loeschen ueber MDPSO
  IF mdpss-vstat EQ vstath.
    IF mdpss-delkz EQ plauf
    OR mdpss-delkz EQ saauf.
      IF NOT mdpss-trmer IS INITIAL         "wurde terminiert ?
      OR NOT mdpss-rater IS INITIAL
      OR NOT mdpss-groer IS INITIAL.
        PERFORM mps_capacity_del_plaf USING mdpss-delnr.
      ENDIF.
    ENDIF.
    mdpss-vstat = vstatl.                                  "new SA 45A
    PERFORM update_mrp_data_in_memory
            USING mdkp mdpss cm61b mdpsx[] mdpso[].
    EXIT.
  ENDIF.
*--> Setzen Löschkennzeichen
  MOVE vstatl TO mdpss-vstat.
*--> Reset Umterminierungskennzeichen
  CLEAR mdpss-ukz01.
  CLEAR mdpss-umdat.
*--> Reset Ausnahmeschluessel
  CLEAR mdpss-aussl.
  CLEAR mdpss-oldsl.
*--> Reset Fixierungskennzeichen
  CLEAR mdpss-fix01.
  CLEAR mdpss-fix02.
*--> Reset ATP-Menge
  CLEAR mdpss-mng04.
*--> Reset Aufloesungsdaten
  CLEAR mdpss-aktal.
  CLEAR mdpss-paltr.
  CLEAR mdpss-revlv.
  CLEAR mdpss-aennr.
  CLEAR mdpss-frthw.
  IF mdpss-verid IS INITIAL.
    CLEAR mdpss-stlan.
    CLEAR mdpss-stalt.
    CLEAR mdpss-bom_versn.
  ENDIF.
*--> Tabelleneintrag in MDPSO uebernehmen
  PERFORM insert_sorted_mdpso USING mdpss.
*--> Daten fuer Planung im Hauptspeicher aktualisieren
  PERFORM update_mrp_data_in_memory
          USING mdkp mdpss cm61b mdpsx[] mdpso[].
ENDFORM.
