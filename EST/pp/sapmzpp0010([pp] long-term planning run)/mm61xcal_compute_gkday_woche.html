Program listing for: MM61XCAL_COMPUTE_GKDAY_WOCHE 
*----------------------------------------------------------------------*
* Periodenende/Periodenanfang fuer die Wochen bestimmen
*----------------------------------------------------------------------*


FORM COMPUTE_GKDAY_WOCHE USING GKDAY TYPE D
                               PERAZ TYPE P.
*--> Hilfsfelder
  DATA: ANZTG TYPE I.
*--> Ausgabebereich clearen
  CLEAR MDCAL.
  MOVE GKDAY TO MDCAL-GKDAY.
*--> Wochentag bestimmen
  PERFORM COMPUTE_GKDAY_WOTAG USING MDCAL-GKDAY.
*--> Wochenanfang ermitteln
  MDCAL-PRANF = MDCAL-GKDAY - MDCAL-WOTAG + 1.
*--> aktuelle Woche bestimmen
  PERFORM CONVERT_GKDAY_FWEEK USING MDCAL-PRANF.
  MOVE MDCAL-FWEEK TO MDCAL-PRPER.
*--> Wochenende ermitteln
  MDCAL-PREND = MDCAL-PRANF + 6.
*--> Wochenende verschieben
  IF PERAZ GT 1.
    ANZTG = ( PERAZ - 1 ) * 7.
    MDCAL-PREND = MDCAL-PREND + ANZTG.
  ENDIF.
ENDFORM.
