Program listing for: MM61XPAG_BLAETTERN 
*---------------------------------------------------------------------*
*       FORM BLAETTERN                                                *
*---------------------------------------------------------------------*
* Blaettern ueber Funktionsbaustein                                    *
*---------------------------------------------------------------------*
*  -->  XLINE   Aufsetzpunkt (erste Zeile auf Screen)           (I/O) *
*  -->  VLINE   Erste  anzeigbare Zeile                         (I)   *
*  -->  BLINE   Letzte anzeigbare Zeile                         (I)   *
*  -->  MLINE   Anzahl Zeilen in Tabelle                        (I)   *
*  -->  LOOPS   Anzahl Zeilen auf Screen                        (I)   *
*  -->  XCODE   Funktionscode                                   (I)   *
*               sinnvolle Werte: 'P-- ','P-  ','P+  ','P++'.
*---------------------------------------------------------------------*


FORM BLAETTERN USING XLINE VLINE BLINE MLINE LOOPS XCODE.

  DATA: L_XLINE LIKE SY-TABIX.

  CHECK BLINE > 0.
  IF XCODE = 'P+'
  OR XCODE = 'P++'.
    L_XLINE = XLINE + LOOPS.
    CHECK L_XLINE LE BLINE.
  ENDIF.
  CALL FUNCTION 'SCROLLING_IN_TABLE'
       EXPORTING
            ENTRY_ACT      = XLINE
            ENTRY_FROM     = VLINE
            ENTRY_TO       = BLINE
            LOOPS          = LOOPS
            OK_CODE        = XCODE
            LAST_PAGE_FULL = 'X'
            OVERLAPPING    = 'X'
       IMPORTING
            ENTRY_NEW      = XLINE
       EXCEPTIONS
*            NO_ENTRY_TO    = 01. "Syntaxcheck
            NO_ENTRY_TO    = 0.

ENDFORM.
