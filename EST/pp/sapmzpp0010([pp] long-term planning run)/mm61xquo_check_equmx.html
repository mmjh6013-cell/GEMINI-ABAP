Program listing for: MM61XQUO_CHECK_EQUMX 
*&---------------------------------------------------------------------*
*&      Form  CHECK_EQUMX
*&---------------------------------------------------------------------*
*       Prüfen ob EQUMX bis zum Datum aufgebaut werden muß,
*       oder ob eine vorherige EQUMX aufgebaut werden muß.
*----------------------------------------------------------------------*
* Bei Wochen- und Monatslosgröße ist es möglich, daß die Intervalle
* sich nach der bisherigen Logik überschneiden.
* Deshalb erfolgt hier die Unterscheidung in 3 Fälle:
* 1. Für das geforderte Datum existiert bereits ein Intervall.
*    Das über quote_intervall_bestimmen ermittelte Intervall
*    überschneidet sich aber mit dem existierenden Intervall (EQUMX)
*    und wird deshalb durch die READ-Anweisung mit dem Key equmk
*    nicht gefunden.
* 2. Das geforderte Datum liegt außerhalb von bereits existierenden
*    Intervallen.
*    Es werden Intervalle (EQUMX-Sätze) vom Ende-Datum (+1) des letzten
*    existierenden Intervalls erzeugt, bis das geforderte Datum
*    in dem soeben erzeugten Intervall liegt.
* 3. Es existiert noch kein Intervall (EQUMX-Satz)
*    Es werden Intervalle (EQUMX-Sätze) vom Planungsdatum ab erzeugt,
*    bis das geforderte Datum in dem soeben erzeugten Intervall liegt.
*----------------------------------------------------------------------*


FORM check_equmx USING qunum LIKE equmx-qunum
                       qupos LIKE equmx-qupos
                       datum LIKE equmx-vdatu
                       abper LIKE equpx-abper
                       abanz LIKE equpx-abanz
                 CHANGING tabix LIKE sy-tabix.
  DATA: l_datum LIKE equmx-vdatu.
  CLEAR l_datum.
*--> (1. Fall) Ist das richtige Intervall bereits vorhanden?
  READ TABLE equmx WITH KEY qunum = qunum
                            qupos = qupos BINARY SEARCH.
  LOOP AT equmx FROM sy-tabix WHERE qunum = qunum
                              AND   qupos = qupos.
    IF  datum GE equmx-vdatu
    AND datum LE equmx-bdatu.
      MOVE datum TO l_datum.
      MOVE sy-tabix TO tabix.
      EXIT.
    ENDIF.
  ENDLOOP.
*--> Richtiges Intverall vorhanden: Rücksprung zum ADD
  IF NOT l_datum IS INITIAL.
    EXIT.
  ENDIF.
*--> Existiert ein EQUMX für diese Quotenposition
  READ TABLE equmx WITH KEY qunum = qunum
                            qupos = qupos BINARY SEARCH.
*--> (2. Fall) Falls ein EQUMX existiert, letzten Satz für EQUMX lesen
*-->           es wird das Datum des letzten Intervalls benötigt.
  IF sy-subrc = 0.
    tabix = tabix - 1.
    READ TABLE equmx INDEX tabix.
    l_datum = equmx-bdatu + 1.
*--> sy-tabix für INSERT wieder richtig setzen
    tabix = tabix + 1.
  ELSE.
*--> (3. Fall) Falls kein EQUMX existiert: Planungsdatum
    l_datum = mdkp-dsdat.
  ENDIF.
*--> Intervall in der Zukunft: Ab gefordertem Datum beginnen
  IF datum LT l_datum.
    MOVE datum TO l_datum.
  ENDIF.
*--> (2. + 3. Fall) Intervalle erzeugen.
  DO.
*--> with note 2950239 and the call of quote_intervall_statics upfront
*    the date should already lie inside a fitting interval and call of QUOTE_INTERVALL_BESTIMMEN
*    should be prevented in that case
    IF NOT ( l_datum >= mdcal-pranf  AND l_datum <= mdcal-prend ).
*--> Bestimmen von Anfangs- und Endtermin der zugehörigen Periode
      PERFORM quote_intervall_bestimmen USING l_datum abper abanz.
    ENDIF.
*--> EQUMX-Satz schreiben aber ohne Menge
*--> Menge wird später über ADD hinzugefügt
    CLEAR equmx.
    MOVE mdcal-pranf  TO equmx-vdatu.
    MOVE mdcal-prend  TO equmx-bdatu.
    MOVE qunum        TO equmx-qunum.
    MOVE qupos        TO equmx-qupos.
    INSERT equmx INDEX tabix.
*--> Falls richtiges Intervall: Satz nachlesen zum ADD
    IF  datum GE equmx-vdatu
    AND datum LE equmx-bdatu.
      READ TABLE equmx INDEX tabix.
      EXIT.
    ENDIF.
*--> Nächstes Intervall aufbauen.
    l_datum = equmx-bdatu + 1.
    tabix = tabix + 1.
  ENDDO.
ENDFORM.                    " CHECK_EQUMX
