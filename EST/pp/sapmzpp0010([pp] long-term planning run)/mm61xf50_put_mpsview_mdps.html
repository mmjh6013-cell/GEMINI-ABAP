Program listing for: MM61XF50_PUT_MPSVIEW_MDPS 
*----------------------------------------------------------------------*
* Daten aus MPS-VIEW in MDPSX uebernehmen                              *
*----------------------------------------------------------------------*


FORM put_mpsview_mdps USING delkz.
*--> Sortierheader zuruecksetzen
  CLEAR mdps.
*--> Pruefen Dispositionselement
  CASE delkz.
*--> Planauftrag
    WHEN plauf
    OR   saauf.
      PERFORM move_mppa_to_mdps.
*--> Bestellanforderung
    WHEN bsanf.
      PERFORM move_mpba_to_mdps.
*--> Lieferplaneinteilung
    WHEN lpein.
      PERFORM move_mplp_to_mdps.
*--> Fertigungsauftrag
    WHEN feauf.
      PERFORM move_mpfa_to_mdps.
*--> Prozeßauftrag
    WHEN barez.
      PERFORM move_mpfa_to_mdps.
*--> Ungültiges Dispositionselement
    WHEN OTHERS.
      MESSAGE a888.
  ENDCASE.
*--> Liefertermin bestimmen / Webaz addieren
  PERFORM add_webaz USING mdps-dat01 mdps-webaz mdps-dat00.
ENDFORM.
