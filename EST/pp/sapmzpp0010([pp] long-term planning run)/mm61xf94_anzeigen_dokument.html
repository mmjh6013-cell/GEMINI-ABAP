Program listing for: MM61XF94_ANZEIGEN_DOKUMENT 
*----------------------------------------------------------------------*
* Anzeigen Dokumente zum Material
*----------------------------------------------------------------------*


FORM ANZEIGEN_DOKUMENT USING MATNR LIKE MARA-MATNR
                             DATUM TYPE D.
*--> Lokale Daten
  DATA: L_OBJKY LIKE DRAD-OBJKY.
*--> Materialnummer in Objektkey überführen
  MOVE MATNR TO L_OBJKY.
*--> Dokuentverwaltung aufrufen
  CALL FUNCTION 'DOCUMENT_ASSIGNS_TO_DATE'
       EXPORTING  DOKOB       = 'MARA'
                  OBJKY       = L_OBJKY
                  DATUM       = DATUM
       EXCEPTIONS NO_DOCUMENT = 01.
  IF SY-SUBRC NE 0.
    MESSAGE S217.
  ENDIF.
ENDFORM.
