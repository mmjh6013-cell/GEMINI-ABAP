*----------------------------------------------------------------------*
*      Test & Support (undocumented feature)
*----------------------------------------------------------------------*


FORM FCODE_TEST USING XCODE LIKE AM61X-XCODE.
  CHECK XCODE CS 'MDPSX-'.
*--> Als OK-Code kann ein MDPSX-Feld eingegeben werden
  FIELD-SYMBOLS: <FNAME>.
*--> Pointer auf MDPSX-Feld in Kopfzeile setzen
  ASSIGN (XCODE) TO <FNAME>.
  CHECK SY-SUBRC = 0.
*--> Inhalt des Feldes wird in MDEZX-Spalte (UserExit 3) angezeigt
  LOOP AT MDEZX WHERE ALINE NE SPACE.
    READ TABLE MDPSX INDEX MDEZX-ALINE.
    IF SY-SUBRC = 0.
      WRITE <FNAME> TO MDEZX-USEX3.
      MODIFY MDEZX.
    ENDIF.
  ENDLOOP.
  MDST-UEX3A = XFLAG.
  PERFORM GET_USEREXIT3_COLUMTC_SIZE.
  CLEAR MDST-UEX3A.
ENDFORM.
