Program listing for: MM61XAUS_SELECTED_HELL 
*----------------------------------------------------------------------*
* Auskt bei markierten Zeilen hell ausgeben                            *
*----------------------------------------------------------------------*


FORM SELECTED_HELL.
*--> Suche nach Ausnahmen: Nur markierte Zeilen bearbeiten
*    Sonst: Auch nicht markierte verändern
  IF  MASEL-SELAU EQ XFLAG.
    CHECK MDEZ-SELKZ EQ XFLAG.
  ENDIF.

  LOOP AT SCREEN.
    IF  SCREEN-GROUP2 EQ 'A00'.
*--> Suche nach Datum
      IF MASEL-SELDA EQ XFLAG.
        IF (    MDEZ-FBYTE EQ CHAR1        "Bestands-,
             OR MDEZ-DELKZ EQ VORPL        "Vorplanungs-,
             OR MDEZ-DELKZ EQ BRTPL )      "oder Bruttoabschnittszeile:
        AND SCREEN-NAME EQ 'MDEZ-DELB0'.   "und Feld Dispoelement
          SCREEN-INTENSIFIED = 0.          "==> NICHT hell !
          MODIFY SCREEN.
        ELSEIF MDEZ-SELKZ EQ XFLAG.        "Zeile markiert ?
          SCREEN-INTENSIFIED = 1.          "==> Hell
          MODIFY SCREEN.
        ENDIF.
      ENDIF.
*--> Suche nach Abschnitten
      IF MASEL-SELAB EQ XFLAG.
        IF  MDEZ-SELKZ  NE XFLAG           "Zeile nicht markiert
        AND SCREEN-NAME EQ 'MDEZ-DELB0'.   "Feld Dispoelement
          SCREEN-INTENSIFIED = 0.          "==> NICHT hell !
          MODIFY SCREEN.
        ENDIF.
      ENDIF.
*--> navigation to certain element                            "SA 4.70
      IF MASEL-NAVIG EQ XFLAG.
        IF MDEZ-SELKZ EQ XFLAG.        "Zeile markiert ?
          SCREEN-INTENSIFIED = 1.          "==> Hell
          MODIFY SCREEN.
        ENDIF.
      ENDIF.
    ENDIF.
*--> Suche nach Ausnahmen
    IF  SCREEN-GROUP2 EQ 'A01'
    AND MASEL-SELAU   EQ XFLAG.
      SCREEN-INTENSIFIED = 1.
      MODIFY SCREEN.
    ENDIF.
  ENDLOOP.
ENDFORM.
