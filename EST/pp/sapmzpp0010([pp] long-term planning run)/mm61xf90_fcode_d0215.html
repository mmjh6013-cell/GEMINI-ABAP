FORM FCODE_D0215.
  CASE AM61X-XCODE.
*@001-Begin
*--> zukünftige Handelsaktionen zum Artikel anzeigen
  WHEN FC-PROM.
    PERFORM FCODE_PROM.
    EXIT.
*--> Übersicht Aktionen
  WHEN FC-WAK7.
    PERFORM FCODE_WAK USING FC-WAK7.
    EXIT.
  WHEN FC-WAK8.
    PERFORM FCODE_WAK USING FC-WAK8.
    EXIT.
*@001-End
*@002-Begin
*--> Infos zu Saisonartikel anzeigen
  WHEN FC-SEAS.
    PERFORM FCODE_SEAS.
    EXIT.
*@002-End
*--> Dispoelement anzeigen
*   when fc-azde.
*     perform fcode_azde.      THD neue Routine in MM61XF95
*     exit.
*--> Anzeigen Ausnahmemeldung
    WHEN FC-AZAM.
      PERFORM FCODE_AZAM_ATP.
      EXIT.
*--> Back zum Aufruf
    WHEN FC-XBAC.
      SET SCREEN '0710'.
      EXIT.
*--> Ändern der Materialnotiz
    WHEN FC-MANO.
      PERFORM FCODE_MANO.
      EXIT.
*--> Revision-Levels anzeigen
    WHEN FC-REVL.
      PERFORM FCODE_REVL.
      EXIT.
   ENDCASE.
*--> Pruefen Blaettern oder ERROR
  IF AM61X-XCODE = FC-PNXT
  OR AM61X-XCODE = FC-PPRE
  OR AM61X-XCODE = FC-PBEG
  OR AM61X-XCODE = FC-PEND.
    PERFORM BLAETTERN_MDINX.
  ELSE.
    MESSAGE I029 WITH AM61X-XCODE.
  ENDIF.
ENDFORM.
