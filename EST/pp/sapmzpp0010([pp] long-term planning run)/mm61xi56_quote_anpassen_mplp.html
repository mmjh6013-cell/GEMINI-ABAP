Program listing for: MM61XI56_QUOTE_ANPASSEN_MPLP 
*----------------------------------------------------------------------*
* Quote_Anpassen_MPLP                                                  *
* Hat sich in der MPLP ein Quotenrelevantes Feld geändert
* ( RESWK, BESKZ, PSTYP, EINDT, FLIEF ), läuft dieses Modul ab
* und es wird geschaut, ob es zur neuen Kombination einen gültigen
* Quotensatz gibt.
* der Lieferant muß hier aus der EKKO nachgelesen werden
*----------------------------------------------------------------------*


MODULE QUOTE_ANPASSEN_MPLP.

MOVE MPLP-QUNUM TO AM61X-QUNUM.
MOVE MPLP-QUPOS TO AM61X-QUPOS.
CLEAR MPLP-QUNUM.
CLEAR MPLP-QUPOS.
*--> der Lieferant muß hier aus der MDRV nachgelesen werden
PERFORM READ_MDRV USING MPLP-EBELN MPLP-EBELP.
CHECK SY-SUBRC = 0.
PERFORM QUOTE_ANPASSEN USING MPLP-QUNUM MPLP-QUPOS  MPLP-EINDT
                             BESKZF     MPLP-PSTYP  MDRV-LIFNR
                             SPACE      CM61W-PLWRK MPLP-RESWK.

*--> Meldung ausgeben, falls sich die QUNUM/QUPOS geändert hat
IF MPLP-QUNUM NE AM61X-QUNUM
OR MPLP-QUPOS NE AM61X-QUPOS.
  MESSAGE I146.
ENDIF.
ENDMODULE.
