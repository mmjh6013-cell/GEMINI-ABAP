Program listing for: MM61XF92_FCODE_FAAL_EZ 
*----------------------------------------------------------------------*
* FCODE: Fertigungsauftrag anlegen aus Einzelbild
*----------------------------------------------------------------------*


FORM FCODE_FAAL_EZ.
*--> Call Auswahlwindow
  CALL SCREEN 0257
       STARTING AT 12 11
       ENDING   AT 40 12.
*--> Prüfen DELKZ
  IF AM61X-DELKZ EQ SPACE.
    EXIT.
  ENDIF.
*--> Clear Einzelzeile
  CLEAR MDEZS.
  CLEAR MDEZS-XLINE.
*--> Clear Summenzeile
  CLEAR EXEZX.
  CLEAR SUKEY.
  CLEAR MDSUS-XLINE.
*--> Clear Dispositionszeile
  CLEAR MDPSS.
  CLEAR MDPSS-XLINE.
*--> Fertigungsauftrag initialisieren
  PERFORM INIT_FERTAUFTRAG_AL USING AM61X-RCODE.
  IF AM61X-RCODE NE CHAR0.
    EXIT.
  ENDIF.
*--> Setzen Verarbeitungssatus
  MOVE VSTATH TO AM61X-VSTAT.
*--> Setzen DELKZ für Ablaufsteuerung
  MOVE FEAUF TO AM61X-DELKZ.
  IF MPFA-AUTYP EQ AFTYPB.
    MOVE BAREZ TO AM61X-DELKZ.
  ENDIF.
*--> MDEZ für Fertigungsauftrag aufbauen
  PERFORM MOVE_MPFA_TO_MDEZ.
*--> MDEZ einfügen
  PERFORM CHECK_AENDERUNG_MDEZ.
*--> Einzelzeilensplitscreen aufrufen
  MDST-ANZEI = EZSI_ACTIV.     "Einzelzeilen-Splitscreen
  SET SCREEN '0730'. LEAVE SCREEN.
ENDFORM.
