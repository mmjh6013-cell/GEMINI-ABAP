Program listing for: MM61XF60_UPDATE_MDPMX_BSANF 

FORM UPDATE_MDPMX_BSANF.
  MOVE CHAR1 TO AM61X-RCODE.               "Returncode vorbesetzen
  IF MPBA-RSNUM IS INITIAL.                "Keine Reservierungsnummer
    IF AM61X-VSTAT  = VSTATH
    AND CM61X-INMEM = XFLAG.               "Bei neuer Banf
      PERFORM STUELI_AUFLOESEN_MPBA.       "Stueli neu aufloesen
      MPBA-AKTAL  = XFLAG.
      MDPS-RSNUM  = MPBA-RSNUM.
      AM61X-RCODE = CHAR0.
      EXIT.
    ELSE.
      EXIT.
    ENDIF.
  ENDIF.
  IF MPBA-AKTAL <> XFLAG.                  "Aufloesung nicht aktuell
    PERFORM READ_MDPMX USING MPBA-RSNUM.   "Komponenten lesen
    IF AM61X-RCODE NE CHAR0. EXIT. ENDIF.
  ENDIF.
  PERFORM CHECK_ANPASSEN_MDPMX_BSANF.      "Check Komponentenanpassung
  MOVE XFLAG TO MPBA-AKTAL.                "Setzen Aktualitaetskz
  MOVE CHAR0 TO AM61X-RCODE.               "Returncode setzen
ENDFORM.
