FORM BEARBEITEN_MDPMX_MPPA USING CAMOD.
*--> Schnittstellendaten fuellen
  MOVE CAMOD       TO CM61Q-CAMOD.
  MOVE CM61W-FABKL TO CM61Q-FABKL.
  MOVE SPACE       TO CM61Q-AENKZ.
  MOVE SPACE       TO CM61Q-RCODE.
  MOVE MPPA-BESKZ  TO CM61Q-BESKZ.
  MOVE HERKTM      TO CM61Q-HERKT.
  MOVE CM61M-PRREG TO CM61Q-PRREG.   " Note 754772
*--< components not changeable for LTP orders (TL 470)
  IF MPPA-OBART EQ OBARTS.
    MOVE CHARA TO CM61Q-TRTYP.
  ENDIF.
*--> Komponenten Bearbeitung / Erfassung aufrufen
  CALL FUNCTION 'MD_BEARBEITEN_MPPA'
       EXPORTING ECM61Q = CM61Q
                 EMPPA  = MPPA
                 EMT61D = MT61D        " Note 760314
                 ECM61M = CM61M
       IMPORTING ICM61Q = CM61Q
                 IMPPA  = MPPA
       TABLES    MDPMX  = MDPMX
                 MDPML  = MDPML.
*--> Aenderungkennzeichen ueberpruefen
  IF CM61Q-AENKZ NE SPACE.
    MOVE XFLAG TO AM61X-AENAL.
    IF CM61X-PLSCN IS INITIAL.                            "31g
      MOVE XFLAG TO MPPA-AUFFX.                           "31g
      MOVE XFLAG TO MPPA-STLFX.                           "31g
    ENDIF.                                                "31g
*--> Nummernvergabe Komponentenliste
    IF MPPA-RSNUM IS INITIAL.
      PERFORM NEW_NUMBER USING 'RESB' T399D-NKRES MPPA-RSNUM.
    ENDIF.
  ENDIF.
ENDFORM.
