Program listing for: MM61XF50_CHECK_SOBKZ 
*----------------------------------------------------------------------*
* Pruefen Sonderbestandskennzeichen                                    *
*----------------------------------------------------------------------*


FORM CHECK_SOBKZ.
*--> Stern-Eingabe ueberpruefen
  IF RM61X-KNTTP EQ STERN.
    CALL SCREEN 0305
         STARTING AT 20 15
         ENDING   AT 65 19.
    EXIT.
  ENDIF.
*--> Kundeneinzelbestand
  IF RM61X-SOBKZ EQ SOBKZE.
    IF RM61X-KDAUF IS INITIAL
    OR RM61X-KDPOS IS INITIAL.
      CALL SCREEN 0305
           STARTING AT 20 15.
    ELSE.
      IF  RM61X-KZVBR EQ KZVBRP
      AND RM61X-PSPEL IS INITIAL.
        CALL SCREEN 0305
             STARTING AT 20 15.
      ENDIF.
    ENDIF.
    EXIT.
  ENDIF.
*--> Projekteinzelbestand
  IF RM61X-SOBKZ EQ SOBKZQ.
    IF RM61X-PSPEL IS INITIAL.
      CALL SCREEN 0306
           STARTING AT 20 15.
    ENDIF.
    EXIT.
  ENDIF.
*--> Sonderbestandskennzeichen initial
  IF  RM61X-SOBKZ NE SOBKZE
  AND RM61X-SOBKZ NE SOBKZQ.
    IF NOT RM61X-KDAUF IS INITIAL
    OR NOT RM61X-KDPOS IS INITIAL
    OR NOT RM61X-PSPEL IS INITIAL.
      CLEAR RM61X-KDAUF.
      CLEAR RM61X-KDPOS.
      CLEAR RM61X-PSPEL.
      MESSAGE I013.
    ENDIF.
    EXIT.
  ENDIF.
ENDFORM.
