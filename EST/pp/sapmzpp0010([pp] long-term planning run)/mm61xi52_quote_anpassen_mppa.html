Program listing for: MM61XI52_QUOTE_ANPASSEN_MPPA 
*----------------------------------------------------------------------*
* Quote_Anpassen_MPPA                                                  *
* Hat sich in der MPPA ein Quotenrelevantes Feld geändert
* ( PWWRK, BESKZ, SOBES, PEDTR, FLIEF, VERID ), läuft dieses Modul ab
* und es wird geschaut, ob es zur neuen Kombination einen gültigen
* Quotensatz gibt.
*----------------------------------------------------------------------*


MODULE QUOTE_ANPASSEN_MPPA.
*--> Planungswerk prüfen
  IF MPPA-PLWRK NE MDKP-PLWRK.
    EXIT.
  ENDIF.
*--> Merken bisherige Quote
  MOVE MPPA-QUNUM TO AM61X-QUNUM.
  MOVE MPPA-QUPOS TO AM61X-QUPOS.
  CLEAR MPPA-QUNUM.
  CLEAR MPPA-QUPOS.
*--> Neu Quotieren
  PERFORM QUOTE_ANPASSEN USING MPPA-QUNUM MPPA-QUPOS MPPA-PEDTR
                               MPPA-BESKZ MPPA-SOBES MPPA-FLIEF
                               MPPA-VERID MPPA-PLWRK MPPA-PWWRK.
*--> Meldung ausgeben, falls sich die Quote geändert hat
  IF MPPA-QUNUM NE AM61X-QUNUM
  OR MPPA-QUPOS NE AM61X-QUPOS.
    MESSAGE I146.
  ENDIF.
ENDMODULE.
