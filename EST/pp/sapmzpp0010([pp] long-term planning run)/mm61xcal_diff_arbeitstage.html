Program listing for: MM61XCAL_DIFF_ARBEITSTAGE 
*----------------------------------------------------------------------*
*    Berechne Anzahl Arbeitstage zwischen Datum_1 und Datum_2.
*----------------------------------------------------------------------*


FORM DIFF_ARBEITSTAGE USING DATUM_1 DATUM_2 DIFF_AT FABKAL.

  DATA: AT_1 LIKE MDCAL-FKDAY.

  PERFORM CONVERT_GKDAY_FKDAY_MINUS USING DATUM_1 FABKAL.
  AT_1 = MDCAL-FKDAY.
  PERFORM CONVERT_GKDAY_FKDAY_MINUS USING DATUM_2 FABKAL.
  DIFF_AT = MDCAL-FKDAY - AT_1.

ENDFORM.
