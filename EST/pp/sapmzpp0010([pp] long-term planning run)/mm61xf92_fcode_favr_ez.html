*----------------------------------------------------------------------*
* FCODE: Fertigungsauftrag aendern
*----------------------------------------------------------------------*


FORM FCODE_FAVR_EZ.
  DATA: LV_SELECTED_LINE LIKE SY-TABIX,
        LV_FOUND         TYPE BOOL.

*--> Einzelzeile ermitteln
  PERFORM PICK_UP_EZ
          USING    CHAR2
          CHANGING LV_SELECTED_LINE LV_FOUND.
  CHECK LV_FOUND = GC_TRUE.
*--> Setzen Verarbeitungssatus
  MOVE VSTATV      TO AM61X-VSTAT.
  MOVE MDEZX-DELKZ TO AM61X-DELKZ.
*--> Auftrag in Ausgabestruktur uebernehmen
  PERFORM PUT_MDPSX_MPSVIEW.
  IF AM61X-RCODE NE CHAR0.
    EXIT.
  ENDIF.
*--> MDEZ vorbereiten
  PERFORM MDEZ_VORBEREITEN_VR USING LV_SELECTED_LINE.
*--> Einzelzeilensplitscreen aufrufen
  MDST-ANZEI = EZSI_ACTIV.     "Einzelzeilen-Splitscreen
  SET SCREEN '0730'. LEAVE SCREEN.
ENDFORM.
