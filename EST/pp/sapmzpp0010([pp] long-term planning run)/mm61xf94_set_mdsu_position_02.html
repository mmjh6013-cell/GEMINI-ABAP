Program listing for: MM61XF94_SET_MDSU_POSITION_02 
*----------------------------------------------------------------------*
* Anzeigeposition fuer MDSU nach MDEZS ermitteln
*----------------------------------------------------------------------*


FORM SET_MDSU_POSITION_02.
*--> Aufsetzpunkt bestimmen
  PERFORM KEY_MDSUX USING MDEZS-PLAAB MDEZS-PLANR MDEZS-DAT00.
  READ TABLE MDSUX WITH KEY SUKEY BINARY SEARCH.
  IF SY-SUBRC NE 0.
    MESSAGE E190 WITH 0 'MDSUX'.
  ENDIF.
*--> Sichern Index fuer aktuelle Summenzeile
  MOVE SY-TABIX TO MDSUS-XLINE.
*--> Anzeige neu positionieren
  MDSUX-XLINE = MDSUS-XLINE - 1.
  IF MDSUX-XLINE LT 1.
    MDSUX-XLINE = 1.
  ENDIF.
*--> TC-Topline setzen
  MOVE MDSUX-XLINE TO TC_PS-TOP_LINE.

ENDFORM.
