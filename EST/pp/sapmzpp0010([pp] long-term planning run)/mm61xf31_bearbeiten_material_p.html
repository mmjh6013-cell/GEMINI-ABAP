Program listing for: MM61XF31_BEARBEITEN_MATERIAL_P 
*----------------------------------------------------------------------*
*  Naechstes Material beim Planungslauf bearbeiten
*----------------------------------------------------------------------*


FORM BEARBEITEN_MATERIAL_PL.
*--> Initialisierung
  PERFORM RESET_DATA.
*--> Lesen und Pruefen naechstes Material
  PERFORM READ_CHECK_MATERIAL.
  IF AM61X-RCODE NE CHAR0.
    EXIT.
  ENDIF.
*--> User-Exit for exluding materials / stopping the planning run
  PERFORM USER_EXIT_001.
  IF CM61X-STOPX = XFLAG.                   "stop planning
    EXIT.
  ENDIF.
  CHECK CM61D-NOMRP IS INITIAL.
*--> Material sperren                        "40c , SL umgestellt 46C
  PERFORM SPERREN_MRP_MP USING CM61D-WERKS CM61D-BERID CM61D-MATNR.
  IF AM61X-RCODE NE CHAR0.
    PERFORM WRITE_MATERIAL_IGNORE.
    EXIT.
  ENDIF.
*--> Disponieren, SL-Aufloesung, Durchlaufterminierung
  PERFORM DISPONIEREN_MATERIAL_BT.
  IF AM61X-RCODE NE CHAR0.
    EXIT.
  ENDIF.
*--> Pruefen Verbuchung Material
  PERFORM CALL_VERBUCHUNG_BT.
  IF AM61X-RCODE NE CHAR0.
    EXIT.
  ENDIF.
*--> Verarbeitungskennzeichen in CM61D sichern (Statistik)
  PERFORM SAVE_KZXXX_CM61D.
*--> Material entsperren
  PERFORM ENTSPERREN_MRP USING CM61D-WERKS CM61D-BERID CM61D-MATNR.
*--> Returncode zuruecksetzen
  MOVE CHAR0 TO AM61X-RCODE.
ENDFORM.
