Program listing for: MM61XSUC_BUILD_SINGLE_MDAUSX 
*---------------------------------------------------------------------*
* Mdausx bearbeiten
*---------------------------------------------------------------------*


FORM BUILD_SINGLE_MDAUSX TABLES MDAUSX STRUCTURE MDAUSX
                         USING  SELAU TYPE C
                                AUSSL LIKE MDEZX-AUSSL
                                ABEKZ LIKE MDEZX-ABEKZ
                                SELKZ LIKE MDEZX-SELKZ.
*--> Suche nach Ausnahmen aktiv ?
  CHECK SELAU NE CHARN.
  CHECK NOT AUSSL IS INITIAL.
  READ TABLE MDAUSX WITH KEY AUSSL BINARY SEARCH.
  MOVE SY-TABIX TO MASEL-XLINE.
*--> Passender Eintrag in Mdausx gefunden.
  IF SY-SUBRC EQ 0.
    IF ABEKZ = XFLAG.
      IF MDAUSX-OLDAU LT 99.                   "#EC PORTABLE
        MDAUSX-OLDAU = MDAUSX-OLDAU + 1.
      ELSE.
        MDAUSX-OLDAU = '99'.
      ENDIF.
    ELSE.
      IF MDAUSX-NEWAU LT 99.                   "#EC PORTABLE
        MDAUSX-NEWAU = MDAUSX-NEWAU + 1.
      ELSE.
        MDAUSX-NEWAU = '99'.
      ENDIF.
    ENDIF.
    MODIFY MDAUSX INDEX MASEL-XLINE.
*--> Kein passender Eintrag in Mdausx gefunden
  ELSE.
    CLEAR MDAUSX.
*----> Zeile in Mdezx selektiert --> Auswahlkz in Mdausx setzen
    IF SELKZ = XFLAG.
      MDAUSX-SELKZ = XFLAG.
    ENDIF.
    MDAUSX-AUSSL = AUSSL.
*---> Ausnahmenummer und -Priorität nachlesen
    PERFORM READ_T458A_RX USING AUSSL.
    MDAUSX-SELGP = T458A-SELGP.
    MDAUSX-AUSKT = T458A-AUSKT.
    MDAUSX-ASPRI = T458A-ASPRI.
*---> Text zur Ausnahmemeldung nachlesen
    PERFORM READ_T458B_RX USING MDAUSX-AUSSL MDAUSX-AUSLT.
    IF ABEKZ = XFLAG.
      MDAUSX-OLDAU = 1.
      MDAUSX-NEWAU = 0.
    ELSE.
      MDAUSX-OLDAU = 0.
      MDAUSX-NEWAU = 1.
    ENDIF.
    INSERT MDAUSX INDEX MASEL-XLINE.
  ENDIF.
ENDFORM.
