Program listing for: MM61XF60_UPDATE_MDPMX_PLAF 
*----------------------------------------------------------------------*
*  Aufloesungstabelle aktualisieren und ggf lesen                      *
*----------------------------------------------------------------------*


FORM UPDATE_MDPMX_PLAF.
  MOVE CHAR1 TO AM61X-RCODE.               "Returncode vorbesetzen
  IF MPPA-RSNUM IS INITIAL.                "Keine Reservierungsnummer
    IF  AM61X-VSTAT = VSTATH
    AND CM61X-INMEM = XFLAG.               "Bei neuen Planauftrag
      PERFORM STUELI_AUFLOESEN_MPPA.       "Stueli neu aufloesen
      MPPA-AKTAL  = XFLAG.
      AM61X-RCODE = CHAR0.
      MDPS-RSNUM  = MPPA-RSNUM.
      EXIT.
    ELSE.
      EXIT.
    ENDIF.
  ENDIF.
  IF MPPA-AKTAL <> XFLAG.                  "Aufloesung nicht aktuell
    PERFORM READ_MDPMX USING MPPA-RSNUM.   "Komponenten lesen
    IF AM61X-RCODE NE CHAR0. EXIT. ENDIF.
  ENDIF.
  PERFORM CHECK_ANPASSEN_MDPMX_PLAUF.      "Check Komponentenanpassung
  MOVE XFLAG TO MPPA-AKTAL.                "Setzen Aktualitaetskz
  MOVE CHAR0 TO AM61X-RCODE.               "Returncode setzen
ENDFORM.
