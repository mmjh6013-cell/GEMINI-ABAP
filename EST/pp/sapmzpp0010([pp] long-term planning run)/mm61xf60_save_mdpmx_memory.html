Program listing for: MM61XF60_SAVE_MDPMX_MEMORY 
*----------------------------------------------------------------------*
* Aufloesungstabelle fuer Verbuchung sichern
*----------------------------------------------------------------------*


FORM save_mdpmx_memory.
*--> Vorraussetzungen pruefen
  IF  mdps-rsnum IS INITIAL
  AND am61x-vstat <> vstath.
    EXIT.
  ENDIF.
*--> Auflösungsflag prüfen (bei Komp.fixierung Anpassung durchführen)
  IF cm61x-inmem EQ gc_false
  AND mdps-aktal NE xflag
  AND mdpss-fix02 NE xflag.                                 "HW 171004
    EXIT.
  ENDIF.
*--> vorlaeufiges Abfangen von LP-Einteilungen ohne LB-Komponenten
  IF  mdps-delkz =  lpein
  AND mdps-sobes <> '3'.
    EXIT.
  ENDIF.
*--> Move Auftragskopfdaten in PLKV
  PERFORM put_mpxx_plkva USING mdps-delkz.
*--> Pruefen Veraenderung
  IF plkva       <> plkvs
  OR cm61x-inmem =  gc_true
  OR mdpss-fix02 =  xflag.                              "TL note 425143
*--> Fixierung überprüfen
    CASE mdps-delkz.
      WHEN plauf
      OR   saauf.
        IF mdps-fix02 NE xflag AND cm61x-inmem = gc_false.
          PERFORM reset_aktal_01. EXIT.
        ENDIF.
        PERFORM update_mdpmx_plaf.
      WHEN bsanf.
        IF mdps-fix02 NE xflag AND cm61x-inmem = gc_false.
          PERFORM reset_aktal_01. EXIT.
        ENDIF.
        PERFORM update_mdpmx_bsanf.
      WHEN lpein.
        IF mdps-fix02 NE xflag AND cm61x-inmem = gc_false.
          PERFORM reset_aktal_01. EXIT.
        ENDIF.
        PERFORM update_mdpmx_lpein.
      WHEN OTHERS.
        MESSAGE a888.
    ENDCASE.
  ENDIF.
*--> Auflösungstabelle ins MEMORY exportieren
  CALL FUNCTION 'MD_SAVE_MDPMI_MEMORY'
       EXPORTING
            ersnum = mdps-rsnum
            eplnum = mdps-delnr
       TABLES
            mdpmx  = mdpmx.
*--> Setzen Kennzeichen fuer aktuelle Stueli-Aufloesung
  mdps-aktal = xflag.
ENDFORM.
