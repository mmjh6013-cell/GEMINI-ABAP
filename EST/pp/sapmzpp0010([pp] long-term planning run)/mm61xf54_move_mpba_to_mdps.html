FORM move_mpba_to_mdps.
*--> MDEZ zuruecksetzen
  CLEAR mdps.

  MOVE netpla     TO mdps-plaab.

    MOVE kndpla     TO mdps-plaab.
    MOVE mpba-vbeln TO plakd-kdauf.
    MOVE mpba-vbelp TO plakd-kdpos.
    MOVE plakd      TO mdps-planr.
  ENDIF.

  "{ Begin ENHO ADSUB_MM61XF54_MOVE_MPBA_TO001 IS-AD-SUC AD_SUB }

    MOVE plakd      TO mdps-planr.
  ENDIF.

  "{ End ENHO ADSUB_MM61XF54_MOVE_MPBA_TO001 IS-AD-SUC AD_SUB }

*--> Pruefen Lagerortdisposition
  IF NOT mpba-lgort IS INITIAL
  AND  ( mdps-plaab EQ netpla
      OR mdps-plaab EQ brtpla ).
    PERFORM check_lgort USING mpba-lgort.
    IF mard-diskz EQ diskz1.           "Lagerort ausgeschlossen
      MOVE lgods2     TO mdps-plaab.
      MOVE mpba-lgort TO plalg-lgort.
      MOVE plalg      TO mdps-planr.
    ENDIF.
    IF mard-diskz EQ diskz2.           "Lagerort seperat disponieren
      MOVE lgods1     TO mdps-plaab.
      MOVE mpba-lgort TO plalg-lgort.
      MOVE plalg      TO mdps-planr.
    ENDIF.
  ENDIF.
*--> Pruefen Bestellanforderungsnummer
  IF mpba-banfn EQ space.
    PERFORM new_number USING 'BANF' t460d-numki mpba-banfn.
    PERFORM banf_sperren USING mpba-banfn mpba-bnfpo.
  ENDIF.
  IF mpba-bnfpo EQ space.
    MOVE t460d-psban TO mpba-bnfpo.
  ENDIF.
