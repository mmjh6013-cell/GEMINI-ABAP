Program listing for: MM61XF93_FCODE_CAPM 
*----------------------------------------------------------------------*
* FCODE: Kapazitätsplanung    aus Materialsicht                        *
*----------------------------------------------------------------------*


FORM FCODE_CAPM.
  DATA: MRPPP LIKE MT61D-MRPPP.
  IF AM61X-PROFL IS INITIAL
  OR AM61X-STYPE IS INITIAL.
  IF MT61D-MRPPP IS INITIAL.
    MRPPP = T399D-MRRPP.
  ELSE.
    MRPPP = MT61D-MRPPP.
  ENDIF.
*--> Planungsart und Profil (wg. Periodenart) bestimmen
    CALL FUNCTION 'MPS_CAPA_SET_PARAMETER'
         EXPORTING
              PROFL_IMP  = AM61X-PROFL
              STYPE_IMP  = AM61X-STYPE
              MRPPP      = MRPPP
         IMPORTING
              PROFILE_ID = AM61X-PROFL
              SCHED_TYPE = AM61X-STYPE
         EXCEPTIONS
              CANCELLED  = 01.
    IF SY-SUBRC <> 0.
      EXIT.
    ENDIF.
  ENDIF.
  PERFORM MPS_CAPACITY_ALL USING AM61X-PROFL AM61X-STYPE.
*--> Aenderungen uebernehmen
  AM61X-VSTAT = VSTATV.
  PERFORM MDPSX_ANPASSEN USING SPACE.
*--> Einzelzeilentabelle aktualisieren
  PERFORM MDEZX_AUFBAUEN.
*--> ATP-Menge   aktualisieren
  IF NOT MDST-KZATP IS INITIAL.
    PERFORM ATP_BERECHNEN_MDEZX.
  ENDIF.
*--> Summenzeile aktualisieren
  PERFORM PUT_MDEZX_MDSUX.
ENDFORM.
