Program listing for: MM61XC02_CHECK_RESET_KZ_PL 
*----------------------------------------------------------------------*
* Planungskennzeichen setzen (Verarbeitungsschlüssel / Planungsmodus)
*----------------------------------------------------------------------*


FORM CHECK_RESET_KZ_PL
     USING    ICM61X LIKE CM61X
     CHANGING L_RESAL LIKE CM61D-RESAL
              L_RESDT LIKE CM61D-RESDT
              L_VMUPD LIKE CM61D-VMUPD.

*--> Pruefen Planungslauf
  IF ICM61X-PLAUF EQ MRPPL
  OR ICM61X-PLAUF EQ MPSPL
  OR ICM61X-PLAUF EQ LFRPL.
     IF ICM61X-PLMOD EQ CHAR2.
        MOVE XFLAG TO L_RESAL.
     ENDIF.
     IF ICM61X-PLMOD EQ CHAR3.
        MOVE XFLAG TO L_RESDT.
        MOVE XFLAG TO L_RESAL.
     ENDIF.
*--> Setzen Update-Kz fuer Verbuchung
     CASE ICM61X-VRART.
          WHEN NEUVR.
            MOVE CHAR1 TO L_VMUPD.
          WHEN NETVR.
            MOVE CHAR1 TO L_VMUPD.
          WHEN NPLVR.
            MOVE CHAR2 TO L_VMUPD.
     ENDCASE.
  ENDIF.
ENDFORM.
