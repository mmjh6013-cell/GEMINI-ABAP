Program listing for: MM61XF60_STUELI_AUFLOESEN_MPPA 
*----------------------------------------------------------------------*
* Stückliste aufloesen fuer Planauftrag
*----------------------------------------------------------------------*


FORM STUELI_AUFLOESEN_MPPA.
*--> Komponententabelle erfrischen
  CLEAR   MDPMX.
  REFRESH MDPMX.
  CLEAR   MDPML.
  REFRESH MDPML.
*--> Aufloesung aufrufen
  CALL FUNCTION 'MD_AUFLOESEN_MPPA'
       EXPORTING  ECM61X = CM61X
                  EMPPA  = MPPA
                  EMT61D = MT61D
                  ET399D = T399D
                  ECM61M = CM61M
       IMPORTING  IMPPA  = MPPA
       TABLES     MDPMX  = MDPMX
                  DQUKX  = EQUKX
                  DQUPX  = EQUPX
       EXCEPTIONS ERROR_MESSAGE = 1.
       IF SY-SUBRC NE 0.
         MOVE CHAR1 TO AM61X-RCODE. EXIT.
       ENDIF.
*--> Komponententabelle ueberpruefen
    DESCRIBE TABLE MDPMX LINES AM61X-ALINE.
    IF AM61X-ALINE EQ 0.
      MOVE CHAR1 TO AM61X-RCODE. EXIT.
    ENDIF.
*--> Sichern Kopfdaten fuer Komponentenanpassung
    IF MPPA-AKTAL EQ XFLAG.
      MOVE XFLAG TO AM61X-AENAL.
      MOVE XFLAG TO MPPA-AUFFX.
*--> Auftrag fixieren (ausser in LFP)
      IF CM61X-PLSCN IS INITIAL.
        MOVE XFLAG TO MPPA-STLFX.
      ENDIF.
    ENDIF.
*--> Sichern Kopfdaten fuer Komponentenanpassung
    PERFORM PUT_MPPA_PLKV USING PLKVS.
*--> Setzen Retruncode
    MOVE CHAR0 TO AM61X-RCODE.
ENDFORM.
