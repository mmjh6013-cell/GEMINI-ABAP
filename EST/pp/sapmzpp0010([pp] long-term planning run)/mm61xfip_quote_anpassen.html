Program listing for: MM61XFIP_QUOTE_ANPASSEN 
*----------------------------------------------------------------------*
* Quote Anpassen                                                       *
* Hat sich in der MPPA ein Quotenrelevantes Feld geändert
* ( BEWRK, BESKZ, SOBES, DATUM, LIFNR, VERID ), läuft dieses UP ab
* und es wird geschaut, ob es zur neuen Kombination einen gültigen
* Quotensatz gibt.
* die Logik ist analog zur Planauftragsverwaltung  (MM61PF70)
*----------------------------------------------------------------------*


FORM QUOTE_ANPASSEN USING QUNUM LIKE EQUP-QUNUM
                          QUPOS LIKE EQUP-QUPOS
                          DATUM TYPE D
                          BESKZ LIKE MPPA-BESKZ
                          SOBES LIKE MPPA-SOBES
                          LIFNR LIKE MPPA-FLIEF
                          VERID LIKE MPPA-VERID
                          PLWRK LIKE MPPA-PLWRK
                          BEWRK LIKE MPPA-PWWRK.
*--> Pruefen Quotierungskennzeichen
  IF CM61M-USEQU EQ SPACE.
    EXIT.
  ENDIF.
*--> Gueltige Quotierung nach Termin suchen
  LOOP AT EQUKX.
    IF  DATUM GE EQUKX-VDATU
    AND DATUM LE EQUKX-BDATU.
      PERFORM SUCHEN_QUOTENPOSITION
              USING QUNUM QUPOS BESKZ SOBES LIFNR VERID PLWRK BEWRK.
      EXIT.
    ENDIF.
  ENDLOOP.
ENDFORM.
