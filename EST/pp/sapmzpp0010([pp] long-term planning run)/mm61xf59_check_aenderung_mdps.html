FORM CHECK_AENDERUNG_MDPS.

"{ Begin ENHO DIMP_GENERAL_SAPMM61X IS-AD-MPN-MRP AD_MPN_IC }
* A&D 3.0; MPN-Projekt; Cora Zimmermann; 12.02.1999
* save MPN-material from old record
  MDPS-MPNMT = MDPSS-MPNMT.
"{ End ENHO DIMP_GENERAL_SAPMM61X IS-AD-MPN-MRP AD_MPN_IC }

ENHANCEMENT-POINT MM61XF59_CHECK_AENDERG_MDPS_01 SPOTS ES_SAPMM61X.
*--> Kennz. 'Terminierung aktuell' zuruecksetzen (wg. Aenderung)
  CLEAR MDPS-AKTFT.
  CLEAR MDPS-AKTRT.
  CLEAR MDPS-AKTGT.
*--> Verarbeitungsstatus ueberpruefen
  IF AM61X-VSTAT EQ VSTATH.
    MOVE VSTATH TO MDPS-VSTAT.
    PERFORM SET_NEW_AUSSL USING AUSV3 MDPS-AUSSL MDPS-OLDSL.
    PERFORM CHECK_FIXIERUNGSHORIZONT USING MDPS-FIX01 MDPS-FIX01.
*--> Bei BSANF / LPEIN Doppelfixierung
    IF MDPS-FIX01 EQ XFLAG                                        "45B
    AND ( MDPS-DELKZ EQ BSANF                                     "45B
          OR MDPS-DELKZ EQ LPEIN ).                               "45B
      MOVE XFLAG TO MDPS-FIX02.                                   "45B
    ENDIF.                                                        "45B
    PERFORM SET_QUOTIERUNG_MDPS.
    PERFORM SAVE_MDPMX_MEMORY.
    PERFORM INSERT_SORTED_MDPSX USING MDPS.
    PERFORM UPDATE_MRP_DATA_IN_MEMORY
            USING MDKP MDPS CM61B MDPSX[] MDPSO[].
    EXIT.
  ENDIF.
*--> Verarbeitungsstatus setzen
  IF MDPS-VSTAT NE VSTATH.
    MOVE VSTATV TO MDPS-VSTAT.
  ENDIF.
*--> Reset Umterminierungsdaten
  PERFORM RESET_MDPS_01.
*--> Setzen Ausnahmemeldung
  PERFORM SET_NEW_AUSSL USING AUSV3 MDPS-AUSSL MDPS-OLDSL.
*--> Preufen Fixierungskennzeichen
  PERFORM CHECK_FIXIERUNGSHORIZONT USING MDPS-FIX01 MDPS-FIX01.
*--> Bei BSANF / LPEIN Doppelfixierung
  IF MDPS-FIX01 EQ XFLAG                                        "45B
  AND ( MDPS-DELKZ EQ BSANF                                     "45B
        OR MDPS-DELKZ EQ LPEIN ).                               "45B
    MOVE XFLAG TO MDPS-FIX02.                                   "45B
  ENDIF.                                                        "45B
*--> Quotierung ueberpruefen
  PERFORM CHECK_QUOTIERUNG_MDPS.
*--> Aufloesung im Memory sichern
  PERFORM SAVE_MDPMX_MEMORY.
*--> Pruefen Aenderung am Sortierbegriff
  IF MDPS-PLAAB NE MDPSS-PLAAB
  OR MDPS-PLANR NE MDPSS-PLANR
  OR MDPS-DAT00 NE MDPSS-DAT00
  OR MDPS-TAG00 NE MDPSS-TAG00
  OR MDPS-SORT1 NE MDPSS-SORT1
  OR MDPS-SORT2 NE MDPSS-SORT2.
    DELETE MDPSX INDEX MDPSS-XLINE.
    PERFORM INSERT_SORTED_MDPSX USING MDPS.
  ELSE.
    READ TABLE MDPSX INDEX MDPSS-XLINE.
    IF SY-SUBRC NE 0.
      MESSAGE E190 WITH MDPSS-XLINE 'MDPSX'.
    ENDIF.
    MOVE MDPS TO MDPSX.
    MODIFY MDPSX INDEX MDPSS-XLINE.
  ENDIF.
  PERFORM UPDATE_MRP_DATA_IN_MEMORY
          USING MDKP MDPS CM61B MDPSX[] MDPSO[].
ENDFORM.
