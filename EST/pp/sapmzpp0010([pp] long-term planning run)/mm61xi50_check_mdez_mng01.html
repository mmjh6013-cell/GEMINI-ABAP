Program listing for: MM61XI50_CHECK_MDEZ_MNG01 
*----------------------------------------------------------------------*
* Pruefen Mengenaenderung direkt auf Einzelzeile
*----------------------------------------------------------------------*


MODULE CHECK_MDEZ_MNG01.
*--> Menge NULL ist nicht unterstützt
  IF MDEZ-MNG01 EQ 0.
    MESSAGE E212.
  ENDIF.
*--> Bestellvorschlag lesen
  PERFORM GET_EZ_FROM_MDEZ USING CHAR1.
*--> Pruefen Aenderung
  IF MDEZ-MNG01 EQ MDEZS-MNG01.
    EXIT.
  ENDIF.
*--> Dispositionszeile anpassen
  MOVE MDPSS TO MDPS.
*--> Auftrags- und Ausschußmenge anpassen
  AM61X-FLP02 = MDPS-MNG02.
  AM61X-FLP02 = AM61X-FLP02 * MDEZ-MNG01 / MDEZX-MNG01.
  MDPS-MNG02  = AM61X-FLP02.
  MDPS-MNG01  = MDPS-MNG02 + MDEZ-MNG01.
*--> Verarbeitungsstatus setzen
  IF MDPS-VSTAT NE VSTATH.
    MOVE VSTATV TO MDPS-VSTAT.
  ENDIF.
*--> Fixierungskennzeichen setzen
  MOVE XFLAG TO MDPS-FIX01.
*--> Reset Umterminierungsdaten
  PERFORM RESET_MDPS_01.
*--> Setzen Ausnahmemeldung
  PERFORM SET_NEW_AUSSL USING AUSV3 MDPS-AUSSL MDPS-OLDSL.
*--> Preufen Fixierungskennzeichen
  PERFORM CHECK_FIXIERUNGSHORIZONT USING MDPS-FIX01 MDPS-FIX01.
*--> Quotierung ueberpruefen
  PERFORM CHECK_QUOTIERUNG_MDPS.
*--> Dispositionszeile modifizieren
  MOVE MDPS TO MDPSX.
  MODIFY MDPSX INDEX MDPSS-XLINE.
*--> Einzelzeile anpassen
  MOVE MDEZS       TO MDEZX.
  MOVE MDEZ-MNG01  TO MDEZX-MNG01.
*--> Extrakt neu setzen
  PERFORM SET_MDEZX_EXTRA.
*--> Einzelzeile modifizieren
  MODIFY MDEZX INDEX MDEZS-XLINE.
*--> Setzen Merker für Tabellenanpassung
  MOVE XFLAG TO AM61X-FLG01.
ENDMODULE.
