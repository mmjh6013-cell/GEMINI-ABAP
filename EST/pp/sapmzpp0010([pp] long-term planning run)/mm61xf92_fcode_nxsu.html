*----------------------------------------------------------------------*
* FCODE: Nächste Summenzeile anzeigen
*----------------------------------------------------------------------*


FORM FCODE_NXSU.
*--> Zeilenindex für die Tabelle MDSUX ermitteln
  AM61X-ALINE = MDSUS-XLINE + 1.
  IF AM61X-ALINE GT MDSUX-MLINE.
    MESSAGE S112. EXIT.
  ENDIF.
*--> Tabelleneintrag aus MDSUX nachlesen
  READ TABLE MDSUX INDEX MDSUS-XLINE.
  IF SY-SUBRC NE 0.
    MESSAGE E190 WITH MDSUS-XLINE 'MDSUX'.
  ENDIF.
*--> Reset Formatbyte Summenzeile
  MOVE SPACE TO MDSUX-FBYTE.
  MODIFY MDSUX INDEX MDSUS-XLINE.
*--> Tabelleneintrag aus MDSUX nachlesen
  PERFORM SET_MDSU_POSITION_03.
ENDFORM.
