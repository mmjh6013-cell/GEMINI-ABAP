Program listing for: MM61XF58_PICK_UP_SU 
*----------------------------------------------------------------------*
* Summenzeile abpicken
*----------------------------------------------------------------------*


FORM PICK_UP_SU.
  DATA: lv_maybechanged TYPE bool,
        ls_message TYPE messa.                           "note 600940

*--> Return-Code vorbesetzen
  MOVE CHAR1 TO AM61X-RCODE.
*--> Step-Loopzeile ermitteln
MOVE MDCURSOR-LINE TO AM61X-BLINE.                 "Table Control THD40
*  get cursor line am61x-bline.
  IF  AM61X-BLINE EQ 0.
    MESSAGE S112.
    EXIT.
  ENDIF.
*--> Zeilenindex für die Tabelle MDSUX ermitteln
  AM61X-ALINE = MDSUX-XLINE + AM61X-BLINE - 1.
  IF  AM61X-ALINE GT MDSUX-MLINE.
    MESSAGE S112.
    EXIT.
  ENDIF.
*--> Tabelleneintrag aus MDSUX nachlesen
  READ TABLE MDSUX INDEX AM61X-ALINE.
  IF SY-SUBRC NE 0.
    MESSAGE E190 WITH AM61X-ALINE 'MDSUX'.
  ENDIF.
*--> Sichern Index fuer die Summenzeile
  MOVE AM61X-ALINE TO MDSUX-XLINE.
  MOVE AM61X-ALINE TO MDSUS-XLINE.
*--> Pruefen Anzahl Bestellvorschlaege
  IF MDSUX-ANZBV IS INITIAL.
    MESSAGE E111.
  ENDIF.
*--> Bestellvorschlag ermitteln
  PERFORM SELECT_BV_MDEZ.
  IF AM61X-RCODE NE CHAR0.
    EXIT.
  ENDIF.
*--> Returncode vorbesetzen
  MOVE CHAR1 TO AM61X-RCODE.
*--> Einzelzeile sichern
  MOVE MDEZX TO MDEZS.
  MOVE AM61X-ALINE TO MDEZS-XLINE.
*--> Dispositionszeile aus MDPSX nachlesen
  READ TABLE MDPSX INDEX MDEZS-ALINE.
  IF SY-SUBRC NE 0.
    MESSAGE E190 WITH MDEZS-ALINE 'MDPSX'.
  ENDIF.
*--> check changeability (note 600940)
  PERFORM may_be_changed USING    mdpsx
                                  char3
                         CHANGING lv_maybechanged
                                  ls_message.
  IF lv_maybechanged = gc_false.
    mdst-anzei = psi_activ.
    IF ls_message-msgid IS INITIAL
    OR ls_message-msgno IS INITIAL.
      MESSAGE E111.
    ELSE.
      MESSAGE ID     ls_message-msgid
              TYPE   'E'
              NUMBER ls_message-msgno
              WITH   ls_message-msgv1
                     ls_message-msgv2
                     ls_message-msgv3
                     ls_message-msgv4.
    ENDIF.
  ENDIF.
*--> Dispositionszeile sichern
  MOVE MDPSX TO MDPSS.
  MOVE MDEZS-ALINE TO MDPSS-XLINE.
*--> Save-Einzelzeile fuer Summenvergleich
  MOVE MDEZS-PLAAB TO EXEZX-PLAAB.
  MOVE MDEZS-PLANR TO EXEZX-PLANR.
  MOVE MDEZS-DAT00 TO EXEZX-DAT00.
  MOVE MDEZS-MNG01 TO EXEZX-MNG01.
*--> MDSU-Key sichern
  MOVE MDSUX-PLAAB TO SUKEY-PLAAB.
  MOVE MDSUX-PLANR TO SUKEY-PLANR.
  MOVE MDSUX-SORT0 TO SUKEY-SORT0.
*--> Formatbyte Summenzeile setzen
  MOVE CHAR2 TO MDSUX-FBYTE.
  MODIFY MDSUX INDEX MDSUS-XLINE.
*--> Setzen Return-Code
  MOVE CHAR0 TO AM61X-RCODE.
ENDFORM.
