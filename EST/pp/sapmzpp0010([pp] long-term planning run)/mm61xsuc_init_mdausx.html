Program listing for: MM61XSUC_INIT_MDAUSX 
***INCLUDE MM61XSUC.
*---------------------------------------------------------------------*
* Mdausx initialisieren
*---------------------------------------------------------------------*


FORM INIT_MDAUSX TABLES MDAUSX STRUCTURE MDAUS
                 USING  SELAU TYPE C.

  DATA: L_LINES LIKE SY-TABIX.

  CHECK SELAU NE CHARN.
  DESCRIBE TABLE MDAUSX LINES L_LINES.
  IF L_LINES GT 0.
*--> Zähler in Mdausx auf Null setzen
    LOOP AT MDAUSX.
      MDAUSX-OLDAU = 0.
      MDAUSX-NEWAU = 0.
      MODIFY MDAUSX.
    ENDLOOP.
  ENDIF.
ENDFORM.
