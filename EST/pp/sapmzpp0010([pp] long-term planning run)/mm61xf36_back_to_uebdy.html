Program listing for: MM61XF36_BACK_TO_UEBDY 
*----------------------------------------------------------------------*
* Zurueck zur Uebersicht nach Neuaufbau
*----------------------------------------------------------------------*


FORM BACK_TO_UEBDY.
*--> Zuruecksetzen Flag für Statistik-Neuaufbau
  CLEAR MDSTA-KZSTA.
*--> Zuruecksetzen ausgwaehltes Dispoelement
  CLEAR AM61X-DELKZ.
*--> Aufsetzen auf der jeweiligen Liste
  IF MDST-ANZEI EQ PSSI_ACTIV.
    PERFORM ATP_BERECHNEN_MDEZX.
    PERFORM PUT_MDEZX_MDSUX.
    IF MDST-ANZEI = PSSI_ACTIV.
      PERFORM SET_MDSU_POSITION_01 USING XFLAG.
      MOVE MDSUX-ALINE TO MDEZX-XLINE.
      MOVE MDSUX-ALINE TO MDEZX-VLINE.
      MOVE MDSUX-ELINE TO MDEZX-BLINE.
    ELSE.
      PERFORM SET_MDSU_POSITION_01 USING SPACE.
    ENDIF.
  ELSE.
    PERFORM SET_MDEZ_POSITION_01.
  ENDIF.
*--> Back zur Ubersicht
  IF MDST-ANZEI = EZSI_ACTIV       "Einzelzeilen Split Table Contrl
  OR MDST-GROKO = GC_TRUE.
*--> Statistikdaten aktualisieren
    PERFORM MDSTA_AUFBAUEN.
*--> Daten an großen Kopf senden
    PERFORM GROKO_DATA_SEND_COMP.
  ENDIF.
  IF MDST-ANZEI = EZSI_ACTIV.     "Einzelzeilen Split Table Contrl
    MOVE EZI_ACTIV TO MDST-ANZEI.  "Flag für Einzelzeilenscreen setz.
    CLEAR MDST-GROKO.       "Flag für großen Kopf löschen.
    PERFORM SET_EINZ_SCREEN.   "Table Control Einzelzeilen aufbereiten
    SET SCREEN DY-X710.
  ELSEIF MDST-ANZEI = PSSI_ACTIV.
    MOVE EZI_ACTIV TO MDST-ANZEI.  "Flag für Periodensummenscreen setz.
    CLEAR MDST-GROKO.
    PERFORM SET_PERS_SCREEN.   "Table Control Periodensum. aufbereiten
    SET SCREEN DY-X710.
  ENDIF.
ENDFORM.
