Program listing for: MM61XF32_READ_CHECK_MATERIAL_M 
*----------------------------------------------------------------------*
* Lesen und Pruefen Material für die Langfristplanung
*----------------------------------------------------------------------*


FORM READ_CHECK_MATERIAL_ML.
*--> View Materialstamm lesen
  PERFORM READ_MT61D USING CM61D-MATNR CM61D-WERKS CM61D-BERID.
  IF SY-SUBRC NE 0.
    MOVE CHAR1 TO AM61X-RCODE.
    EXIT.
  ENDIF.
*--> PIC : material check for MPN+SUS "{ ENHO AD_MPN_PUR2_SAPMM61X IS-AD-MPN AD_MPN_IC }
  DATA : LV_PIC_RC LIKE AM61X-RCODE. "{ ENHO AD_MPN_PUR2_SAPMM61X IS-AD-MPN AD_MPN_IC }



"{ Begin ENHO AD_MPN_PUR2_SAPMM61X IS-AD-MPN AD_MPN_IC }
PERFORM PIC_MATERIAL_CHECK_BT
                    USING     RM61X MT61D
                    CHANGING  LV_PIC_RC GT_PIC_PARTS[].
  IF LV_PIC_RC NE 0.
    MOVE CHAR1 TO AM61X-RCODE.
    EXIT.
  ENDIF.

"{ End ENHO AD_MPN_PUR2_SAPMM61X IS-AD-MPN AD_MPN_IC }



ENHANCEMENT-POINT READ_CHECK_MATERIAL_ML_01 SPOTS ES_SAPMM61X STATIC.
ENHANCEMENT-POINT READ_CHECK_MATERIAL_ML_02 SPOTS ES_SAPMM61X.
*--> Dispositionsmerkmal ueberpruefen
  PERFORM CHECK_DISMM USING MT61D-DISMM.
  IF AM61X-RCODE NE CHAR0.
    MOVE CHAR1 TO AM61X-RCODE.
    EXIT.
  ENDIF.
*--> Returncode zuruecksetzen
  MOVE CHAR0 TO AM61X-RCODE.
ENDFORM.
