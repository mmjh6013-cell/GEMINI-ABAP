Program listing for: MM61XPSZ_CHECK_PLSC_SUBRC 
*---------------------------------------------------------------------*
*       FORM CHECK_PLSC                                               *
*---------------------------------------------------------------------*
*       mit Fehlermeldung, wenn Werk dem Szenario nicht zugeordnet    *
*---------------------------------------------------------------------*
*  -->  VALUE(WERKS)                                                  *
*  -->  PLSC                                                          *
*---------------------------------------------------------------------*


FORM CHECK_PLSC_SUBRC USING VALUE(WERKS) LIKE PLPT-PLWRK
                      PLSC STRUCTURE PLSC
                      SUBRC LIKE SY-SUBRC.
  CLEAR SUBRC.
  IF PLSC-PSACT <> PSACT_ACTIVE.
    SUBRC = 1.
    EXIT.
  ENDIF.
  IF NOT WERKS IS INITIAL.
    PERFORM SELECT_PLPT_WERKS USING PLSC-PLSCN WERKS SUBRC.
  ENDIF.
ENDFORM.
