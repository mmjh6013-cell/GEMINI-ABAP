Program listing for: MM61XF36_ERSTELLEN_MDPSX_IP 
*----------------------------------------------------------------------*
* MDPSX und MDEZX für interaktive Planung erstellen                    *
*----------------------------------------------------------------------*


FORM ERSTELLEN_MDPSX_IP.
*--> Material für Einzelplanung sperren
  PERFORM SPERREN_MRP_EP USING RM61X-WERKS RM61X-BERID RM61X-MATNR.
*--> Kommunikationsaerea fuer Transaktion erstellen
  PERFORM ERSTELLEN_CM61X.
*--> ATP initialisieren bzw. Puffer deaktivieren, falls CM61X-ATPDA = X
  PERFORM ATP_INITIALIZE.
*--> Initialisieren Steuerleiste und -Tabellen für Zeilenselektion
  PERFORM INIT_SUCHSTEUERUNG.
*--> Statistikleiste initialisieren
  CLEAR MDSTA.
*--> Pruefen RESET-KZ
  PERFORM CHECK_RESET_KZ_EP.
*--> Dispositionstabelle fuer die Anzeige erstellen
  PERFORM READ_MDPSX_INTERACTIV.
*--> Dispositionstabelle anzeigen
  PERFORM SHOW_MDEZX USING CHARC.
ENDFORM.
