Program listing for: MM61XMDV_UPDATE_AKDST 
*&---------------------------------------------------------------------*
*&      Form  UPDATE_AKDST
*&---------------------------------------------------------------------*
*       Einlesen der nächsten Dispostufe der Materialvormerkungen
*----------------------------------------------------------------------*
*  -->  disstx   :   Tabelle mit allen Dispostufen der DBVM
*  <--  akdst    :   neue aktuelle Dispostufe
*----------------------------------------------------------------------*


FORM UPDATE_AKDST TABLES   T_DISSTX
                  CHANGING L_AKDST  LIKE AM61X-DISST
                           L_AKMAT  LIKE AM61X-MATNR
                           RCODE    TYPE C.

  STATICS: DSTINDX TYPE I VALUE '0'.

*--> Initialisierung Dispostufentabelle
  IF DISSTX[] IS INITIAL.
    PERFORM FILL_DISSTX.
    DSTINDX = 1.
*   Initialisierung Zeiger Materialvormerkdatei DBVM
    CLEAR L_AKDST.
    CLEAR L_AKMAT.
  ELSE.
    DSTINDX = DSTINDX + 1.
  ENDIF.

  READ TABLE T_DISSTX INDEX DSTINDX.

  IF SY-SUBRC EQ 0.
*    Aktualisierung von Dispostufe und Zeiger selekt. Material
     MOVE T_DISSTX TO L_AKDST.
     CLEAR L_AKMAT.
  ELSE.
    IF NOT DSTINDX EQ 1.
* Alle Dispostufen bereits geplant
       RCODE = CHAR1.
       EXIT.
    ELSE.
* Planungsvormerkdatei leer
       MESSAGE E315(61).
    ENDIF.
  ENDIF.

ENDFORM.                    " UPDATE_AKDST
