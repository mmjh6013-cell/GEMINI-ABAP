Program listing for: MM61XC02_READ_CHECK_MATERIAL 
*----------------------------------------------------------------------*
* Lesen und Pruefen Material fuer den MRP-/MPS-Planungslauf
*----------------------------------------------------------------------*


FORM READ_CHECK_MATERIAL.
*--> Materialstamm lesen
  PERFORM READ_MT61D USING CM61D-MATNR CM61D-WERKS CM61D-BERID.
  IF SY-SUBRC NE 0.
    PERFORM LOESCHEN_MDVM_BT.
    MOVE CHAR1 TO AM61X-RCODE.
    EXIT.
  ENDIF.
*--> Dispositionsmerkmal ueberpruefen
  PERFORM CHECK_DISMM USING MT61D-DISMM.
  IF AM61X-RCODE NE CHAR0.
    PERFORM LOESCHEN_MDVM_BT.
    MOVE CHAR1 TO AM61X-RCODE.
    EXIT.
  ENDIF.
*--> Dispositionsstufe ueberpruefen
  PERFORM CHECK_DISST USING MT61D-DISST.
  IF AM61X-RCODE NE CHAR0.
    PERFORM DELETE_INSERT_MDVM_BT.
    MOVE CHAR1 TO AM61X-RCODE.
    EXIT.
  ENDIF.
*--> Returncode zuruecksetzen
  MOVE CHAR0 TO AM61X-RCODE.
ENDFORM.
