Program listing for: MM61XF80_CHECK_FIXIERUNGSHORIZ 
*----------------------------------------------------------------------*
* Pruefen Fxierungshorizont                                            *
*----------------------------------------------------------------------*


FORM CHECK_FIXIERUNGSHORIZONT USING I_FIXKZ LIKE MDPS-FIX01
                                    O_FIXKZ LIKE MDPS-FIX01.
*--> Pruefen Fixierungsart
  IF ( CM61M-FXART EQ SPACE
  OR   CM61M-FXART EQ CHAR0 )
  AND  CM61M-MFHKZ IS INITIAL.
    EXIT.
  ENDIF.
*--> Pruefen Dispositionsverfahren
  IF  MDPSX-PLAAB NE NETPLA
  AND MDPSX-PLAAB NE BRTPLA.
    EXIT.
  ENDIF.
*--> Pruefen Fixierungshorizont bei masch. Fixierung
  IF CM61M-FXART EQ CHAR1
  OR CM61M-FXART EQ CHAR2.
    IF MDPSX-DAT00 LT MDKP-FIXTR.      "K11K100298
      MOVE XFLAG TO O_FIXKZ.
    ENDIF.
  ENDIF.
*--> Pruefen man. Fixierungsdatum bei Fixierungsart Space und 0
  IF    ( CM61M-FXART EQ SPACE
  OR      CM61M-FXART EQ CHAR0 )
  AND NOT CM61M-MFHKZ IS INITIAL.
    IF MDPSX-DAT00 LT MDKP-FIXTR.
      MOVE XFLAG TO O_FIXKZ.
    ENDIF.
  ENDIF.
*--> Pruefen Fixierungshorizont bei man. Fixierung
*--> Zusatzlogik raus zu 40A, ersetzt durch moegliche Eingabe eines
*--> manuellen Fixierungsdatums
* IF CM61M-FXART EQ CHAR3
* OR CM61M-FXART EQ CHAR4.
*   IF I_FIXKZ NE XFLAG.
*     EXIT.
*   ENDIF.
*   IF MDPSX-DAT00 GT MDKP-FIXTR.
*     MOVE MDPSX-DAT00 TO MDKP-FIXTR.
*   ENDIF.
* ENDIF.
ENDFORM.
