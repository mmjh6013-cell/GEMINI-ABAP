Program listing for: MM61XF53_INIT_FERTAUFTRAG_VR 
*----------------------------------------------------------------------*
* Fertigungsauftrag für Änderung initialisieren
*----------------------------------------------------------------------*


FORM INIT_FERTAUFTRAG_VR USING RCODE LIKE AM61X-RCODE.
*--> Funktionscode initialisieren
  MOVE CHAR0 TO RCODE.
*--> Auftragsnummer überprüfen
  CLEAR MPFA.
  MOVE MDPSX-DEL12 TO MPFA-AUFNR.
*--> Fertigungsauftrag lesen/initilisieren
  CALL FUNCTION 'CO_EXT_ORDER_INIT'
       EXPORTING  AUFNR_IMP              = MPFA-AUFNR
                  TRTYP_IMP              = 'V'
                  MPFA_IMP               = MPFA
       IMPORTING  MPFA_EXP               = MPFA
       EXCEPTIONS AUTHORITY_CHECK_FAILED = 01
                  NOT_FOUND              = 02
                  WRONG_TRTYP            = 03
                  WRONG_AUART            = 04
                  ENQUEUE_FAILED         = 05.

  IF SY-SUBRC NE 0.
    MOVE CHAR1 TO RCODE.
    IF SY-SUBRC EQ 2.
      MESSAGE ID SY-MSGID TYPE SY-MSGTY NUMBER SY-MSGNO WITH SY-MSGV1.
    ENDIF.
  ENDIF.
ENDFORM.
