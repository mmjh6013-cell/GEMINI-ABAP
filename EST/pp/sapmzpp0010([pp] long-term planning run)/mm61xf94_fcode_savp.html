*----------------------------------------------------------------------*

FORM FCODE_SAVP.
*--> Probelesen Einstellungsdaten
  PERFORM READ_UMD01 USING SY-UNAME T450N-MDAKT.
  IF SY-SUBRC EQ 0.
*--> User-Einstellungen in UMD01 fuellen
    PERFORM UMD01_DATA_FILL.
*--> Update UMD01
    PERFORM UPDATE_UMD01.
  ELSE.
    MOVE SY-UNAME    TO UMD01-UNAME.
    MOVE T450N-MDAKT TO UMD01-MDAKT.
*--> User-Einstellungen in UMD01 fuellen
    PERFORM UMD01_DATA_FILL.
*--> Insert UMD01
    PERFORM INSERT_UMD01.
  ENDIF.
  MESSAGE S565.
*--> Setzen SYNC-Point
  CALL FUNCTION 'DB_COMMIT'.
ENDFORM.
