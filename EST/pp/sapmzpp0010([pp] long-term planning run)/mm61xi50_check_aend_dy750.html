Program listing for: MM61XI50_CHECK_AEND_DY750 
*----------------------------------------------------------------------*
* Pruefen Anpassung MDEZX und MDSUX bei Mengenaenderung
*----------------------------------------------------------------------*


MODULE CHECK_AEND_DY750.
IF MDST-ANZEI NE PSEZSI_ACTIV.
 EXIT.
ENDIF.
*--> Pruefen Aenderungsflag
  IF AM61X-FLG01 EQ SPACE.
    EXIT.
  ENDIF.
*--> EinzelTabelle aktualisieren
  PERFORM MDEZX_AKTUALISIEREN.
*--> ATP-Menge fuer MDEZX neu bestimmen
  PERFORM ATP_BERECHNEN_MDEZX.
*--> Summentabelle neu aufbauen
  PERFORM PUT_MDEZX_MDSUX.
*--> Tabelleneintrag aus MDSUX nachlesen
  READ TABLE MDSUX INDEX MDSUS-XLINE.
  IF SY-SUBRC NE 0.
    MESSAGE E190 WITH AM61X-ALINE 'MDSUX'.
  ENDIF.
*--> Formatbyte Summenzeile setzen
  MOVE CHAR2 TO MDSUX-FBYTE.
  MODIFY MDSUX INDEX MDSUS-XLINE.
*--> Anzeige neu positionieren
  MDSUX-XLINE = MDSUS-XLINE - 1.
  IF MDSUX-XLINE LT 1.
    MDSUX-XLINE = 1.
  ENDIF.
*--> Loopbereich fuer Einzelzeilen definiern
  MOVE MDSUX-ALINE TO MDEZX-XLINE.
  MOVE MDSUX-ALINE TO MDEZX-VLINE.
  MOVE MDSUX-ELINE TO MDEZX-BLINE.

*--> Topline für Einzelzeilen neu setzen
  MOVE MDEZX-XLINE TO TC_EZ-TOP_LINE.

ENDMODULE.
