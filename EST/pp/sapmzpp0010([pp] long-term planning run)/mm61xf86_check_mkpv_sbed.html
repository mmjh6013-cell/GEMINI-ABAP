Program listing for: MM61XF86_CHECK_MKPV_SBED 
*----------------------------------------------------------------------*
* Prüfen Verfügbarkeit der Komponenten
*----------------------------------------------------------------------*


FORM CHECK_MKPV_SBED.
*--> Aktuelle Auflösung ermitteln
  CASE AM61X-DELKZ.
*--> PLanauftrag
  WHEN PLAUF
  OR   SAAUF.
    PERFORM UPDATE_MDPMX_PLAF.
    IF AM61X-RCODE <> CHAR0. MESSAGE I027. EXIT. ENDIF.
*--> Bestellanforderung
  WHEN BSANF.
    PERFORM UPDATE_MDPMX_BSANF.                          "TL 470
    IF AM61X-RCODE <> CHAR0. MESSAGE I027. EXIT. ENDIF.
*--> Ungültiges DELKZ
  WHEN OTHERS.
    MESSAGE A888.
  ENDCASE.
*--> Sekundaerbedarf überprüfen
  DESCRIBE TABLE MDPMX LINES AM61X-ALINE.
  IF AM61X-ALINE = 0.
    MESSAGE I027. EXIT.
  ENDIF.
*--> Verfügbarkeitstabellen erfrischen
  REFRESH MDVAX.
  REFRESH RSNRX.
*--> Sichern aktuelle RSNUM
  DATA: L_RSNUM LIKE RESB-RSNUM.
  IF AM61X-DELKZ EQ PLAUF.
    MOVE MPPA-RSNUM TO L_RSNUM.
  ENDIF.
  IF AM61X-DELKZ EQ BSANF.
    MOVE MPBA-RSNUM TO L_RSNUM.
  ENDIF.
  MOVE L_RSNUM TO RSNRX-RSNUM.
  APPEND RSNRX.
*--> Aktuelle Auflösung übernehmen
  PERFORM UEBERNEHMEN_MDPMX USING CHAR1 L_RSNUM.
*--> Aktuelle MDPMX im Memory sichern (temporär)
  EXPORT MDPMX TO MEMORY ID '$12345678'.
*--> Auflösung für die restlichen Aufträge aktualisieren
  CALL FUNCTION 'MD_AUFLOESUNG_DISPOSITION'
       EXPORTING ECM61X  = CM61X
                 ECM61W  = CM61W
                 ECM61M  = CM61M
                 ECM61B  = CM61B
                 EMT61D  = MT61D
                 ET399D  = T399D
                 EMDKP   = MDKP
                 EEXDEL  = MDPSS-DELKZ  "Exclude akt. Auftrag
                 EEXDNR  = MDPSS-DELNR  "Exclude akt. Auftrag
                 EEXDPS  = MDPSS-DELPS  "Exclude akt. Auftrag
       IMPORTING IMDKP   = MDKP
       TABLES    MDPSX   = MDPSX
                 DQUKX   = EQUKX
                 DQUPX   = EQUPX
       EXCEPTIONS ERROR_MESSAGE = 1.
       IF SY-SUBRC NE 0.
         PERFORM SEND_ERROR_MESSAGE.
       ENDIF.
*--> Die restl. SBED's in VF-Tabelle übernehmen
  LOOP AT MDPSX.
    CHECK NOT MDPSX-RSNUM IS INITIAL.
    IF MDPSX-VSTAT EQ VSTATL.
      MOVE MDPSX-RSNUM TO RSNRX-RSNUM.
      APPEND RSNRX.
    ELSE.
      IF MDPSX-AKTAL EQ XFLAG.
        MOVE MDPSX-RSNUM TO RSNRX-RSNUM.
        APPEND RSNRX.
        PERFORM GET_MDPMX USING MDPSX-RSNUM.
        PERFORM UEBERNEHMEN_MDPMX USING CHAR2 MDPSX-RSNUM.
      ENDIF.
    ENDIF.
  ENDLOOP.
*--> IMPORT aktuelle MDPMX from Memory (temporär)
  IMPORT MDPMX FROM MEMORY ID '$12345678'.
  FREE MEMORY ID '$12345678'.
*--> Verfügbarkeitsprüfung aufrufen
  PERFORM PRUEFUNG_AUFRUFEN USING CHAR2
                                  SPACE
                                  CHAR3
                                  CM61M-FKOBS.
ENDFORM.
