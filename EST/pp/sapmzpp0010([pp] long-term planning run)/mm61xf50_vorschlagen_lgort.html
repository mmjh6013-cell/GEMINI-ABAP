Program listing for: MM61XF50_VORSCHLAGEN_LGORT 
*----------------------------------------------------------------------*
* Lagerort vorschlagen beim Anlegen Bestellvorschlag
*----------------------------------------------------------------------*


FORM VORSCHLAGEN_LGORT CHANGING LGORT LIKE T001L-LGORT.
*--> Zugangslagerort aus Materialstamm setzen
  IF MT61D-BESKZ EQ BESKZE.
    MOVE MT61D-LGPRO TO LGORT.
  ENDIF.
  IF MT61D-BESKZ EQ BESKZF.
    MOVE MT61D-LGFSB TO LGORT.
  ENDIF.
  IF LGORT IS INITIAL.
*--> Lagerort aus Dispobereichs-Cust. setzen  (falls vorhanden)
    MOVE CM61B-ORTZG TO LGORT.
  ENDIF.
ENDFORM.
