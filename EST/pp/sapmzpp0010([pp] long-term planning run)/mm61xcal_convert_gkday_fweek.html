Program listing for: MM61XCAL_CONVERT_GKDAY_FWEEK 
*----------------------------------------------------------------------*
* Kalendertag in Kalenderwoche convertieren                            *
*----------------------------------------------------------------------*


FORM CONVERT_GKDAY_FWEEK USING GKDAY LIKE MDCAL-GKDAY.
CALL FUNCTION 'DATE_GET_WEEK'
     EXPORTING   DATE         = GKDAY
     IMPORTING   WEEK         = MDCAL-FWEEK
     EXCEPTIONS  DATE_INVALID = 01.
     IF SY-SUBRC NE 0.
       MESSAGE ID '61' TYPE 'E' NUMBER '060' WITH GKDAY.
     ENDIF.
ENDFORM.
