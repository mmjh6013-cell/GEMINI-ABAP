FORM READ_UMD01 USING UNAME MDAKT.
*--> Inhalt Workaerea pruefen
  IF  UNAME EQ UMD01-UNAME
  AND MDAKT EQ UMD01-MDAKT.
    SY-SUBRC = 0.
    EXIT.
  ENDIF.
*--> Tabelleneintrag nachlesen
  SELECT SINGLE * FROM  UMD01
                  WHERE UNAME EQ UNAME
                  AND   MDAKT EQ MDAKT.
*--> Returncode wird beim Aufruf geprüft !!!!
  IF SY-SUBRC NE 0.
     MOVE 'UMD01' TO AM61X-TBNAM.
     SET PARAMETER ID 'TAB' FIELD AM61X-TBNAM.
  ELSE.
*   In S/4 only STYPE "detailed scheduling"
    UMD01-STYPE = SCHEDTYPE-FEIN.
  ENDIF.
ENDFORM.
