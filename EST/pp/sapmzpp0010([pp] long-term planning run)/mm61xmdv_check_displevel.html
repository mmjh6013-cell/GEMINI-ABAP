Program listing for: MM61XMDV_CHECK_DISPLEVEL 
*&---------------------------------------------------------------------*
*&      Form  CHECK_DISPLEVEL
*&---------------------------------------------------------------------*
*       Überprüfen der gelesenen Materialvormerkungen
*       auf Dispostufenwechsel
*       (AKDST ändern bzw. Paket schliessen)
*----------------------------------------------------------------------*
*  -->
*  <--  h_rcode    :  Portionsabschluss
*                    ( - Dispostufenwechsel oder
*                      - Portion vollständig aufgefüllt )
*----------------------------------------------------------------------*


FORM CHECK_DISPLEVEL CHANGING H_RCODE   LIKE AM61X-RCODE.
*--> Bei parall. Dispo darf bei Dispostufenwechsel nur gelesen werden,
*--> wenn dieser schon bemerkt wurde (NEW_LEVEL_FLAG)

*--> Initialisierung
  MOVE CHAR0 TO H_RCODE.

  IF AM61X-FLP01 EQ 0.                 "Portions-Paket MDMMX bisher leer
*--> Dispostufen-Wechsel zum Portions-Anfang MDMMX
    IF  RM61X-PARAL = XFLAG
    AND AM61X-DISST GT AM61X-AKDST           "#EC PORTABLE
    AND NEW_LEVEL_FLAG IS INITIAL.
      MOVE CHAR1 TO H_RCODE.
      EXIT.
    ENDIF.
    MOVE AM61X-DISST TO AM61X-AKDST.   "Akt. Dispostufe setzen
                                       "(nur bei Schreiben in MDMMX!)
*
  ELSE.                                "Portions-Paket MDMMX nichtleer
*
*--> Dispostufen-Wechsel mitten in Portion MDMMX
    IF AM61X-DISST GT AM61X-AKDST.    "#EC PORTABLE Dispostufenwechsel
      MOVE CHAR1 TO H_RCODE.           "Neues Paket
      EXIT.                            "initialisieren
    ENDIF.
  ENDIF.

ENDFORM.                               " CHECK_DISPLEVEL
