Program listing for: MM61XMDV_SELECT_MDVL_FOR_LFR 
*---------------------------------------------------------------------*
*       FORM SELECT_MDVL_FOR_LFR                                      *
*---------------------------------------------------------------------*
* Materialvormerkungen fuer den LFR-Planungslauf selektieren          *
*---------------------------------------------------------------------*
*  -->  CM61X  transaction control parameters                  (I)    *
*  -->  CM61D                                                  (I/O)  *
*---------------------------------------------------------------------*


FORM SELECT_MDVL_FOR_LFR.
**--> LOkale Datenfelder
*  DATA: L_MDKEY     LIKE AM61X-MDKEY,
*        L_PORTIONRC LIKE AM61X-RCODE.
**--> Clear Datenbereiche
*  CLEAR AM61X-FLP01.
**--> SET-Key erstellen
*  CALL FUNCTION 'MDVMKEY_AUFBAUEN'
*       EXPORTING
*            MAFID   = CM61X-MDMAF
*            DISST   = CM61D-DISST
*            MATNR   = CM61D-MATNR
*            WERKS   = CM61D-WERKS
*       IMPORTING
*            MDVMKEY = L_MDKEY.
**--> Pruefen Verarbeitungsart
*  CASE CM61X-VRART.
**--> Lesen MDVL bei Neuplanung
*    WHEN NEUVR.
*      SELECT * FROM  MDVL
*               INTO  MDVL
*               WHERE MAFID EQ CM61X-MDMAF
*               AND   PLSCN EQ CM61X-PLSCN
*               AND   MDKEY GT L_MDKEY                "#EC PORTABLE
*               ORDER BY PRIMARY KEY.
**--> Mafid ueberpruefen
*        IF MDVL-MAFID NE CM61X-MDMAF.
*          EXIT.
*        ENDIF.
**--> Materialvormerkung MDMMX uebernehmen
*        PERFORM ADD_MDVL_TO_MDMMX
*                USING    CM61X-WERKS
*                         MDVL
*                CHANGING L_PORTIONRC.
*        IF L_PORTIONRC NE CHAR0.
*          EXIT.
*        ENDIF.
*      ENDSELECT.
**--> Lesen MDVL bei NET_CHANGE-Verarbeitung
*    WHEN NETVR.
*      SELECT * FROM  MDVL
*               INTO  MDVL
*               WHERE MAFID EQ CM61X-MDMAF
*               AND   PLSCN EQ CM61X-PLSCN
*               AND   MDKEY GT L_MDKEY             "#EC PORTABLE
*               AND   GSAEN EQ XFLAG
*               ORDER BY PRIMARY KEY.
**--> Mafid ueberpruefen
*        IF MDVL-MAFID NE CM61X-MDMAF.
*          EXIT.
*        ENDIF.
**--> Materialvormerkung in MDMMX uebernehmen
*        PERFORM ADD_MDVL_TO_MDMMX
*                USING    CM61X-WERKS
*                         MDVL
*                CHANGING L_PORTIONRC.
*        IF L_PORTIONRC NE CHAR0.
*          EXIT.
*        ENDIF.
*      ENDSELECT.
**--> Lesen MDVL bei Kurzfrist-NET-CHANGE-Verarbeitung
*    WHEN NPLVR.
*      SELECT * FROM  MDVL
*               INTO  MDVL
*               WHERE MAFID EQ CM61X-MDMAF
*               AND   PLSCN EQ CM61X-PLSCN
*               AND   MDKEY GT L_MDKEY               "#EC PORTABLE
*               AND   AKKEN EQ XFLAG
*               ORDER BY PRIMARY KEY.
**--> MAFID ueberpruefen
*        IF MDVL-MAFID NE CM61X-MDMAF.
*          EXIT.
*        ENDIF.
**--> Materialvormerkung in MDMMX uebernehmen
*        PERFORM ADD_MDVL_TO_MDMMX
*                USING    CM61X-WERKS
*                         MDVL
*                CHANGING L_PORTIONRC.
*        IF L_PORTIONRC NE CHAR0.
*          EXIT.
*        ENDIF.
*      ENDSELECT.
*    WHEN OTHERS.
*      MESSAGE A051 WITH CM61X-VRART.
*  ENDCASE.
ENDFORM.
