*----------------------------------------------------------------------*
* Prueftabelle T460D lesen
*----------------------------------------------------------------------*


FORM READ_T460D USING OBART LIKE T460D-OBART
                      PAART LIKE T460D-PAART.
*--> Inhalt Workarea ueberpruefen
  IF  OBART EQ T460D-OBART
  AND PAART EQ T460D-PAART.
    SY-SUBRC = 0. EXIT.
  ENDIF.
*--> Tabelleneintrag nachlesen
  SELECT SINGLE * FROM  T460D
                  WHERE OBART = OBART
                  AND   PAART = PAART.
  IF SY-SUBRC NE 0.
    MOVE 'T460D' TO AM61X-TBNAM.
    SET PARAMETER ID 'TAB' FIELD AM61X-TBNAM.
    MESSAGE E001 WITH OBART AM61X-TBNAM.
  ENDIF.
ENDFORM.
