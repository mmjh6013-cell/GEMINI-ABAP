Program listing for: MM61XF53_MPFA_VORBEREITEN 
*----------------------------------------------------------------------*
* MPFA für Auftragsanlage vorbereiten                                  *
*----------------------------------------------------------------------*


FORM MPFA_VORBEREITEN.
*--> Ausgabebereich initialisieren
  CLEAR MPFA.
*--> Auftragsart setzen
  MOVE RM61X-FASCH TO MPFA-AUART.
*--> Materialdaten vorbesetzen
  MOVE MDKP-MATNR  TO MPFA-MATNR.
  MOVE MDKP-PLWRK  TO MPFA-WERKS.
  MOVE MDKP-WEBAZ  TO MPFA-WEBAZ.
*--> Check Unterdeckungsmenge
  IF EXEZX-MNG01 LT 0.
    MPFA-GAMNG = EXEZX-MNG01 * -1.
  ENDIF.
*--> Check Losgroessenparameter
* PERFORM CHECK_MPPA_MENGEN.
*--> Check Unterdeckungstermin
  IF NOT EXEZX-DAT00 IS INITIAL.
    IF MPFA-WEBAZ GT 0.
*--> Umrechnen Unterdeckungstermin
      PERFORM CONVERT_GKDAY_FKDAY_MINUS USING EXEZX-DAT00 CM61W-FABKL.
*--> WEBAZ subtrahieren
      AM61X-SFDAY = MDCAL-FKDAY - MPFA-WEBAZ.
*--> NEW-Endtermin bestimmen
      PERFORM CONVERT_FKDAY_GKDAY USING AM61X-SFDAY CM61W-FABKL.
      MOVE MDCAL-GKDAY TO MPFA-GLTRP.
    ELSE.
      MOVE EXEZX-DAT00 TO MPFA-GLTRP.
    ENDIF.
*--> Starttermin bestimmen
*   PERFORM COMP_PSTTR.
  ENDIF.
ENDFORM.
