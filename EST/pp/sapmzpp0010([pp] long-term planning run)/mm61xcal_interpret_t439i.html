Program listing for: MM61XCAL_INTERPRET_T439I 
*----------------------------------------------------------------------*
* Interpretieren_T439i
*----------------------------------------------------------------------*


FORM INTERPRET_T439I USING IFLAG TYPE C
                           WERKS LIKE MARC-WERKS
                           MRPPK LIKE MARC-MRPPP
                           GKDAY TYPE D
                           PERAZ TYPE P.
*--> Lokale Daten
  DATA: L_PERAZ LIKE MDKP-PERAZ.
  DATA: L_WERKS LIKE MDKP-PLWRK.
*--> Datenbereich clearen
  CLEAR MDCAL.
  CLEAR L_PERAZ.
  MOVE GKDAY TO MDCAL-GKDAY.
*--> Möglicherweise ist der Planungskalender im Referenzwerk definiert
  PERFORM ZUGRIFFSWERK USING WERKS L_WERKS MRPPK.
*--> Tabelle T439I lesen
  SELECT * FROM T439I
           WHERE WERKS EQ L_WERKS
           AND   MRPPP EQ MRPPK
           AND   PPBIS GE GKDAY
  ORDER BY PRIMARY KEY.
*--> Perioden zaehlen
  L_PERAZ = L_PERAZ + 1.
*--> Periodenanfang/PKPER sichern
  IF L_PERAZ = 1.
    MOVE T439I-PPVON TO MDCAL-PRANF.
    MOVE T439I-PPBIS TO MDCAL-PREND.
    MOVE T439I-PPERI TO MDCAL-PRPER+0(3).
  ENDIF.
*--> Periodenende sichern
  IF L_PERAZ = PERAZ.
    MOVE T439I-PPBIS TO MDCAL-PREND.
    EXIT.
  ENDIF.
  ENDSELECT.
*--> Korrekte Ermittlung ueberpruefen
  IF L_PERAZ NE PERAZ.
    IF IFLAG NE SPACE.
      MESSAGE ID '61' TYPE 'E' NUMBER '123' WITH MRPPK.
    ELSE.
      SY-SUBRC = 4.
    ENDIF.
  ENDIF.
ENDFORM.
