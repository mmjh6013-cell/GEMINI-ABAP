Program listing for: MM61XAUS_SUCHTABELLEN_AUFBAUEN 
*---------------------------------------------------------------------*
* Tabelle mit Ausnahmemeldungen und Anzahl neue/alte neu aufbauen     *
*---------------------------------------------------------------------*


FORM SUCHTABELLEN_AUFBAUEN.

  DATA: L_LINES LIKE SY-TABIX,
        L_PLAAB LIKE MDEZ-PLAAB,
        L_PLANR LIKE MDEZ-PLANR.

*--> Mdausx initialisieren
  PERFORM INIT_MDAUSX TABLES MDAUSX USING MASEL_SELAU.
*--> Mddelx initialisieren
  PERFORM INIT_MDDELX TABLES MDDELX USING MASEL_SELDA.
*--> Mdausx initialisieren
* IF MASEL_SELAU NE CHARN.
*   DESCRIBE TABLE MDAUSX LINES L_LINES.
*   IF L_LINES GT 0.
*--> Zähler in Mdausx auf Null setzen
*     LOOP AT MDAUSX.
*       MDAUSX-OLDAU = 0.
*       MDAUSX-NEWAU = 0.
*       MODIFY MDAUSX.
*     ENDLOOP.
*   ENDIF.
* ENDIF.
*--> Mddelx initialisieren
* IF MASEL_SELDA NE CHARN.
*   DESCRIBE TABLE MDDELX LINES L_LINES.
*   IF L_LINES GT 0.
*--> Zähler in Mdausx auf Null setzen
*     LOOP AT MDDELX.
*       CLEAR MDDELX-DAT00.
*       CLEAR MDDELX-DAT01.
*       MODIFY MDDELX.
*     ENDLOOP.
*   ENDIF.
* ENDIF.
*--> Tabelle für Kundeneinzelabschnitte initialisieren
  CLEAR MDKDAX. REFRESH MDKDAX.
*--> Tabelle für Projekteinzelabschnitte initialisieren
  CLEAR MDPROX. REFRESH MDPROX.
*--> Tabelle für Lagerortlabschnitte initialisieren
  CLEAR MDLORX. REFRESH MDLORX.
*--> Tabelle für Chargenabschnitte initialisieren
  CLEAR MDCHAX. REFRESH MDCHAX.
*--> Tabelle für Chargen/Lagerortabschnitte initialisieren
  CLEAR MDCHLX. REFRESH MDCHLX.
*--> Merkfeld 'Keine verschiedenen Abschnitte' setzen
  MOVE CHARN TO MASEL_VSABS.
  READ TABLE MDEZX INDEX 1.
  MOVE MDEZX-PLAAB TO L_PLAAB.
  MOVE MDEZX-PLANR TO L_PLANR.

*--> Loop über MDEZX
  LOOP AT MDEZX.
*--> Kennzeichen 'verschiedene Abschnitte vorhanden' versorgen
    IF L_PLAAB NE MDEZX-PLAAB
    OR L_PLANR NE MDEZX-PLANR.
      CLEAR MASEL_VSABS.
    ENDIF.
    MOVE MDEZX-PLAAB TO L_PLAAB.
    MOVE MDEZX-PLANR TO L_PLANR.
*--> Neuer Kundenabschnitt ?
    IF  MDEZX-PLAAB EQ KNDPLA
    AND MDEZX-DELKZ EQ KDBST.
      MOVE MDEZX-PLANR(16) TO MDKDAX.
      APPEND MDKDAX.
    ENDIF.
*--> Neuer Projektabschnitt ?
    IF  MDEZX-PLAAB EQ PROPLA
    AND MDEZX-DELKZ EQ PRBST.
      MOVE  MDEZX-PLANR TO PLAPR.
      MOVE  PLAPR-PSPEL TO MDPROX-PSPEL.
      WRITE MDPROX-PSPEL TO MDPROX-PRANR.
      APPEND MDPROX.
    ENDIF.
*--> Neuer Lagerortabschnitt ?
    IF (   MDEZX-PLAAB EQ LAGERPR
        OR MDEZX-PLAAB EQ LGODS1
        OR MDEZX-PLAAB EQ LGODS2 )
    AND MDEZX-DELKZ EQ LGBST.
      MOVE MDEZX-PLANR TO PLALG.
      MOVE PLALG-LGORT TO MDLORX-LGORT.
      APPEND MDLORX.
    ENDIF.
*--> Neuer Chargenabschnitt ?
    IF  MDEZX-PLAAB EQ CHARGPR
    AND MDEZX-DELKZ EQ CHBST.
      MOVE MDEZX-PLANR TO PLACH.
      MOVE PLACH-CHARG TO MDCHAX-CHARG.
      APPEND MDCHAX.
    ENDIF.
*--> Neuer Chargen/Lagerortabschnitt ?
    IF  MDEZX-PLAAB EQ CHALGPR
    AND MDEZX-DELKZ EQ LCBST.
      MOVE MDEZX-PLANR TO PCHLG.
      MOVE PCHLG-LGORT TO MDCHLX-LGORT.
      MOVE PCHLG-CHARG TO MDCHLX-CHARG.
      APPEND MDCHLX.
    ENDIF.
*--> Zeile Ausnahmentabelle anpassen
    PERFORM BUILD_SINGLE_MDAUSX
                         TABLES MDAUSX
                         USING  MASEL_SELAU MDEZX-AUSSL
                                MDEZX-ABEKZ MDEZX-SELKZ.
*--> Zeile Delkztabelle anpassen
    PERFORM BUILD_SINGLE_MDDELX
                         TABLES MDDELX
                         USING  MASEL_SELDA MDEZX-DELKZ MDEZX-SORT0.
  ENDLOOP.
*--> Abschließen Suchtabellen
  PERFORM ABSCHLIESSEN_MDAUSX TABLES MDAUSX.
  PERFORM ABSCHLIESSEN_MDDELX TABLES MDDELX.
*--> Zeilen von Mdausx, bei denen keine Ausn. gezählt wurden, löschen
* LOOP AT MDAUSX
*      WHERE OLDAU = 0
*      AND   NEWAU = 0.
*   DELETE MDAUSX.
* ENDLOOP.
*--> Mddelx-Zeilen ohne Datum (nicht mehr da) löschen
* LOOP AT MDDELX
*      WHERE DAT00 IS INITIAL
*      AND   DAT01 IS INITIAL.
*   DELETE MDDELX.
* ENDLOOP.
*--> Für Suche vorgesehene Delkzs vorhanden? Nur dann Suche nach Datum
  DESCRIBE TABLE MDDELX LINES L_LINES.
  IF L_LINES LE 0.
    MOVE CHARN TO MASEL_SELDA.
  ENDIF.

ENDFORM.
