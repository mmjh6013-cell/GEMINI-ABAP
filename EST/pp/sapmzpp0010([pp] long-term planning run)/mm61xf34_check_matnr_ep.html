Program listing for: MM61XF34_CHECK_MATNR_EP 
*----------------------------------------------------------------------*
* Prüfen Materialstamm bei Einzelplanung
*----------------------------------------------------------------------*


FORM CHECK_MATNR_EP.
*--> Materialstamm (und Dispobereich) lesen, E-Meldungen
  PERFORM READ_MT61D_DIALOG USING RM61X-MATNR RM61X-WERKS RM61X-BERID.
  MOVE MT61D-DISST TO RM61X-DISST.
  MOVE MT61D-MAKTX TO RM61X-TXMAT.
*--> Prüfen Produktgruppenkennzeichen
  IF MT61D-KZGRP NE SPACE.
    MOVE XFLAG TO RM61X-PRGKZ.
    MESSAGE E680 WITH RM61X-MATNR RM61X-WERKS.
  ENDIF.
*--> Prüfen Loeschvormerkung
  IF MT61D-LVORM NE SPACE.
    MESSAGE E403 WITH RM61X-MATNR RM61X-WERKS.
  ENDIF.
*--> Sichern aktuelles Material
  CLEAR CM61D.
  MOVE RM61X-MATNR TO CM61D-MATNR.
  MOVE RM61X-WERKS TO CM61D-WERKS.
  MOVE RM61X-DISST TO CM61D-DISST.
  MOVE RM61X-BERID TO CM61D-BERID.
*--> Authority-Check
  PERFORM CHECK_AUTHORITY_D_01                         "
          USING T450N-MDAKT T450N-MDATY MT61D-WERKS MT61D-DISPO.
*--> Dispositionsmerkmal ueberpruefen
  PERFORM CHECK_DISMM USING MT61D-DISMM.
  IF AM61X-RCODE EQ CHAR1.
    MESSAGE E008 WITH MT61D-MATNR MT61D-WERKS RM61X-BERID.
  ENDIF.
*--> Dispositionsverfahren ueberpruefen
  PERFORM CHECK_DISVF.
*--> Materialstatus ueberpruefen (allgemein)
  PERFORM CHECK_MMSTA_OL USING MT61D-MSTAE MT61D-MATNR MT61D-MSTDE.
*--> Materialstatus ueberpruefen (Werk)
  PERFORM CHECK_MMSTA_OL USING MT61D-MMSTA MT61D-MATNR MT61D-MMSTD.
ENDFORM.
