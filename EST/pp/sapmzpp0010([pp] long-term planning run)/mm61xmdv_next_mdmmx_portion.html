Program listing for: MM61XMDV_NEXT_MDMMX_PORTION 
*---------------------------------------------------------------------*
*       FORM NEXT_MDMMX_PORTION                                       *
*---------------------------------------------------------------------*
*       Paketbildung für RFCs :                                       *
*       -  Transfer MDMMX --> CM61D_TAB                               *
*       -  Pakete der Grösse TSIZE                                    *
*---------------------------------------------------------------------*
*  -->  TSIZE     Portion size (# materials per task) (I)             *
*  <--> TINDX     Current Index on MDMMX   (I/O)                      *
*  <--> NEW_LEVEL_FLAG  Indicator for change of low-level-code (I/O)  *
*---------------------------------------------------------------------*


FORM next_mdmmx_portion USING
                          tsize          TYPE i
                        CHANGING
                          tindx          TYPE i
                          new_level_flag LIKE am61x-flg01.

  IF new_level_flag EQ xflag.
*-->  Materialvormerkungen selektieren (MDMMX auffuellen)
    PERFORM mdmmx_fill.
    tindx = 1.
    CLEAR new_level_flag.
  ENDIF.

*--> Nichts mehr zu Dstufe und Werk gefunden
  IF mdmmx[] IS INITIAL.
    new_level_flag = xflag.
    EXIT.
  ENDIF.

*--> Initialisierung für Materialvergleich
  CLEAR mdmmx-matnr.

*--> AUFBAU DER RFC-PAKETE PLANUNG
  PERFORM fill_cm61dtab_from_mdmmx
          using    tsize
          CHANGING tindx
                   new_level_flag.

*--> Anzeigefeld 'DispoStufe' fuellen (Jobübersicht)
  rm61x-disst = cm61d-disst.

ENDFORM.                    "NEXT_MDMMX_PORTION
