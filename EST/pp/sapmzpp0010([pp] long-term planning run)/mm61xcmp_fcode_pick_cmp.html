*---------------------------------------------------------------------*
*       FORM FCODE_PICK_CMP                                           *
*---------------------------------------------------------------------*
* Auswaehlen einer Periode zur Einzelanzeige                           *
*---------------------------------------------------------------------*
*  -->  EFLAG  error flag ( 0 = ok )                                  *
*  -->  MINDX  index of selected period in MDAGX                      *
*---------------------------------------------------------------------*


FORM fcode_pick_cmp USING eflag mindx.
  DATA: fname LIKE am61r-fname,
        cline LIKE sy-tabix.
*
  CLEAR eflag.
*--> Cursorposition ermitteln
  MOVE mdcursor-fname_ps TO fname.
  MOVE mdcursor-line_ps TO cline.
*  get cursor field fname line cline.
  IF cline = 0.
    eflag = xflag.
    EXIT.
  ENDIF.
*--> Index in Vergleichstabelle ermitteln
  mindx = tc_cp-top_line + cline - 1.
  IF mindx GT tc_cp-lines.
    eflag = xflag.
    EXIT.
  ENDIF.

  READ TABLE mdagx INDEX mindx.
  MOVE mdagx-vlina TO mdezx-vline.
  MOVE mdagx-blina TO mdezx-bline.
ENDFORM.                    "FCODE_PICK_CMP
