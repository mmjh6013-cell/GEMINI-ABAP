Program listing for: MM61XCAL_COMPUTE_GKDAY_WOTAG 
*----------------------------------------------------------------------*
* Compute Kalenderdatum in Wochentag
*----------------------------------------------------------------------*


FORM COMPUTE_GKDAY_WOTAG USING GKDAY LIKE MDCAL-GKDAY.
CALL FUNCTION 'DATE_COMPUTE_DAY'
     EXPORTING   DATE         = GKDAY
     IMPORTING   DAY          = MDCAL-WOTAG.
ENDFORM.
