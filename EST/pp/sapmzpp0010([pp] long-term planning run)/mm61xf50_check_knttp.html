Program listing for: MM61XF50_CHECK_KNTTP 
*----------------------------------------------------------------------*
* Pruefen Kontierung
*----------------------------------------------------------------------*


FORM CHECK_KNTTP.
*--> Retruncode vorbesetzen
  MOVE CHAR0 TO AM61X-RCODE.
*--> Kontierungstyp ueberpruefen
  IF RM61X-KNTTP EQ SPACE.
    PERFORM CLEAR_KNTTP.
    MOVE CHAR1 TO AM61X-RCODE.
  ENDIF.
*--> Kontierungsfaehigkeit ueberpruefen
  IF T460P-KZEKN EQ OPTMI
  OR T460P-KZPKN EQ OPTMI.
    MESSAGE S145.
    EXIT.
  ENDIF.
*--> Kontierungstyp nachlesen
  PERFORM READ_T163K USING RM61X-KNTTP.
*--> Kundeneinzelfertigung
  IF T163K-SOBKZ EQ SOBKZE.
    MOVE T163K-SOBKZ TO RM61X-SOBKZ. "Kontierungkennzeichen
    MOVE T163K-KZVBR TO RM61X-KZVBR.
    EXIT.
  ENDIF.
*--> Projekteinzelfertigung
  IF T163K-SOBKZ EQ SOBKZQ.
    MOVE T163K-SOBKZ TO RM61X-SOBKZ. "Kontierungskennzeichen
    MOVE T163K-KZVBR TO RM61X-KZVBR.
    EXIT.
  ENDIF.
*--> Unbekannte Kontierung ueberpruefen
  IF  T163K-SOBKZ EQ SPACE
  AND T163K-KZVBR EQ KZVBRU.
    IF  ( MT61D-WERTU EQ SPACE                  "unbewertetes Mat
       OR MPBA-SOBKZ  NE SPACE ).               "Sonderbestand
      MOVE T163K-SOBKZ TO RM61X-SOBKZ.
      MOVE T163K-KZVBR TO RM61X-KZVBR.
    ELSE.
      MESSAGE E143 WITH RM61X-KNTTP.
    ENDIF.
    EXIT.
  ENDIF.
*--> Ungueltiger Kontierungstyp
  MESSAGE E143 WITH RM61X-KNTTP.
ENDFORM.
