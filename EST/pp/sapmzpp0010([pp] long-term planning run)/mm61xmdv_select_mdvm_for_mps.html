Program listing for: MM61XMDV_SELECT_MDVM_FOR_MPS 
*---------------------------------------------------------------------*
*       FORM SELECT_MDVM_FOR_MPS                                      *
*---------------------------------------------------------------------*
*       Materialvormerkungen fuer den MPS-Planungslauf selektieren    *
*---------------------------------------------------------------------*
*  -->  CM61X  transaction control parameters                  (I)    *
*  -->  CM61D                                                  (I/O)  *
*---------------------------------------------------------------------*


FORM SELECT_MDVM_FOR_MPS.
**--> Lokale Datenfelder
*  DATA: PORTION_RC  LIKE AM61X-RCODE.
*
**--> Clear Datenbereiche
*  CLEAR AM61X-FLP01.
**--> SET-Key erstellen
*  CALL FUNCTION 'MDVMKEY_AUFBAUEN'
*       EXPORTING
*            MAFID   = CM61X-MDMAF
*            DISST   = CM61D-DISST
*            MATNR   = CM61D-MATNR
*            WERKS   = CM61D-WERKS
*       IMPORTING
*            MDVMKEY = AM61X-MDKEY.
*
**--> Pruefen Verarbeitungsart
*  CASE CM61X-VRART.
**--> Lesen MDVM bei Neuplanung
*    WHEN NEUVR.
*      SELECT * FROM  MDVM
*               INTO  MDVM
*               WHERE MAFID EQ CM61X-MDMAF
*               AND   MDKEY GT AM61X-MDKEY              "#EC PORTABLE
*               AND   MPSKZ EQ XFLAG
*               ORDER BY PRIMARY KEY.
**--> Materialvormerkung MDMMX uebernehmen
*        PERFORM ADD_MDVM_TO_MDMMX
*                USING    CM61X-WERKS
*                         MDVM
*                CHANGING PORTION_RC.
*        IF PORTION_RC NE CHAR0.
*          EXIT.
*        ENDIF.
*      ENDSELECT.
**--> Lesen MDVM bei NET_CHANGE-Verarbeitung
*    WHEN NETVR.
*      SELECT * FROM  MDVM
*               INTO  MDVM
*               WHERE MAFID EQ CM61X-MDMAF
*               AND   MDKEY GT AM61X-MDKEY              "#EC PORTABLE
*               AND   MPSKZ EQ XFLAG
*               AND ( GSAEN EQ XFLAG OR
*                   ( RHYTD GT DATUMU AND RHYTD LE CM61X-DISPD ) )
*               ORDER BY PRIMARY KEY.
**--> Materialvormerkung in MDMMX uebernehmen
*        PERFORM ADD_MDVM_TO_MDMMX
*                USING    CM61X-WERKS
*                         MDVM
*                CHANGING PORTION_RC.
*        IF PORTION_RC NE CHAR0.
*          EXIT.
*        ENDIF.
*      ENDSELECT.
**--> Lesen MDVM bei Kurzfrist-NET-CHANGE-Verarbeitung
*    WHEN NPLVR.
*      SELECT * FROM  MDVM
*               INTO  MDVM
*               WHERE MAFID EQ CM61X-MDMAF
*               AND   MDKEY GT AM61X-MDKEY              "#EC PORTABLE
*               AND   MPSKZ EQ XFLAG
*               AND ( AKKEN EQ XFLAG OR
*                   ( RHYTD GT DATUMU AND RHYTD LE CM61X-DISPD ) )
*               ORDER BY PRIMARY KEY.
**--> Materialvormerkung in MDMMX uebernehmen
*        PERFORM ADD_MDVM_TO_MDMMX
*                USING    CM61X-WERKS
*                         MDVM
*                CHANGING PORTION_RC.
*        IF PORTION_RC NE CHAR0.
*          EXIT.
*        ENDIF.
*      ENDSELECT.
*    WHEN OTHERS.
*      MESSAGE A051 WITH CM61X-VRART.
*  ENDCASE.
ENDFORM.
