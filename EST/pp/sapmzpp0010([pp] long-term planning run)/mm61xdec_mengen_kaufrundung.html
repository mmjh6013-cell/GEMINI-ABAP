Program listing for: MM61XDEC_MENGEN_KAUFRUNDUNG 
*----------------------------------------------------------------------*
* Dezimalstellenrundung fuer Mengen (Menge wird kaufm. gerundet)       *
*----------------------------------------------------------------------*


FORM MENGEN_KAUFRUNDUNG USING ANDEC MNGXX.
*--> Lokale Daten
DATA: MNG01 LIKE AM61X-MNG01.
*--> Anzahl Dezimalstellen pruefen und entsprechend runden

CASE ANDEC.
  WHEN 3.
    EXIT.

  WHEN 2.
    IF MNGXX GT 9999999999990.
      MNGXX = 9999999999990.
      EXIT.
    ENDIF.
    MNG01 = MNGXX / 10.
    MNG01 = MNG01 * 10.
    MNGXX = MNG01.

  WHEN 1.
    IF MNGXX GT 9999999999900.
      MNGXX = 9999999999900.
      EXIT.
    ENDIF.
    MNG01 = MNGXX / 100.
    MNG01 = MNG01 * 100.
    MNGXX = MNG01.

  WHEN 0.
    IF MNGXX GT 9999999999000.
      MNGXX = 9999999999000.
      EXIT.
    ENDIF.
    MNG01 = MNGXX / 1000.
    MNG01 = MNG01 * 1000.
    MNGXX = MNG01.
  ENDCASE.

ENDFORM.
