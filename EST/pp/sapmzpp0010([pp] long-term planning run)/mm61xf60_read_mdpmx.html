Program listing for: MM61XF60_READ_MDPMX 
*----------------------------------------------------------------------*
* Aufloesungstabelle lesen
*----------------------------------------------------------------------*


FORM READ_MDPMX USING RSNUM LIKE RESB-RSNUM.
*--> Komponententabellen erfrischen
  CLEAR   MDPMX.
  REFRESH MDPMX.
  CLEAR   MDPML.
  REFRESH MDPML.
*--> Aufloesungstabelle von der Datenbank holen
  IF CM61X-PLSCN IS INITIAL.              "operativer SekBedarf
    CALL FUNCTION 'MD_LESEN_KOMPONENTEN_RSNUM'
         EXPORTING RSNUM = RSNUM
         TABLES    MDPMX = MDPMX.
  ELSE.                                   "simulativer SekBedarf
    CALL FUNCTION 'MD_LESEN_KOMPONENTEN_RSNUM'
         EXPORTING SBNUM = RSNUM
         TABLES    MDPMX = MDPMX.
  ENDIF.
*--> Aufloesungsergebnis pruefen
  DESCRIBE TABLE MDPMX LINES AM61X-ALINE.
  IF AM61X-ALINE GT 0.
    MOVE CHAR0 TO AM61X-RCODE.
  ELSE.
    MOVE CHAR1 TO AM61X-RCODE.
  ENDIF.
ENDFORM.
