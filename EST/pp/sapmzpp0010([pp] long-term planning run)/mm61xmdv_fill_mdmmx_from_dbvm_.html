Program listing for: MM61XMDV_FILL_MDMMX_FROM_DBVM_ 
*&---------------------------------------------------------------------*
*&      Form  FILL_MDMMX_FROM_DBVM_DBVL
*&---------------------------------------------------------------------*
*       Einlesen MDMMX bei Dispobereichs-Planung über DBVM/DBVL
*----------------------------------------------------------------------*
*  -->  DBVM / DBVL
*  <--  MDMMX
*----------------------------------------------------------------------*


FORM FILL_MDMMX_FROM_DBVM_DBVL.

DATA:    DONE_FLAG TYPE C,                    "Flag: Planung fertig
         NLINE TYPE I.                        "Zähler MDMMX-Einträge

*--> Initialisierung Returncode Planungsende
  MOVE CHAR0 TO DONE_FLAG.

*--> Ändern Dispostufe, falls letztes Paket nicht voll
  IF DISSTX[] IS INITIAL.
     PERFORM UPDATE_AKDST TABLES   DISSTX
                          CHANGING P_DBVM-DISST
                                   P_DBVM-MATNR
                                   DONE_FLAG.
  ENDIF.

*--> Paketaufbau MDMMX und RFC-Level-Flag
*--> (nächste nichtleere Dispostufe)
  DO.

*--> Auswahl der Materialvormerkungen über DBVM
    IF     CM61X-PLAUF EQ MRPPL.
      PERFORM SELECT_DBVM_FOR_MRP.     " USING Zeiger P_DBVM.
    ELSEIF CM61X-PLAUF EQ MPSPL.
      IF CM61X-ICMRP EQ XFLAG.
        PERFORM SELECT_DBVM_FOR_GES.   " USING Zeiger P_DBVM.
      ELSE.
        PERFORM SELECT_DBVM_FOR_MPS.   " USING Zeiger P_DBVM.
      ENDIF.
    ELSEIF CM61X-PLAUF EQ LFRPL.
      PERFORM SELECT_DBVL_FOR_LFR.     " USING Zeiger P_DBVM.
    ELSE.
      MESSAGE A050.
    ENDIF.

*--> Paketübergabe MDMMX und Dispostufenwechsel
*   Nichtleeres Paket zum Planen schicken oder
*   bei paralleler Planung leeres Paket bei Dispostufenwechsel,
*   falls dieser noch nicht bemerkt wurde (für RFC-Synchro)

*--> Vormerkungspaket zur Dispostufe gefüllt
    IF NOT MDMMX[] IS INITIAL.
       EXIT.
*--> selektiertes Vormerkungspaket leer und
    ELSE.
*-->  Dispostufenwechsel
      PERFORM UPDATE_AKDST TABLES   DISSTX
                           CHANGING P_DBVM-DISST
                                    P_DBVM-MATNR
                                    DONE_FLAG.
*-->  Check: Alle Dispostufen geplant
      IF DONE_FLAG EQ CHAR1.
         EXIT.
      ENDIF.
*-->  Parallelverarbeitung Planungslauf
      IF NOT RM61X-PARAL IS INITIAL
      AND NEW_LEVEL_FLAG IS INITIAL.
        EXIT.
      ENDIF.

    ENDIF.                                       "mdmmx[]

  ENDDO.

ENDFORM.                               " FILL_MDMMX_FROM_DBVM_DBVL
