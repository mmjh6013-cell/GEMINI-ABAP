Program listing for: MM61XF86_ADD_AUSSCHUSS 
*----------------------------------------------------------------------*
* Baugruppenausschuss dazurechnen                                      *
* Feldverwendung: AM61X-MNG01 = Auftragsmenge                          *
*                 AM61X-MNG02 = Ausschussmenge                         *
*----------------------------------------------------------------------*


FORM ADD_AUSSCHUSS USING BESKZ.
*--> Pruefen Beschaffungskennzeichen
  IF BESKZ EQ BESKZF.
    EXIT.
  ENDIF.
*--> Pruefen Baugruppenauschuss
  IF MT61D-AUSSS LT 0.
    EXIT.
  ENDIF.
*--> Ausschussmenge bestimmen
  AM61X-FLP01 = AM61X-MNG01.
  AM61X-FLP01 = AM61X-FLP01 * MT61D-AUSSS.
  AM61X-FLP01 = AM61X-FLP01 / 10000.
  AM61X-MNG02 = AM61X-FLP01.
*--> Ausschussmenge runden
  PERFORM MENGEN_AUFRUNDUNG USING CM61M-ANDEC AM61X-MNG02.
*--> Auftragsmenge erhoehen
  AM61X-FLP01 = AM61X-MNG01 + AM61X-MNG02.
  AM61X-MNG01 = AM61X-FLP01.
ENDFORM.
