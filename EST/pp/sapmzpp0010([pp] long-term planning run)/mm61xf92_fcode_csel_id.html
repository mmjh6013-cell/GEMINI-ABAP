Program listing for: MM61XF92_FCODE_CSEL_ID 
*----------------------------------------------------------------------*
* FCODE: Bestellvorschlag aus Uebersicht auswaehlen
*----------------------------------------------------------------------*


FORM FCODE_CSEL_ID.
*--> Return-Code vorbesetzen
  MOVE CHAR1 TO AM61X-RCODE.
*--> Step-Loopzeile ermitteln
  GET CURSOR LINE AM61X-BLINE.
  IF  AM61X-BLINE EQ 0.
    MESSAGE S112.
    EXIT.
  ENDIF.
*--> Zeilenindex für die Tabelle MDIDX ermitteln
  AM61X-ALINE = MDIDX-XLINE + AM61X-BLINE - 1.
  IF  AM61X-ALINE GT AM61X-MLINE.
    MESSAGE S112.
    EXIT.
  ENDIF.
*--> Tabelleneintrag aus MDIDX nachlesen
  READ TABLE MDIDX INDEX AM61X-ALINE.
  IF SY-SUBRC NE 0.
    MESSAGE E190 WITH AM61X-ALINE 'MDIDX'.
  ENDIF.
*--> Tabelleneintrag aus MDEZX nachlesen
  MOVE MDIDX-ILINE TO AM61X-ALINE.
  READ TABLE MDEZX INDEX AM61X-ALINE.
  IF SY-SUBRC NE 0.
    MESSAGE E190 WITH AM61X-ALINE 'MDEZX'.
  ENDIF.
*--> Return-Code setzen
  MOVE CHAR0 TO AM61X-RCODE.
ENDFORM.
