Program listing for: MM61XF86_SUB_AUSSCHUSS 
*----------------------------------------------------------------------*
* Baugruppenausschuss bestimmen                                        *
* Feldverwendung: AM61X-MNG01 = Auftragsmenge                          *
*                 AM61X-MNG02 = Ausschussmenge                         *
*----------------------------------------------------------------------*


FORM SUB_AUSSCHUSS USING BESKZ FLG01.
*--> Pruefen Beschaffungskennzeichen
  IF BESKZ EQ BESKZF.
    EXIT.
  ENDIF.
*--> Pruefen Bearb.Kennzeichen
  IF FLG01 NE XFLAG.
    EXIT.
  ENDIF.
*--> Pruefen Baugruppenauschuss
  IF MT61D-AUSSS LT 0.
    EXIT.
  ENDIF.
*--> Ausschussmenge neu bestimmen
  AM61X-FLP01 = MT61D-AUSSS.
  AM61X-FLP01 = AM61X-FLP01 + 10000.
  AM61X-FLP02 = AM61X-MNG01.
  AM61X-FLP02 = AM61X-FLP02 * MT61D-AUSSS.
  AM61X-FLP02 = AM61X-FLP02 / AM61X-FLP01.
  AM61X-MNG02 = AM61X-FLP02.
*--> Ausschussmenge runden
  PERFORM MENGEN_AUFRUNDUNG USING CM61M-ANDEC AM61X-MNG02.
ENDFORM.
