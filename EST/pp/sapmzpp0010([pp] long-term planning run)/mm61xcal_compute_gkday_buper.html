Program listing for: MM61XCAL_COMPUTE_GKDAY_BUPER 
*----------------------------------------------------------------------*
* Compute Periodenende/Periodenanfang nach T009B (BUPER)
*----------------------------------------------------------------------*


FORM COMPUTE_GKDAY_BUPER USING PERIV LIKE T009-PERIV
                               GKDAY LIKE MDCAL-GKDAY
                               PERAZ TYPE P.
*--> Periodentabelle
DATA: BEGIN OF PPERX OCCURS 12.
        INCLUDE STRUCTURE PPER.
DATA: END OF PPERX.
*--> Ausgabebereich clearen
  CLEAR MDCAL.
  MOVE GKDAY TO MDCAL-GKDAY.
*--> Aktuelle Periode ermitteln
  CALL FUNCTION 'PROGNOSEPERIODEN_ERMITTELN'
                 EXPORTING  EANZPR = PERAZ
                            EDATUM = GKDAY
                            EPERIV = PERIV
                 TABLES     PPERX  = PPERX
                 EXCEPTIONS T009B_FEHLERHAFT    = 01
                            T009_NICHT_GEFUNDEN = 02.
  CASE SY-SUBRC.
    WHEN 01.
      MESSAGE ID '61' TYPE 'E' NUMBER '118'.              "note 3571319
    WHEN 02.
      MESSAGE ID '61' TYPE 'E' NUMBER '116'.
  ENDCASE.
*--> Periodenanfang/Periodenende/BUPER ermitteln
  READ TABLE PPERX INDEX 1.
  MOVE PPERX-VONTG TO MDCAL-PRANF.
  MOVE PPERX-BISTG TO MDCAL-PREND.
  MOVE PPERX-PRPER TO MDCAL-PRPER.
*--> Periodenende verschieben
  IF PERAZ GT 1.
    READ TABLE PPERX INDEX PERAZ.
    MOVE PPERX-BISTG TO MDCAL-PREND.                "P30K042701
  ENDIF.
ENDFORM.
