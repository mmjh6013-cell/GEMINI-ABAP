Program listing for: MM61XF98_DELETE_CAPACITY_REQ 
*----------------------------------------------------------------------*
* Wenn der Bestellvorschlag (hier nur Planauftrag) nicht übernommen
* wird, muessen eventuell vorhandene Kapa-Bedarfe aus der Kapa-Situation
* geloescht werden.
*----------------------------------------------------------------------*


FORM DELETE_CAPACITY_REQ.
*--> Aktion nur bei Planauftrag
  CHECK NOT MPPA-PLNUM IS INITIAL.
*--> Sind für den neu hinzugefügten Planauftrag Terminierungsdaten
*--> vorhanden ?
  IF ( NOT MPPA-TRMER IS INITIAL )
  OR ( NOT MPPA-RATER IS INITIAL )
  OR ( NOT MPPA-GROER IS INITIAL ).
*--> Wenn ja, dann loesche die Kapa-Bedarfe aus der Kapa-Sitaution
    PERFORM MPS_CAPACITY_DEL_PLAF USING MPPA-PLNUM.
  ENDIF.
ENDFORM.
