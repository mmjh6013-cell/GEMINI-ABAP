FORM DISPATCHER CHANGING PLANNING_FINISHED LIKE AM61X-FLG01.
  DATA: FINISHED_FLAG  LIKE AM61X-FLG01,
        NLINE LIKE SY-TABIX.
  CLEAR FINISHED_FLAG.

*  Beendete Tasks verarbeiten
  LOOP AT RECVX.
*--> Statustab. TASKX/WORKX aktualisieren und Statistik fortschreiben
    PERFORM RECEIVE_ADMIN USING    RECVX
                          CHANGING MRPSTOP.
    DELETE RECVX.
  ENDLOOP.
*--> Fehlerhaften Saetzen eine zweite Chance geben
  IF MRPSTOP IS INITIAL.
    PERFORM ERROR_TAB.
  ENDIF.
*--> Laufzeit ermitteln
  RM61X-RTIME = SY-UZEIT - RM61X-SZEIT.

*--> Bei Stopflags alle angefangenen Tasks abwarten
  IF NOT MRPSTOP IS INITIAL
  OR NOT CM61X-STOPX IS INITIAL.                          "HW 155335
     PERFORM CHECK_ALL_TASKS_FINISHED CHANGING FINISHED_FLAG.
     IF FINISHED_FLAG EQ XFLAG.
        PLANNING_FINISHED = XFLAG.
     ENDIF.
*       EXIT.
  ENDIF.
*
  CHECK MRPSTOP IS INITIAL
  AND CM61X-STOPX IS INITIAL.                             "HW 155335
*                                        "Synchronisation pruefen
  IF NEW_LEVEL_FLAG EQ XFLAG.
*  bei Dispostufenwechsel vorsichtshalber Verbindungen schliessen
*  und neu aufbauen, damit interne Tabellen geloescht werden
    CLEAR KEEPING_TASK.
    PERFORM CHECK_ALL_TASKS_FINISHED CHANGING FINISHED_FLAG.
    IF FINISHED_FLAG <> XFLAG.
      EXIT.                            "Synchronisation (warten)
    ENDIF.
    IF NEVER_KEEPING_TASK IS INITIAL.
      KEEPING_TASK = XFLAG.
    ENDIF.
  ENDIF.

*   Lesen naechste Materialvormerkung(en)
