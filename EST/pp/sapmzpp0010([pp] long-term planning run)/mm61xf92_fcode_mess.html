*----------------------------------------------------------------------*
*  Fehlermeldungen anzeigen                                        *
*----------------------------------------------------------------------*


FORM FCODE_MESS.
  DATA: MESSAGES LIKE SY-TABIX.

  CALL FUNCTION 'MESSAGES_COUNT' IMPORTING COUNT = MESSAGES.
  IF MESSAGES > 0.
    CALL FUNCTION 'MESSAGES_SHOW'
         EXPORTING OBJECT       = 'Daten lesen'(200)
                   SEND_IF_ONE  = ' '       "Direktes Anzeigen bei 1
                   SHOW_LINNO   = ' '.      "Keine Zeilennummern
  ELSE.
    MESSAGE S329(MF).  "Keine Fehler beim Lesen der Daten
  ENDIF.
ENDFORM.
