Program listing for: MM61XDBR_MRP_AREA_PLANT_CHECK 
*---------------------------------------------------------------------*
*       FORM MRP_AREA_PLANT_CHECK                                     *
*---------------------------------------------------------------------*
*       checks consistency mrp area / plant                           *
*---------------------------------------------------------------------*
*  -->  BERID       mrp area                                          *
*  -->  WERKS       plant                                             *
*---------------------------------------------------------------------*


FORM MRP_AREA_PLANT_CHECK USING BERID LIKE MDLV-BERID
                                BERTX LIKE MDLV-BERTX
                                WERKS LIKE MDLW-WERKS.
  STATICS:
    BERID_OLD LIKE MDLV-BERID,
    BERTX_OLD LIKE MDLV-BERTX,
    WERKS_OLD LIKE MDLW-WERKS,
    FIRST_CALL TYPE C VALUE 'X'.
*--> clear bertx.      "Dispobereichsname initialisieren
*--> plant and mrp area is initial
  IF WERKS IS INITIAL AND BERID IS INITIAL.
*    IF T000MD-DISFG IS INITIAL.
*     MESSAGE E327(MD).    "Dispobereich nicht aktiv
*    ELSE.
     MESSAGE E320(MD).    "Dispobereich aktiv
*   ENDIF.
  ENDIF.
*--> check client flag
*  PERFORM READ_T000MD.
*  IF  T000MD-DISFG IS INITIAL
*  AND T000MD-UDBVM IS INITIAL.                              "HW 624642
**--> normally impossible (BERID filled by SET/GET but client flag OFF)
*    CLEAR BERID.
*    EXIT.
*  ENDIF.
*--> OLD-Vergleichswerte bei Erstaufruf ermitteln
  IF NOT FIRST_CALL IS INITIAL.
    CLEAR FIRST_CALL.
    BERID_OLD = GLOBAL_BERID_OLD.      "in PBO gefuellt
    BERTX_OLD = GLOBAL_BERTX_OLD.
    WERKS_OLD = GLOBAL_WERKS_OLD.      "in PBO gefuellt

  ENDIF.
*--> check berid versus plant
  IF BERID IS INITIAL.
*--> get plant MRP area
    PERFORM BERID_FOR_WERKS USING WERKS CHANGING BERID BERTX.
  ELSE.
*--> determine plant (4.0c logik: MRP area belongs to exactly 1 plant)
    PERFORM READ_MDLV USING BERID CHANGING MDLV.
    IF WERKS IS INITIAL.
*--> set plant
      WERKS = MDLV-WERZG.
      BERTX = MDLV-BERTX.
    ELSEIF WERKS NE MDLV-WERZG.        "4.0c: check MDLV is sufficient
      IF     WERKS_OLD NE WERKS
      AND    BERID_OLD EQ BERID.
*--> User hat Werk geandert, also BERID anpassen
        PERFORM BERID_FOR_WERKS USING WERKS CHANGING BERID BERTX.
        PERFORM READ_MDLV USING BERID CHANGING MDLV.
*--> wird bei sofortigem Leave To Transaction beneotigt (MD04):
*       IF NOT T000MD-DISFG IS INITIAL.                     "Note 898006
          SET PARAMETER ID 'BERID' FIELD BERID.
*       ENDIF.
      ELSEIF WERKS_OLD EQ WERKS
      AND    BERID_OLD NE BERID.
*--> User hat DB geandert, also Werk anpassen
        WERKS = MDLV-WERZG.
        BERTX = MDLV-BERTX.
*--> wird bei sofortigem Leave To Transaction beneotigt (MD04):
        SET PARAMETER ID 'WRK' FIELD WERKS.
      ELSE.
*   Dispobereich &1 und Werk &2 passen nicht zueinander
        MESSAGE E317(MD) WITH BERID WERKS.
      ENDIF.
    ENDIF.
  ENDIF.

*--> Dispobereichstext.
    MOVE MDLV-BERTX TO BERTX.                               "Note 1801696

*--> Werte fuer Vergleich merken
  BERID_OLD = BERID.
  BERTX_OLD = BERTX.
  WERKS_OLD = WERKS.
ENDFORM.
