Program listing for: MM61XF80_ADD_WEBAZ 
*----------------------------------------------------------------------*
* WEBAZ addieren                                                       *
*----------------------------------------------------------------------*


FORM ADD_WEBAZ USING DAT01 WEBAZ DAT00.
  IF WEBAZ GT 0.
    MOVE DAT01 TO AM61X-GKDAY.
    PERFORM CONVERT_GKDAY_FKDAY_PLUS USING AM61X-GKDAY CM61W-FABKL.
    AM61X-FKDAY = MDCAL-FKDAY + WEBAZ.
    PERFORM CONVERT_FKDAY_GKDAY USING AM61X-FKDAY CM61W-FABKL.
    MOVE MDCAL-GKDAY TO DAT00.
  ELSE.
    MOVE DAT01 TO DAT00.
  ENDIF.
ENDFORM.
