Program listing for: MM61XF60_UPDATE_MDPMX_LPEIN 

FORM UPDATE_MDPMX_LPEIN.
  MOVE CHAR1 TO AM61X-RCODE.               "Returncode vorbesetzen
  IF MPLP-RSNUM IS INITIAL.                "Keine Reservierungsnummer
    IF AM61X-VSTAT  = VSTATH
    AND CM61X-INMEM = XFLAG.               "Bei neuer Banf
      PERFORM STUELI_AUFLOESEN_MPLP.       "Stueli neu aufloesen
      MPLP-AKTAL  = XFLAG.
      MDPS-RSNUM  = MPLP-RSNUM.
      AM61X-RCODE = CHAR0.
      EXIT.
    ELSE.
      EXIT.
    ENDIF.
  ENDIF.
  IF MPLP-AKTAL <> XFLAG.                  "Aufloesung nicht aktuell
    PERFORM READ_MDPMX USING MPLP-RSNUM.   "Komponenten lesen
    IF AM61X-RCODE NE CHAR0. EXIT. ENDIF.
  ENDIF.
  PERFORM CHECK_ANPASSEN_MDPMX_LPEIN.      "Check Komponentenanpassung
  MOVE XFLAG TO MPLP-AKTAL.                "Setzen Aktualitaetskz
  MOVE CHAR0 TO AM61X-RCODE.               "Returncode setzen
ENDFORM.
