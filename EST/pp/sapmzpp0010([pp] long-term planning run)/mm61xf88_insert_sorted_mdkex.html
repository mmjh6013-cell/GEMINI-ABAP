FORM INSERT_SORTED_MDKEX.
*--> Set auf Tabelle MDPSO
  READ TABLE MDKEX
       WITH KEY DISST = MDKEX-DISST
                MATNR = MDKEX-MATNR
                PLWRK = MDKEX-PLWRK
                BERID = MDKEX-BERID
       BINARY SEARCH
       TRANSPORTING NO FIELDS.
  CASE SY-SUBRC.
    WHEN 0.
      MODIFY MDKEX INDEX SY-TABIX.
    WHEN 4.
      INSERT MDKEX INDEX SY-TABIX.
    WHEN OTHERS.
      APPEND MDKEX.
  ENDCASE.
*--> Suchstatistik in der Uebersicht muss ggf. aktualisiert werden
  CLEAR CR61T-STASU.
ENDFORM.
