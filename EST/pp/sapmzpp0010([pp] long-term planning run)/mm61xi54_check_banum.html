Program listing for: MM61XI54_CHECK_BANUM 
*----------------------------------------------------------------------*
* Pruefen Nummer Bestellanforderung                                    *
*----------------------------------------------------------------------*


MODULE CHECK_BANUM.
*--> Pruefen externe Eingabe
  IF MPBA-BANFN EQ SPACE.
    EXIT.
  ENDIF.
*--> Pruefen Positionsnummer
  IF MPBA-BNFPO EQ 0.
    MOVE T460D-PSBAN TO MPBA-BNFPO.
  ENDIF.
*--> Probelesen
  PERFORM READ_EBAN USING MPBA-BANFN MPBA-BNFPO.
  IF SY-SUBRC EQ 0.
    MESSAGE E034 WITH MPBA-BANFN MPBA-BNFPO.
  ENDIF.
*--> Pruefen gegen externen Nummernkreis
  PERFORM CHECK_NUMBER USING 'BANF' T460D-NUMKE MPBA-BANFN.
*--> Sperren der Bestellanforderung
  PERFORM BANF_SPERREN USING MPBA-BANFN MPBA-BNFPO.
ENDMODULE.
