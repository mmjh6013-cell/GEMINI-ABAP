Program listing for: MM61XPSZ_CHECK_PLSC 
*----------------------------------------------------------------------*
* Pruefen Planungszenario                                             *
*---------------------------------------------------------------------*
*       mit Warnmeldung, wenn Werk dem Szenario nicht zugeordnet      *
*----------------------------------------------------------------------*


FORM check_plsc USING value(werks) LIKE plpt-plwrk
                      plsc STRUCTURE plsc.
  DATA: subrc LIKE sy-subrc.
  IF plsc-psact <> psact_active.
*   Das Planungsszenario & ist nicht freigegeben
    MESSAGE e114(md) WITH plsc-plscn.
  ENDIF.
  IF NOT werks IS INITIAL.
    PERFORM select_plpt_werks USING plsc-plscn werks subrc.
    IF subrc <> 0.
      MESSAGE w116(md) WITH plsc-plscn werks.
    ENDIF.
  ENDIF.
ENDFORM.
