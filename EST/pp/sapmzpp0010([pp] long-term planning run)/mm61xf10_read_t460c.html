*----------------------------------------------------------------------*
* Prueftabelle T460C lesen
*----------------------------------------------------------------------*


FORM READ_T460C USING OBART LIKE T460C-OBART
                      PASCH LIKE T460C-PASCH.
*--> Inhalt Workarea ueberpruefen
  IF  OBART EQ T460C-OBART
  AND PASCH EQ T460C-PASCH.
    SY-SUBRC = 0. EXIT.
  ENDIF.
*--> Tabelleneintrag nachlesen
  SELECT SINGLE * FROM  T460C
                  WHERE OBART = OBART
                  AND   PASCH = PASCH.
  IF SY-SUBRC NE 0.
    MOVE 'T460C' TO AM61X-TBNAM.
    SET PARAMETER ID 'TAB' FIELD AM61X-TBNAM.
    MESSAGE E001 WITH OBART AM61X-TBNAM.
  ENDIF.
ENDFORM.
