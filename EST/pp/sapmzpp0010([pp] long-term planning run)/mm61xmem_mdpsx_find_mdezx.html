*----------------------------------------------------------------------*
*  MDPSX_FIND_MDEZX                                                    *
*----------------------------------------------------------------------*


FORM MDPSX_FIND_MDEZX
     USING    IV_MDPSINDEX LIKE SY-TABIX
     CHANGING ES_LINE      TYPE MRP_LIST_LINE_TYPE.

  DATA: LV_INDEX LIKE SY-TABIX.

*--> Vorbesetzen Index MDEZ-Eintrag
  ES_LINE-MDEZ_INDEX = 0.

*--> MDPSX lesen
  READ TABLE MDPSX INTO ES_LINE-MDPS INDEX IV_MDPSINDEX.
  IF SY-SUBRC > 0. EXIT. ENDIF.

*--> Index in Struktur fuer ausgewaehlte Zeile
  MOVE IV_MDPSINDEX       TO ES_LINE-MDPS_INDEX.

*--> Key fuellen
  MOVE ES_LINE-MDPS-PLAAB TO EZKEY-PLAAB.
  MOVE ES_LINE-MDPS-PLANR TO EZKEY-PLANR.
  IF  MDST-VRFWE  EQ XFLAG
  AND ES_LINE-MDPS-PLUMI EQ PLUSX.
    MOVE ES_LINE-MDPS-DAT01 TO EZKEY-SORT0.
  ELSE.
    MOVE ES_LINE-MDPS-DAT00 TO EZKEY-SORT0.
  ENDIF.
  MOVE ES_LINE-MDPS-TAG00 TO EZKEY-TAG00.
  MOVE ES_LINE-MDPS-SORT1 TO EZKEY-SORT1.
  MOVE ES_LINE-MDPS-SORT2 TO EZKEY-SORT2.

*--> MDEZX lesen
  READ TABLE MDEZX WITH KEY EZKEY BINARY SEARCH.
  LV_INDEX = SY-TABIX.
  IF SY-SUBRC = 8. EXIT. ENDIF.
  LOOP AT MDEZX INTO ES_LINE-MDEZ FROM LV_INDEX.
    IF ES_LINE-MDEZ-ALINE = IV_MDPSINDEX.
      ES_LINE-MDEZ_INDEX = SY-TABIX. EXIT.
    ENDIF.
  ENDLOOP.
ENDFORM.
