Program listing for: MM61XF60_ANPASSEN_MDPMX 
*----------------------------------------------------------------------*
* Anpassung Materialkomponenten
*----------------------------------------------------------------------*


FORM ANPASSEN_MDPMX.
*--> Schnittstellendaten fuellen
  MOVE SPACE       TO CM61Q-CAMOD.
  MOVE CM61W-FABKL TO CM61Q-FABKL.
  MOVE SPACE       TO CM61Q-AENKZ.
  MOVE SPACE       TO CM61Q-RCODE.
*--> Komponenten anpassen
  CALL FUNCTION 'MD_ANPASSEN_PLKV'
       EXPORTING ECM61Q = CM61Q
                 EPLKVA = PLKVA
                 EPLKVS = PLKVS
       IMPORTING ICM61Q = CM61Q
       TABLES    MDPML  = MDPML
                 MDPMX  = MDPMX.
*--> Sichern PLKVA in PLKVS
  MOVE PLKVA TO PLKVS.
ENDFORM.
