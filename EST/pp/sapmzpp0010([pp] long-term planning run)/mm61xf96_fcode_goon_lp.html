FORM FCODE_GOON_LP.
*--> Setzen Startzeit
  GET_START_TIME TIME3.
*--> Stueckliste aufloesen
  PERFORM STUECKLISTE_AUFLOESEN_BT.
  IF AM61X-RCODE NE CHAR0.
    EXIT.
  ENDIF.
*--> Abschliessen Dispositionstabelle
* perform close_disp_tabelle_bt.
* if am61x-rcode ne char0.
*   exit.
* endif.
*--> Dispositionsergebnis verbuchen
  PERFORM CALL_VERBUCHUNG_MP.
  IF AM61X-RCODE NE CHAR0.
    EXIT.
  ENDIF.
*--> Verarbeitungskennzeichen in CM61D sichern (Statistik)
  PERFORM SAVE_KZXXX_CM61D.
*--> Ermitteln Zeit für Bearbeitung
  CLEAR TDIFF.
  run_time tdiff time4 time3.
*--> Statistik erfassen
  perform erfassen_statistik using tdiff.
*--> Material für Einzelplanung entsperren
  PERFORM ENTSPERREN_LFR USING RM61X-PLSCN
                               CM61D-WERKS CM61D-BERID CM61D-MATNR.
*--> Werk für Rekursivitätsprüfung merken
  REFRESH REKWK.
  MOVE CM61D-MATNR TO REKMT-MATNR.
  MOVE CM61D-BERID TO REKWK-BERID.
  MOVE CM61D-WERKS TO REKWK-WERKS.
  APPEND REKWK.
*--> Setzen Daten für Haltepunktsteuerung
  MOVE RM61X-ANZDL TO CM61X-ANZDL.
*--> Reset Materialdaten des letzten Materials
  CLEAR RM61X-MATNR.
  CLEAR RM61X-WERKS.
  CLEAR RM61X-DISST.
  CLEAR RM61X-BERID.
*--> Materialvormerkungen abarbeiten
  DO.
*--> Naechste Vormerkung ermitteln
    PERFORM NEXT_PLANNING_REQUEST.
    IF AM61X-RCODE NE CHAR0.
      EXIT.
    ENDIF.
*--> Material bearbeiten
    GET_START_TIME TIME3.
    PERFORM BEARBEITEN_MATERIAL_ML USING XFLAG.
    CLEAR TDIFF.
    run_time tdiff time4 time3.
*--> Statistik erfassen
    perform erfassen_statistik using tdiff.
*--> Material für Einzelplanung entsperren
    PERFORM ENTSPERREN_LFR USING RM61X-PLSCN
                                 CM61D-WERKS CM61D-BERID CM61D-MATNR.
  ENDDO.
*--> Statistik aufbereiten
  PERFORM AUFBEREITEN_STATISTIK.
ENDFORM.
