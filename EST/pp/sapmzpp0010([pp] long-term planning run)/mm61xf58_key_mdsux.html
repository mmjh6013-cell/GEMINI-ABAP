Program listing for: MM61XF58_KEY_MDSUX 
*----------------------------------------------------------------------*
* Keyaufbau fuer MDSUX
*----------------------------------------------------------------------*


FORM KEY_MDSUX USING PLAAB LIKE MDSU-PLAAB
                     PLANR LIKE MDSU-PLANR
                     DATUM TYPE D.
*--> Periodenanfang ermitteln
  CASE MDST-INPER.
    WHEN TAGEX.
      MOVE DATUM TO MDCAL-PRANF.
      MOVE DATUM TO MDCAL-PREND.
    WHEN WOCHE.
      PERFORM COMPUTE_GKDAY_WOCHE USING DATUM 1.
    WHEN MONAT.
      PERFORM COMPUTE_GKDAY_MONAT USING DATUM 1.
    WHEN BUPER.
      PERFORM COMPUTE_GKDAY_BUPER USING MT61D-PERIV DATUM 1.
    WHEN PKPER.
      PERFORM COMPUTE_GKDAY_PKPER
              USING MT61D-WERKS MDST-MRPPP DATUM 1.
  ENDCASE.
*--> MDSU-Key erstellen
  MOVE PLAAB       TO SUKEY-PLAAB.
  MOVE PLANR       TO SUKEY-PLANR.
  MOVE MDCAL-PRANF TO SUKEY-SORT0.
ENDFORM.
