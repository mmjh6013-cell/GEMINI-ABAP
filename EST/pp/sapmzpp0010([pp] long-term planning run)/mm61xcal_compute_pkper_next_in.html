Program listing for: MM61XCAL_COMPUTE_PKPER_NEXT_IN 
*----------------------------------------------------------------------*
* COMPUTE_PKPER_NEXT_INTERVAL USING WERKS MRPPK GKDAY
* Lesen des nächst größeren Intervalls in der T439I in Bezug
* auf das Datum GKDAY
*----------------------------------------------------------------------*


FORM COMPUTE_PKPER_NEXT_INTERVAL USING WERKS LIKE MARC-WERKS
                                       MRPPK LIKE MARC-MRPPP
                                       GKDAY TYPE D.
*--> Lokale Daten
  DATA: REF_WERKS LIKE MDKP-PLWRK.
*--> Datenbereich clearen
  CLEAR MDCAL.
*--> Zugriffswerk bestimmen
  PERFORM ZUGRIFFSWERK USING WERKS REF_WERKS MRPPK.
*--> Tabelle T439I lesen
  SELECT * FROM T439I
           WHERE WERKS EQ REF_WERKS
           AND   MRPPP EQ MRPPK
           AND   PPVON GT GKDAY
  ORDER BY PRIMARY KEY.
        MOVE T439I-PPVON TO MDCAL-PRANF.
        MOVE T439I-PPBIS TO MDCAL-PREND.
        EXIT.
  ENDSELECT.
ENDFORM.
