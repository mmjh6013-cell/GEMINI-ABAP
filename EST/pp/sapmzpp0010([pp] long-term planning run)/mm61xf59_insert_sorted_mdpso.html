* Eintrag in Tabelle MDPSO sortiert einfuegen
*----------------------------------------------------------------------*


FORM INSERT_SORTED_MDPSO USING MDPSI STRUCTURE MDPS.
*--> MOVE MDPSI to MDPS
  MOVE MDPSI TO MDPS.
*--> SET-Key fuer die Tabelle MDPSX erstellen
  MOVE MDPS-PLAAB TO PSKEY-PLAAB.
  MOVE MDPS-PLANR TO PSKEY-PLANR.
  MOVE MDPS-DAT00 TO PSKEY-DAT00.
  MOVE MDPS-TAG00 TO PSKEY-TAG00.
  MOVE MDPS-SORT1 TO PSKEY-SORT1.
  MOVE MDPS-SORT2 TO PSKEY-SORT2.
*--> Set auf Tabelle MDPSO
  READ TABLE MDPSO
       WITH KEY PSKEY BINARY SEARCH.
  CASE SY-SUBRC.
      WHEN 0.
        MOVE MDPS TO MDPSO.
        INSERT MDPSO INDEX SY-TABIX.
      WHEN 4.
        MOVE MDPS TO MDPSO.
        INSERT MDPSO INDEX SY-TABIX.
      WHEN OTHERS.
        MOVE MDPS TO MDPSO.
        APPEND MDPSO.
  ENDCASE.
ENDFORM.
