Program listing for: MM61XF80_COMP_FRGDT 
*----------------------------------------------------------------------*
* Ermitteln Freigabetermin                                             *
*----------------------------------------------------------------------*


FORM COMP_FRGDT.
*--> Umrechnen Liefertermin
  PERFORM CONVERT_GKDAY_FKDAY_PLUS USING MPBA-LFDAT CM61W-FABKL.
  MOVE MDCAL-GKDAY TO AM61X-GKDAY.
  MOVE MDCAL-FKDAY TO AM61X-FKDAY.
*--> Planlieferzeit subtrahieren
  IF MT61D-PLIFZ GT 0.
    AM61X-GKDAY = AM61X-GKDAY - MT61D-PLIFZ.
    PERFORM CONVERT_GKDAY_FKDAY_MINUS USING AM61X-GKDAY CM61W-FABKL.
    MOVE MDCAL-GKDAY TO AM61X-GKDAY.
    MOVE MDCAL-FKDAY TO AM61X-FKDAY.
  ENDIF.
*--> Bearbeitungszeit subtrahieren
  IF T399D-BZTEK NE 0.
    AM61X-FKDAY = AM61X-FKDAY - T399D-BZTEK.
    PERFORM CONVERT_FKDAY_GKDAY USING AM61X-FKDAY CM61W-FABKL.
    MOVE MDCAL-GKDAY TO AM61X-GKDAY.
  ENDIF.
  MOVE AM61X-GKDAY TO MPBA-FRGDT.
ENDFORM.
