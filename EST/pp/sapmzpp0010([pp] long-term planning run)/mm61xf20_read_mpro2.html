* Lesen Tabelle MPRO2                                                 *
*----------------------------------------------------------------------*


FORM READ_MPRO2 USING PRGRP LIKE MPRO2-MATNR
                      PRWRK LIKE MPRO2-WERKS.
*--> Prüfen Tabelleninhalt
  IF  PRGRP EQ MPRO2-MATNR
  AND PRWRK EQ MPRO2-WERKS.
    SY-SUBRC = 0. EXIT.
  ENDIF.
*--> Produktgruppe fuer Disposition lesen
  CALL FUNCTION 'MD_PG_READ_HEAD'
       EXPORTING EPRGRP  = PRGRP
                 EWERKS  = PRWRK
       IMPORTING IMPRO2  = MPRO2
       EXCEPTIONS ERROR   = 1.
  IF SY-SUBRC > 0.
    MESSAGE ID SY-MSGID TYPE 'E' NUMBER SY-MSGNO
            WITH SY-MSGV1 SY-MSGV2 SY-MSGV3 SY-MSGV4.
  ENDIF.
ENDFORM.
