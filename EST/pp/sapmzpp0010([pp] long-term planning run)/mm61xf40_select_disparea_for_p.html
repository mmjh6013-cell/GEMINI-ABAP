*&---------------------------------------------------------------------*
*&      Form  SELECT_DISPAREA_FOR_PLANT
*&---------------------------------------------------------------------*
*       Bestimmen der Dispobereiche zu einem Werk
*       und Füllen der int. Tabelle PLANTX
*----------------------------------------------------------------------*
*  -->  werks    :  Aufzulösendes Planungswerk
*  <--  p_plantx :  interne Tabelle mit Dispobereichen zum Planungswerk
*----------------------------------------------------------------------*


FORM SELECT_DISPAREA_FOR_PLANT TABLES P_PLANTX STRUCTURE PLANTX
                               USING  WERKS.
  DATA: BERIDTAB LIKE MDLV OCCURS 0
                 WITH HEADER LINE.
  DATA: L_PUCNT  LIKE PLANTX-PUCNT.

  CLEAR L_PUCNT.
  CLEAR P_PLANTX. REFRESH P_PLANTX.

  CALL FUNCTION 'MD_GET_BERID_FOR_WERKS'
       EXPORTING
            IWERKS    = WERKS
       TABLES
            EMDLV_TAB = BERIDTAB.

  LOOP AT BERIDTAB.
*--> Selektionstabelle Dispobereiche zu den selektierten Werken aufbauen
    PERFORM APPEND_SELBERIDX USING BERIDTAB-BERID.
    IF NOT T000MD-DISFG IS INITIAL.
*--> Reihenfolge-Tabelle P_PLANTX
      MOVE CM61X-PUWNR    TO P_PLANTX-PUWNR.
      MOVE BERIDTAB-BERID TO P_PLANTX-BERID.
      MOVE BERIDTAB-BERTY TO P_PLANTX-BERTY.
      MOVE BERIDTAB-WERZG TO P_PLANTX-PLWRK.
      APPEND P_PLANTX.
    ENDIF.
  ENDLOOP.
  IF T000MD-DISFG IS INITIAL.
*-->  PLANTX über Werk
    CLEAR P_PLANTX-PUWNR.
    P_PLANTX-PLWRK = CM61X-WERKS.
    CLEAR P_PLANTX-BERID.
    PERFORM CHECK_MRP_ACTIVE USING P_PLANTX-PLWRK.
    APPEND P_PLANTX.
  ENDIF.
*--> Sortieren der Dispobereiche pro Werk
  SORT P_PLANTX BY BERTY DESCENDING.
*--> Reihenfolge neu festlegen
  LOOP AT P_PLANTX.
    L_PUCNT = L_PUCNT + 1.
    MOVE L_PUCNT TO P_PLANTX-PUCNT.
    MODIFY P_PLANTX INDEX SY-TABIX TRANSPORTING PUCNT.
  ENDLOOP.

ENDFORM.                               " SELECT_DISPAREA_FOR_PLANT
