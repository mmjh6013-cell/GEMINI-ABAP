Program listing for: MM61XFIP_SUCHEN_QUOTENPOSITION 
*----------------------------------------------------------------------*
* Suchen Quotensatzposition                                            *
*----------------------------------------------------------------------*


FORM SUCHEN_QUOTENPOSITION USING QUNUM LIKE EQUP-QUNUM
                                 QUPOS LIKE EQUP-QUPOS
                                 BESKZ LIKE MPPA-BESKZ
                                 SOBES LIKE MPPA-SOBES
                                 LIFNR LIKE MPPA-FLIEF
                                 VERID LIKE MPPA-VERID
                                 PLWRK LIKE MPPA-PLWRK
                                 BEWRK LIKE MPPA-PWWRK.
*--> Quotenposition ermitteln
  CLEAR EQUPG.
  MOVE EQUKX-QUNUM TO EQUPG-QUNUM.
  READ TABLE EQUPX WITH KEY EQUPG BINARY SEARCH.
  IF SY-SUBRC NE 0.
    EXIT.
  ENDIF.
*--> Erste Quotenposition merken
  MOVE SY-TABIX TO AM61X-ALINE.
*--> Passende Quotenposition suchen (BESKZ SOBES LIFNR VERID BEWRK)
  LOOP AT EQUPX FROM AM61X-ALINE.
     IF EQUPX-QUNUM NE EQUPG-QUNUM.
        EXIT.
     ENDIF.
     IF EQUPX-BESKZ = BESKZ AND
        EQUPX-SOBES = SOBES AND
        EQUPX-LIFNR = LIFNR AND
        EQUPX-VERID = VERID.
           IF  ( NOT BEWRK IS INITIAL ) AND BEWRK NE PLWRK.
              CHECK EQUPX-BEWRK = BEWRK.
           ENDIF.
           MOVE EQUPX-QUNUM TO QUNUM.
           MOVE EQUPX-QUPOS TO QUPOS.
           EXIT.
     ENDIF.
  ENDLOOP.
ENDFORM.
