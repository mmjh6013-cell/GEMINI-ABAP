Program listing for: MM61XF59_CHECK_AENDERUNG_MDPS_ 
*----------------------------------------------------------------------*
* Geaenderter Fertigungsauftrag in Dispositionstabelle übernehmen
*----------------------------------------------------------------------*


FORM CHECK_AENDERUNG_MDPS_FA.
*--> Verarbeitungsstatus ueberpruefen
  IF AM61X-VSTAT EQ VSTATH.
    PERFORM SET_NEW_AUSSL USING AUSV3 MDPS-AUSSL MDPS-OLDSL.
    PERFORM SET_QUOTIERUNG_MDPS.
    PERFORM INSERT_SORTED_MDPSX USING MDPS.
    EXIT.
  ENDIF.
*--> Reset Umterminierungsdaten
  PERFORM RESET_MDPS_01.
*--> Setzen Ausnahmemeldung
  PERFORM SET_NEW_AUSSL USING AUSV3 MDPS-AUSSL MDPS-OLDSL.
*--> Quotierung ueberpruefen
  PERFORM CHECK_QUOTIERUNG_MDPS.
*--> Pruefen Aenderung am Sortierbegriff
  IF MDPS-PLAAB NE MDPSS-PLAAB
  OR MDPS-PLANR NE MDPSS-PLANR
  OR MDPS-DAT00 NE MDPSS-DAT00
  OR MDPS-TAG00 NE MDPSS-TAG00
  OR MDPS-SORT1 NE MDPSS-SORT1
  OR MDPS-SORT2 NE MDPSS-SORT2.
    READ TABLE MDPSX INDEX MDPSS-XLINE.   "Positionsnr. retten THD31I
    MOVE MDPSX-DELPS TO MDPS-DELPS.       "Positionsnr. retten THD31I
    DELETE MDPSX INDEX MDPSS-XLINE.
    PERFORM INSERT_SORTED_MDPSX USING MDPS.
  ELSE.
    READ TABLE MDPSX INDEX MDPSS-XLINE.
    MOVE MDPSX-DELPS TO MDPS-DELPS.       "Positionsnr. retten THD31I
    IF SY-SUBRC NE 0.
      MESSAGE E190 WITH MDPSS-XLINE 'MDPSX'.
    ENDIF.
    MOVE MDPS TO MDPSX.
    MODIFY MDPSX INDEX MDPSS-XLINE.
  ENDIF.
ENDFORM.
