*  POP_DIALOGSTACK                                                     *
*----------------------------------------------------------------------*


FORM POP_DIALOGSTACK.

  DATA: LS_DIALOGSTACK TYPE DIALOGSTACK_TYP,
        LV_ANSWER      TYPE C.

  READ TABLE GT_DIALOGSTACK INTO LS_DIALOGSTACK INDEX 1.
  IF SY-SUBRC > 0.
*--> Kein Eintrag auf Stack -> Materialuebersicht anzeigen
    PERFORM CLEAR_DIALOGSTACK.
    PERFORM SHOW_PLANNED_MATERIALS.
  ELSE.
*--> Stack abbauen
    DELETE GT_DIALOGSTACK INDEX 1.
*--> Material vom Stack anzeigen
    PERFORM SHOW_MRP_LIST
            USING LS_DIALOGSTACK-MATERIAL
                  LS_DIALOGSTACK-PLANT
                  LS_DIALOGSTACK-BERID
                  LS_DIALOGSTACK-CURSORLINE
                  GC_FALSE
                  GC_TRUE.
  ENDIF.
ENDFORM.
