*----------------------------------------------------------------------*
* Fixierungskennzeichen Plauf/Saauf ueberpruefen
*----------------------------------------------------------------------*


FORM CHECK_PLAF_FIX01.

  DATA: FIX_FLAG(1) TYPE C.

*--> Plaf-Fixierung pruefen
  CHECK MDPSX-FIX01 EQ XFLAG.
  CHECK MDPSX-VSTAT NE VSTATV.
  CLEAR FIX_FLAG.
*--> Plaf nachlesen
  PERFORM READ_PLAF USING MDPSX-DELNR.
  IF SY-SUBRC NE 0.
    IF MDPSX-VSTAT EQ VSTATN.
      CLEAR MDPSX-FIX01.
    ENDIF.
    EXIT.
  ENDIF.
  MOVE PLAF-AUFFX TO FIX_FLAG.
  IF PLAF-WEMNG GT 0.
    MOVE XFLAG TO FIX_FLAG.
  ENDIF.
*--> physische Fixierung pruefen
  IF FIX_FLAG IS INITIAL.
    CLEAR MDPSX-FIX01.
  ENDIF.

ENDFORM.                    " CHECK_PLAF_FIX01
