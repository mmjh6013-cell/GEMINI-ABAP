Program listing for: MM61XF92_FCODE_BVDL_PS 
*----------------------------------------------------------------------*
* FCODE: Bestellvorschlag loeschen
*----------------------------------------------------------------------*


FORM FCODE_BVDL_PS.
  DATA: LV_FOUND         TYPE BOOL,
        LV_SELECTED_LINE LIKE SY-TABIX.
*--> Dispositionselement ermitteln
  PERFORM PICK_UP_EZ
          USING     CHAR1
          CHANGING  LV_SELECTED_LINE LV_FOUND.
  CHECK LV_FOUND = GC_TRUE.
*--> DirektBAnfen duerfen nicht geloescht werden
  IF  MDPSX-DELKZ EQ BSANF
  AND NOT MDPSX-ARSNR IS INITIAL.
*   Die Bestellanf. kann nur über den zugeh. Auftrag gelöscht werden
    MESSAGE E239.
  ENDIF.
*--> SD-Banfen duerfen nicht geloescht werden
  IF  MDPSX-DELKZ EQ BSANF
  AND MDPSX-VRFKZ EQ SPACE.
    MESSAGE E246.
  ENDIF.
*--> Loeschen Bestellvorschlag aus MDPSX
  PERFORM DELETE_MDPSS_01.
*--> MDEZX neu aufbauen
  PERFORM MDEZX_AUFBAUEN.
ENDFORM.
