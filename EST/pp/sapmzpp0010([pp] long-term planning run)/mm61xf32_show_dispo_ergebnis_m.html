Program listing for: MM61XF32_SHOW_DISPO_ERGEBNIS_M 
*----------------------------------------------------------------------*
*  Dispositionsergebnis anzeigen
*----------------------------------------------------------------------*


FORM SHOW_DISPO_ERGEBNIS_MP.
*--> Abbruchbedingung pruefen
  IF CM61X-ANZDL NE XFLAG.
    EXIT.
  ENDIF.
*--> Haltepunkt pruefen
  IF RM61X-MATNR NE CM61D-MATNR
  OR RM61X-WERKS NE CM61D-WERKS
  OR RM61X-DISST NE CM61D-DISST
  OR RM61X-BERID NE CM61D-BERID.                 "TODO check + test
    EXIT.
  ENDIF.
*--> Setzen Merker
  MOVE XFLAG TO AM61X-NEWHP.
*--> Setzen Message für Anzeige
  IF MDKP-MSGAR EQ MSGTYPW.
    PERFORM READ_T141T USING T141-MMSTA SY-LANGU.
    MESSAGE S130 WITH CM61D-MATNR CM61D-WERKS T141T-MTSTB.
  ELSE.
    MESSAGE S054 WITH CM61D-MATNR CM61D-WERKS CM61D-BERID.
  ENDIF.
*--> Anzeige aufrufen
  PERFORM SHOW_MDEZX USING CHARC.
*--> Check Returncode
  IF AM61X-RCODE EQ CHARA.
    SET SCREEN 0.
    LEAVE SCREEN.
  ENDIF.
ENDFORM.
