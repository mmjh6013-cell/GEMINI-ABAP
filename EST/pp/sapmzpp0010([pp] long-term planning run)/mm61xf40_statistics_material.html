Program listing for: MM61XF40_STATISTICS_MATERIAL 
*----------------------------------------------------------------------*
* Material statistik-maessig auswerten und ggf. in Liste ausgeben
*----------------------------------------------------------------------*


FORM STATISTICS_MATERIAL USING P_CM61D LIKE CM61D.
*--> Anzahl bearbeiteter Materialien
  RM61X-ANZMT = RM61X-ANZMT + 1.
*--> Anzahl Mat. mit Abbruch
  IF NOT P_CM61D-MSGID IS INITIAL.
    ADD 1 TO RM61X-ANZEX.
  ENDIF.
*--> Anzahl Mat. mit neuen Ausnahmemeldungen
  IF NOT P_CM61D-NAUKZ IS INITIAL.
    ADD 1 TO RM61X-ANZAM.
  ENDIF.
*--> Laufzeitstatistik
  IF RM61X-ANZLS EQ XFLAG.
    PERFORM WRITE_NEXT_STATISTIK USING P_CM61D.
  ENDIF.
ENDFORM.
