FORM DATE_PLUS_WORK USING DATUM_1 DIF_WDAYS RESULT FABKAL.

  DATA: WDAY LIKE MDCAL-FKDAY.

  PERFORM CONVERT_GKDAY_FKDAY_MINUS USING DATUM_1 FABKAL.
  WDAY = MDCAL-FKDAY + DIF_WDAYS.
  PERFORM CONVERT_FKDAY_GKDAY USING WDAY FABKAL.
  RESULT = MDCAL-GKDAY.

ENDFORM.
