Program listing for: MM61XCAL_CONVERT_FWEEK_GKDAY 
*----------------------------------------------------------------------*
* Kalenderwoche in 1. Kalendertag der Woche convertieren               *
*----------------------------------------------------------------------*


FORM CONVERT_FWEEK_GKDAY USING FWEEK LIKE MDCAL-FWEEK.
CALL FUNCTION 'WEEK_GET_FIRST_DAY'
     EXPORTING   WEEK         = FWEEK
     IMPORTING   DATE         = MDCAL-GKDAY
     EXCEPTIONS  WEEK_INVALID = 01.
     IF SY-SUBRC NE 0.
       MESSAGE ID '61' TYPE 'E' NUMBER '060' WITH FWEEK.
     ENDIF.
ENDFORM.
