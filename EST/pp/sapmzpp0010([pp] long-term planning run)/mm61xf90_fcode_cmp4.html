FORM FCODE_CMP4.
  CLEAR MDKP2.                    " erzwingt neues Einlesen
  DATA: RCODE LIKE SY-SUBRC.
  PERFORM POPUP_TO_GET_PLSCN USING PLSC2-PLSCN RCODE.
  CHECK RCODE IS INITIAL.
  PERFORM READ_PLSC USING PLSC2-PLSCN PLSC2.
  PERFORM CHECK_PLSC USING RM61X-WERKS PLSC2.
  VERGLEICH-CTYPE = CTYPE_PPLN_PLSC.
  PERFORM VERGLEICH USING RM61X-WRT05.
  CALL SCREEN VERGLEICH-DYN01.
ENDFORM.
