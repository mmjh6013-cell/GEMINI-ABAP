*---------------------------------------------------------------------*
* Mddelx initialisieren
*---------------------------------------------------------------------*


FORM INIT_MDDELX TABLES MDDELX STRUCTURE MDDEL
                 USING  SELDA TYPE C.

  DATA: L_LINES LIKE SY-TABIX.

  CHECK SELDA NE CHARN.
  DESCRIBE TABLE MDDELX LINES L_LINES.
  IF L_LINES GT 0.
*--> Zähler in Mdausx auf Null setzen
    LOOP AT MDDELX.
      CLEAR MDDELX-DAT00.
      CLEAR MDDELX-DAT01.
      MODIFY MDDELX.
    ENDLOOP.
  ENDIF.
ENDFORM.
