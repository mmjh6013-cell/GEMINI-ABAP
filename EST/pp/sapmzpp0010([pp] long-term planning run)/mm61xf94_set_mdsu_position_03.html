Program listing for: MM61XF94_SET_MDSU_POSITION_03 
*----------------------------------------------------------------------*
* Anzeigeposition fuer MDSU für Splittanzeige ermitteln
*----------------------------------------------------------------------*


FORM SET_MDSU_POSITION_03.
  DATA: STORE_MDSUX LIKE MDSUX.

*--> Pruefen aktuelle Position
  IF AM61X-ALINE LE MDSUX-VLINE.
    AM61X-ALINE = 1.
  ENDIF.
  IF AM61X-ALINE GT MDSUX-BLINE.
    AM61X-ALINE = MDSUX-BLINE.
  ENDIF.
*--> Tabelleneintrag aus MDSUX nachlesen
  READ TABLE MDSUX INDEX AM61X-ALINE.
  IF SY-SUBRC NE 0.
    MESSAGE E190 WITH AM61X-ALINE 'MDSUX'.
  ENDIF.

  MOVE MDSUX TO STORE_MDSUX.           "aktuelle mdsux speichern
*--> Loeschen Formatbyte alt MDSU
  LOOP AT MDSUX WHERE FBYTE = CHAR2.
    MOVE SPACE TO MDSUX-FBYTE.
    MODIFY MDSUX.
  ENDLOOP.
  MOVE STORE_MDSUX TO MDSUX.

*--> Formatbyte Summenzeile setzen
  MOVE CHAR2 TO MDSUX-FBYTE.
  MODIFY MDSUX INDEX AM61X-ALINE.
*--> Sichern Index fuer die Summenzeile
  MOVE AM61X-ALINE TO MDSUS-XLINE.
*--> Anzeige neu positionieren
  MDSUX-XLINE = MDSUS-XLINE - 1.
  IF MDSUX-XLINE LT 1.
    MDSUX-XLINE = 1.
  ENDIF.
*--> TC-Topline setzen
  MOVE MDSUX-XLINE TO TC_PS-TOP_LINE.
*--> Loopbereich fuer Einzelzeilen definiern
  MOVE MDSUX-ALINE TO MDEZX-XLINE.
  MOVE MDSUX-ALINE TO MDEZX-VLINE.
  MOVE MDSUX-ELINE TO MDEZX-BLINE.
*--> Anfangszeile für Tablecontrol setzen
  MOVE MDEZX-VLINE TO TC_EZ-TOP_LINE.

*--> MDSU-Key sichern
  MOVE MDSUX-PLAAB TO SUKEY-PLAAB.
  MOVE MDSUX-PLANR TO SUKEY-PLANR.
  MOVE MDSUX-SORT0 TO SUKEY-SORT0.
ENDFORM.
