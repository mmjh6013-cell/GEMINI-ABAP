Program listing for: MM61XFIP_RESET_QUOTIERUNG_MDPS 
*----------------------------------------------------------------------*
* Reset Quotierung_MDPSS                                               *
*----------------------------------------------------------------------*


FORM RESET_QUOTIERUNG_MDPSS.
*--> Pruefen Quotierungskennzeichen
  IF CM61M-USEQU EQ SPACE.
    EXIT.
  ENDIF.
* alte QUNUM/QUPOS/Menge in der MDPSS: Quoten werden zurückgesetzt
  IF ( NOT MDPSS-QUNUM IS INITIAL ) AND ( NOT MDPSS-QUPOS IS INITIAL ).
     MOVE MDPSS-QUNUM   TO EQUPK-QUNUM.
     MOVE MDPSS-QUPOS   TO EQUPK-QUPOS.
     READ TABLE EQUPX WITH KEY EQUPK BINARY SEARCH.
     IF SY-SUBRC EQ 0.
        EQUPX-QUMNG = EQUPX-QUMNG - MDPSS-MNG01.
        IF EQUPX-QUMNG LT 0.
           EQUPX-QUMNG = 0.
        ENDIF.
        MODIFY EQUPX INDEX SY-TABIX.
     ENDIF.
  ENDIF.
ENDFORM.
