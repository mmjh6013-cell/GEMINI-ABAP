Program listing for: MM61XMDV_ADD_MDVL_TO_MDMMX 
*---------------------------------------------------------------------*
*       FORM ADD_MDVL_TO_MDMMX                                        *
*---------------------------------------------------------------------*
*       Materialvormerkungen in interne Tabelle uebernehmen           *
*---------------------------------------------------------------------*
*  -->  WERKS    plant                                          (I)   *
*  -->  MDVM     planning file entry                            (I)   *
*  -->  PORTRC   return code                                    (O)   *
*---------------------------------------------------------------------*
*FORM ADD_MDVL_TO_MDMMX USING
*                         WERKS LIKE AM61X-WERKS
*                         MDVL STRUCTURE MDVL
*                       CHANGING
*                         PORTRC LIKE AM61X-RCODE.
*  STATICS:
*    MATNR_OLD LIKE CM61D-MATNR.        "Vorhergehende Materialnummer
** Intra-Material-Parallelisierung (aktivierbar über MOD)
*  DATA:    PARMX   LIKE MDMM-PARMX.    "No. of tasks per material
*
**--> Return-Code zuruecksetzen
*  MOVE CHAR0 TO PORTRC.
*
**--> MDVL-Key aufloesen
*  CALL FUNCTION 'MDVMKEY_AUFLOESEN'
*       EXPORTING
*            MAFID   = MDVL-MAFID
*            MDVMKEY = MDVL-MDKEY
*       IMPORTING
*            DISST   = AM61X-DISST
*            MATNR   = AM61X-MATNR
*            WERKS   = AM61X-WERKS.
*
**--> Dispositionstufe ueberpruefen
*  PERFORM CHECK_DISPLEVEL CHANGING PORTRC.
*  IF NOT PORTRC EQ CHAR0.
**--> Dispostufenwechsel
*     EXIT.
*  ENDIF.
*
**--> Auswahl Planungswerk im Planungsumfang
*  IF  KZ_MULTI_PLANT EQ XFLAG          "Planungsumfang
*  AND NOT RM61X-PARAL IS INITIAL.
*    CHECK WERKS EQ SPACE               "CM61X-WERKS leer ?
*    OR    AM61X-WERKS IN SELPLANTX.
*  ELSE.
*    CHECK WERKS EQ SPACE
*    OR    WERKS EQ AM61X-WERKS.
*  ENDIF.
*
**--> Paketbildung: Paketgrössen-Check
**--> Pakete bilden mit Groesse psize + Rest desselben Materials
*  IF  AM61X-FLP01 GE PSIZE
*  AND AM61X-MATNR NE MATNR_OLD.
*    MOVE CHAR1 TO PORTRC.
*    EXIT.
*  ENDIF.
*
**--> MDMMX fuellen
*  CLEAR MDMMX.
*  MOVE AM61X-DISST TO MDMMX-DISST.
*  MOVE AM61X-MATNR TO MDMMX-MATNR.
*  MOVE AM61X-WERKS TO MDMMX-PLWRK.
*  MOVE MDVL-RESDT  TO MDMMX-RESDT.
*  MOVE MDVL-RESAL  TO MDMMX-RESAL.
*
*  IF  rm61x-paral EQ xflag
*  AND NOT gv_ltp_parallel_intramat IS INITIAL.
**--> Customer logic: identifiying MTO materials with long run times
*    CLEAR parmx.
*    PERFORM check_mat_parallel USING    mdmmx-plwrk
*                                        mdmmx-matnr
*                               CHANGING parmx.
**--> Einfügen Materialvormerkung Intramaterial-Parallelization
*    IF parmx GT 0.
*      mdmmx-parmx = parmx.
*      mdmmx-parct = 0.
*      DO parmx TIMES.
*        APPEND mdmmx.
*        mdmmx-parct = mdmmx-parct + 1.
*      ENDDO.
*      CLEAR mdmmx-parct.
*    ELSE.
*      APPEND MDMMX.
*    ENDIF.
*  ELSE.
**--> Einfügen Materialvormerkung Standard
*    APPEND MDMMX.
*  ENDIF.
*
**-->  Zähler MDMMX-Eintraege
*  AM61X-FLP01 = AM61X-FLP01 + 1.       "Zaehler hochsetzen
**--> Materialnummer merken
*  MOVE MDMMX-MATNR TO MATNR_OLD.
*
*ENDFORM.
