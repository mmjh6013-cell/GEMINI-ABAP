*&---------------------------------------------------------------------*
*&      Form  FCODE_GROKO_TAB
*&---------------------------------------------------------------------*
*      FCodes für TabStrip großer Kopf MD04   (THD)
*----------------------------------------------------------------------*


FORM FCODE_GROKO_TAB USING XCODE LIKE AM61R-XCODE
                           RCODE LIKE SY-SUBRC.
  DATA: TABNR  LIKE SY-TABIX.
  DATA: XCODE_ABAP LIKE AM61R-XCODE.
*  statics: tabnr_old like sy-tabix.        THD40B
  CLEAR RCODE.
  MOVE XCODE TO XCODE_ABAP.
  IF XCODE_ABAP(2) ='TB'.            "Es wurde ein Tabstrip gedrückt
    MOVE XCODE_ABAP+2(2) TO TABNR.
    READ TABLE GROKO_DYNP INDEX TABNR.
    MOVE GROKO_DYNP-DYNNR TO SUBSCREEN_GRKOPF.
    TABTC-ACTIVETAB = XCODE.           "Aktiven Tab setzen
    MOVE '1' TO RCODE.
    MOVE TABNR TO TABNR_OLD.
  ENDIF.
ENDFORM.                                              " FCODE_GROKO_TAB
