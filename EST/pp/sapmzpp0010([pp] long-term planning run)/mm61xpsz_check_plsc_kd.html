Program listing for: MM61XPSZ_CHECK_PLSC_KD 
*----------------------------------------------------------------------*
* Pruefen Planungszenario                                             *
*---------------------------------------------------------------------*
*       mit Warnmeldung, wenn Werk dem Szenario nicht zugeordnet      *
*----------------------------------------------------------------------*


FORM CHECK_PLSC_KD USING VALUE(WERKS) LIKE PLPT-PLWRK
                         PLSC STRUCTURE PLSC.
  DATA: SUBRC LIKE SY-SUBRC.
  IF PLSC-PSACT <> PSACT_ACTIVE.
*   Das Planungsszenario & ist nicht freigegeben
    MESSAGE E114(MD) WITH PLSC-PLSCN.
  ENDIF.
  IF PLSC-EINPL IS INITIAL.
*   Szenario &1 ist für Einzelplanung nicht vorgesehen
    MESSAGE E147(MD) WITH PLSC-PLSCN.
  ENDIF.
  IF NOT WERKS IS INITIAL.
    PERFORM SELECT_PLPT_WERKS USING PLSC-PLSCN WERKS SUBRC.
    IF SUBRC <> 0.
*     Szenario &1 ist für Kundenauftragswerk &2 nicht vorgesehen
      MESSAGE E146(MD) WITH PLSC-PLSCN WERKS.
    ENDIF.
  ENDIF.
ENDFORM.
