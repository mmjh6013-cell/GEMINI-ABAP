Program listing for: MM61XCMP_SET_FBYTE_MDAG 
*---------------------------------------------------------------------*
*       FORM SET_FBYTE_MDAG                                           *
*---------------------------------------------------------------------*
*       set format 'INTENSIFIED' for period with differences.         *
*---------------------------------------------------------------------*
*  -->  LIMIT   set format 'INTENSIFIED' if difference (in %) > LIMIT
*---------------------------------------------------------------------*


FORM SET_FBYTE_MDAG USING LIMIT.
  DATA: LIMIT_FLAG.
  LOOP AT MDAGX WHERE AEN01 <> SPACE.
    CLEAR LIMIT_FLAG.
    PERFORM COMPARE_PERCENT USING MDAGX-MNGD1 MDAGX-MNGA1
                                  LIMIT       LIMIT_FLAG.
    PERFORM COMPARE_PERCENT USING MDAGX-MNGD2 MDAGX-MNGA2
                                  LIMIT       LIMIT_FLAG.
    PERFORM COMPARE_PERCENT USING MDAGX-MNGD3 MDAGX-MNGA3
                                  LIMIT       LIMIT_FLAG.
    IF LIMIT_FLAG IS INITIAL
    AND MDAGX-MNGD1 = MDAGX-MNGA1      "no difference but AEN01 = X
    AND MDAGX-MNGD2 = MDAGX-MNGA2      "-> element exists only in
    AND MDAGX-MNGD3 = MDAGX-MNGA3      "one list !
    AND MDAGX-MNGD4 = MDAGX-MNGA4
    AND MDAGX-MNGD5 = MDAGX-MNGA5.
      IF MDAGX-FBYTE = FBYTE_STOCK_INTENSIFIED.
*        EXIT.
         CONTINUE.
      ELSE.
        MDAGX-FBYTE = FBYTE_ROW_INTENSIFIED.
      ENDIF.
      MODIFY MDAGX.
    ELSEIF LIMIT_FLAG = XFLAG.
      MDAGX-FBYTE = FBYTE_ROW_INTENSIFIED.
      MODIFY MDAGX.
    ENDIF.
  ENDLOOP.
ENDFORM.
