Program listing for: MM61XMDV_ADD_DBVM_TO_MDMMX 
*---------------------------------------------------------------------*
*       FORM ADD_DBVM_TO_MDMMX                                        *
*---------------------------------------------------------------------*
* Materialvormerkungen in interne Tabelle uebernehmen
*---------------------------------------------------------------------*
*  -->  DBVM    planning file entry                             (I)   *
*  -->  PORTRC  portion return code  = 1 if DISST changed       (O)   *
*                                  or about psize entries read
* ( append to internal table MDMMX )
*---------------------------------------------------------------------*


FORM add_dbvm_to_mdmmx USING
                         dbvm  STRUCTURE dbvm       "Arbeitsbereich
                       CHANGING
                         p_matnr LIKE am61x-matnr "Zeiger gel. Mat.
                         portrc LIKE am61x-rcode.   "Paketende-Check
  STATICS:
    matnr_old        LIKE cm61d-matnr,        "Vorhergehende Materialnummer
    lv_no_first_call TYPE boolean,
    lv_psize         TYPE i,
    lv_curr_psize    TYPE i.

*@001-Begin
* Kennung, ob Material gelistet ist
* DATA: L_KZGELISTET       TYPE C.
*@001-End
  DATA:    parmx   LIKE mdmm-parmx.    "No. of tasks per material
  DATA:    lv_max_psize TYPE char10,                       "NOTE 2121225
           lv_min_psize TYPE char10.


*--> Return-Code zuruecksetzen
  MOVE char0 TO portrc.

*--> Aktuelles Material zuweisen
  MOVE dbvm-disst TO am61x-disst.
  MOVE dbvm-matnr TO am61x-matnr.
  MOVE dbvm-berid TO am61x-berid.
*--> Werk zu Dispobereich bestimmen
* READ TABLE PLANTX WITH KEY BERID = AM61X-BERID.          "NOTE 356566
*      TODO LATER : Performance!!                          "NOTE 356566
* MOVE PLANTX-PLWRK TO AM61X-WERKS.                        "NOTE 356566
  DATA: l_mdlv LIKE mdlv.                                  "NOTE 356566
  PERFORM read_mdlv USING    am61x-berid                   "NOTE 356566
                    CHANGING l_mdlv.                       "NOTE 356566
  MOVE l_mdlv-werzg TO am61x-werks.                        "NOTE 356566



*--> Zusatz-Check/-Selektion RETAIL
*@001-Begin
*  NUR für Handelsbetriebe Listungsprüfung durchführen
* IF NOT T001W-VLFKZ IS INITIAL.
*   Default: Material immer gelistet
*   MOVE XFLAG TO L_KZGELISTET.
*   PERFORM CHECK_LISTUNG CHANGING L_KZGELISTET.
*   IF L_KZGELISTET IS INITIAL.
*     Material im Zeiger merken
*     P_MATNR = AM61X-MATNR.
*     EXIT.
*   ENDIF.
* ENDIF.
*@001-End

*--> Easy variation of PSIZE by S/G-Parameter
  IF lv_no_first_call IS INITIAL.
* Maximum
    GET PARAMETER ID 'PPH_MAX_PSIZE' FIELD lv_max_psize.
    IF  lv_max_psize IS NOT INITIAL
    AND lv_max_psize GE 1.
      lv_psize = lv_max_psize.
    ELSE.
      lv_psize = psize.
    ENDIF.
* Minimum
    GET PARAMETER ID 'PPH_MIN_PSIZE' FIELD lv_min_psize.
    IF  lv_min_psize IS NOT INITIAL
    AND lv_min_psize GE 1.
      gv_hana_psize = lv_min_psize.
    ENDIF.
*--> Size PFE Read depending on optimal package size and number of tasks
    IF gv_number_tasks IS NOT INITIAL.
      lv_curr_psize = lv_psize * gv_number_tasks.
    ELSE.
      lv_curr_psize = lv_psize.
    ENDIF.
    lv_no_first_call = abap_true.
  ENDIF.


*--> Pakete bilden mit Groesse psize + alles zu demselben Material
  IF  am61x-flp01 GE lv_curr_psize
  AND am61x-matnr NE matnr_old.
    MOVE char1 TO portrc.
    CLEAR lv_no_first_call.
    EXIT.
  ENDIF.

*--> MDMMX fuellen
  CLEAR mdmmx.
  MOVE am61x-werks  TO mdmmx-plwrk.
  MOVE am61x-disst  TO mdmmx-disst.
  MOVE am61x-matnr  TO mdmmx-matnr.
* IF NOT t000md-disfg IS INITIAL.
    MOVE am61x-berid  TO mdmmx-berid.
* ENDIF.
  MOVE dbvm-resdt   TO mdmmx-resdt.
  MOVE dbvm-resal   TO mdmmx-resal.
  MOVE dbvm-rhytd   TO mdmmx-rhytd.
*

  IF  rm61x-paral EQ xflag
  AND NOT gv_parallel_intramat IS INITIAL.
*--> Customer logic: identifiying MTO materials with long run times
    CLEAR parmx.
    PERFORM check_mat_parallel USING    mdmmx-plwrk
                                        mdmmx-matnr
                               CHANGING parmx.
*--> Einfügen Materialvormerkung Intramaterial-Parallelization
    IF parmx GT 0.
      mdmmx-parmx = parmx.
      mdmmx-parct = 0.
      DO parmx TIMES.
        APPEND mdmmx.
        mdmmx-parct = mdmmx-parct + 1.
      ENDDO.
      CLEAR mdmmx-parct.
    ELSE.
      APPEND mdmmx.
    ENDIF.
  ELSE.
*--> Einfügen Materialvormerkung Standard
    APPEND mdmmx.
  ENDIF.

**--> Akt. Dispostufe festlegen
*  MOVE am61x-disst TO am61x-akdst.

*-->  Zähler MDMMX-Eintraege
  am61x-flp01 = am61x-flp01 + 1.       "Zaehler hochsetzen
*--> Materialnummer merken
  MOVE mdmmx-matnr TO p_matnr.         "Zeiger gelesene Mat. DBVM
  MOVE mdmmx-matnr TO matnr_old.       "Vorgängermat. für Mat.block

ENDFORM.
