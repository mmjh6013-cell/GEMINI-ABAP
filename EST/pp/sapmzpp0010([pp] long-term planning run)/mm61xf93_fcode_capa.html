Program listing for: MM61XF93_FCODE_CAPA 
*----------------------------------------------------------------------*
* FCODE: Kapa-Planung  aus PLAF-Bearbeitung
*----------------------------------------------------------------------*


FORM FCODE_CAPA.
  DATA: MRPPP LIKE MT61D-MRPPP.
  IF AM61X-PROFL IS INITIAL
  OR AM61X-STYPE IS INITIAL.
  IF MT61D-MRPPP IS INITIAL.
    MRPPP = T399D-MRRPP.
  ELSE.
    MRPPP = MT61D-MRPPP.
  ENDIF.
*--> Planungsart und Profil (wg. Periodenart) bestimmen
    CALL FUNCTION 'MPS_CAPA_SET_PARAMETER'
         EXPORTING
              PROFL_IMP  = AM61X-PROFL
              STYPE_IMP  = AM61X-STYPE
              MRPPP      = MRPPP
         IMPORTING
              PROFILE_ID = AM61X-PROFL
              SCHED_TYPE = AM61X-STYPE
         EXCEPTIONS
              CANCELLED  = 01.
    IF SY-SUBRC <> 0.
      EXIT.
    ENDIF.
  ENDIF.
*--> Pruefen Planauftragsnummer
  IF MPPA-PLNUM EQ SPACE.
*--> Nummer muss hier vergeben werden, damit PLNUM als Key vorhanden
    IF CM61X-PLSCN IS INITIAL.
      PERFORM NEW_NUMBER USING 'PLAF' T460D-NUMKI MPPA-PLNUM.
    ELSE.
      PERFORM NEW_NUMBER USING 'PLAF' T399D-NKSAF MPPA-PLNUM.
    ENDIF.
    PERFORM PLAF_SPERREN USING MPPA-PLNUM.
    PERFORM MPS_CAPACITY_OVERVIEW USING MPPA AM61X-PROFL AM61X-STYPE.
  ELSE.
    PERFORM MPS_CAPACITY_OVERVIEW USING MPPA AM61X-PROFL AM61X-STYPE.
  ENDIF.
ENDFORM.
