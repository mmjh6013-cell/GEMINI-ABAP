Program listing for: MM61XF92_FCODE_BVUT 
*----------------------------------------------------------------------*
* FCODE: Bestellvorschlag umterminieren                                *
*----------------------------------------------------------------------*


FORM FCODE_BVUT.
*--> Umterminierungstermin ermitteln
  PERFORM CHECK_UMDAT_BV.
  IF RM61X-UMDAT IS INITIAL.
    MOVE CHAR1 TO AM61X-RCODE.
    EXIT.
  ENDIF.
*--> Bestellvorschlagstermine verschieben
  CASE AM61X-DELKZ.
    WHEN PLAUF.
*--> Termine verschieben
      PERFORM SHIFT_TERMINE_MPPA.
*--> MPPA nach MDEZ uebernehmen
      PERFORM MOVE_MPPA_TO_MDEZ_PL.
    WHEN SAAUF.
*--> Termine verschieben
      PERFORM SHIFT_TERMINE_MPPA.
*--> MPPA nach MDEZ uebernehmen
      PERFORM MOVE_MPPA_TO_MDEZ_SA.
    WHEN BSANF.
*--> Termine verschieben
      PERFORM SHIFT_TERMINE_MPBA.
*--> MPBA nach MDEZ uebernehmen
      PERFORM MOVE_MPBA_TO_MDEZ.
    WHEN LPEIN.
*--> Termine verschieben
      PERFORM SHIFT_TERMINE_MPLP.
*--> MPLP nach MDEZ uebernehmen
      PERFORM MOVE_MPLP_TO_MDEZ.
*--> Ungültiges DELKZ
    WHEN OTHERS.
      MESSAGE A888.
  ENDCASE.
*--> Reset Umterminierungstermin
  CLEAR RM61X-UMDAT.
*--> Wenn Periodensummen angezeigt werden
  IF MDST-ANZEI = PSSI_ACTIV.
    PERFORM CHECK_AENDERUNG_MDEZ.            "Einzelzeile aktualisieren
    PERFORM ATP_BERECHNEN_MDEZX.             "ATP-Menge aktualisieren
    PERFORM PUT_MDEZX_MDSUX.                 "Summenzeilen aktualisieren
    PERFORM SET_MDSU_POSITION_01 USING XFLAG.   "Aufsetzpunkt bestimmen
  ENDIF.
ENDFORM.
