FORM SET_QUOTIERUNG_MDPS.
*--> Prüfen Planungswerk
  IF MDPS-WRK01 NE MDKP-PLWRK.
    EXIT.
  ENDIF.
*--> Pruefen Quotierungskennzeichen
  IF CM61M-USEQU EQ SPACE.
    EXIT.
  ENDIF.
*--> Quotenfortschreibung
  IF  ( NOT MDPS-QUNUM IS INITIAL )
  AND ( NOT MDPS-QUPOS IS INITIAL ).
     MOVE MDPS-QUNUM TO EQUPK-QUNUM.
     MOVE MDPS-QUPOS TO EQUPK-QUPOS.
     READ TABLE EQUPX WITH KEY EQUPK BINARY SEARCH.
     IF SY-SUBRC EQ 0.
       EQUPX-QUMNG = EQUPX-QUMNG + MDPS-MNG01.
       MODIFY EQUPX INDEX SY-TABIX.
     ENDIF.
  ENDIF.
ENDFORM.
