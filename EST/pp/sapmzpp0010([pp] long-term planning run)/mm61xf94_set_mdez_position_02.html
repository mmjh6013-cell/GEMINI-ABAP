* Erste Anzeigeposition fuer MDEZ ermitteln; Key aus MDPS              *

FORM SET_MDEZ_POSITION_02.
  MOVE MDPS-PLAAB TO EZKEY-PLAAB.
  MOVE MDPS-PLANR TO EZKEY-PLANR.
*--> Sortheader anpassen
  IF  MDST-VRFWE  EQ XFLAG
  AND MDPS-PLUMI EQ PLUSX.
    MOVE MDPS-DAT01 TO EZKEY-SORT0.
  ELSE.
    MOVE MDPS-DAT00 TO EZKEY-SORT0.
  ENDIF.
  MOVE MDPS-TAG00 TO EZKEY-TAG00.
  MOVE MDPS-SORT1 TO EZKEY-SORT1.
  MOVE MDPS-SORT2 TO EZKEY-SORT2.
  READ TABLE MDEZX WITH KEY EZKEY BINARY SEARCH.
  IF  SY-SUBRC EQ 0
  AND SY-TABIX GE 2
  AND SY-TABIX GT MDEZX-LOOPS.
    MDEZX-XLINE = SY-TABIX - 1.
  ENDIF.
ENDFORM.
