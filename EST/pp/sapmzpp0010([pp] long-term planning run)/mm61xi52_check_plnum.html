*----------------------------------------------------------------------*
* Pruefen Planauftragsnummer                                           *
*----------------------------------------------------------------------*


MODULE CHECK_PLNUM INPUT.
*--> Eingabe überprüfen
  IF MPPA-PLNUM EQ SPACE.
    EXIT.
  ENDIF.
*--> Planauftragsexistenz überprüfen
  PERFORM READ_PLAF USING MPPA-PLNUM.
  IF SY-SUBRC EQ 0.
    MESSAGE E002 WITH MPPA-PLNUM.
  ENDIF.
*--> Nummer gegen Nummerkreis überprüfen
  PERFORM CHECK_NUMBER USING 'PLAF' T460D-NUMKE MPPA-PLNUM.
*--> Planauftragsnummer sperren
  PERFORM PLAF_SPERREN USING MPPA-PLNUM.
ENDMODULE.
