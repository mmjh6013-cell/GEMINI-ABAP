Program listing for: MM61XC02_CHECK_DISMM 
*----------------------------------------------------------------------*
* Dispostufe ueberpruefen (check low-level-code)                       *
*----------------------------------------------------------------------*


FORM CHECK_DISMM USING DISMM LIKE T438A-DISMM.
*--> Returncode vorbesetzen
  MOVE CHAR1 TO AM61X-RCODE.
*--> Dispositionsmerkmal ueberpruefen
  IF DISMM NE SPACE.
    PERFORM READ_T438A USING DISMM.
    IF SY-SUBRC NE 0.
      EXIT.
    ENDIF.
*@001-Begin
*   IF T438A-DISVF NE DISVFN.
    IF T438A-DISVF <> DISVFN AND T438A-DISVF <> DISVFW.
*@001-End
      MOVE CHAR0 TO AM61X-RCODE.
    ENDIF.
  ENDIF.
*--> Prüfen verbrauchgesteuerte Disposition bei Langfristplanung
  IF T438A-DISVF EQ DISVFB
  OR T438A-DISVF EQ DISVFS.
    IF  CM61X-PLOBJ EQ MDOBJL
    AND CM61X-SBFLG NE XFLAG.
      MOVE CHAR1 TO AM61X-RCODE.
    ENDIF.
  ENDIF.
ENDFORM.
