*---------------------------------------------------------------------*
*       FORM FRAME_TEXTS                                              *
*---------------------------------------------------------------------*
*       set frame texts depending on STATU and PERIOD
*---------------------------------------------------------------------*
*  -->  STATU   display status                               (I)
*  -->  PERIOD  period description                           (I)
*  -->  TEXT1   text parameters (choice) for frame 1         (I)
*  -->  TEXT2   text parameters (choice) for frame 2         (I)
*  -->  TEXT_FRAME1                                          (O)
*  -->  TEXT_FRAME1                                          (O)
*---------------------------------------------------------------------*


FORM FRAME_TEXTS USING
        STATU
        PERIOD
        TEXT1 STRUCTURE TEXT1
        TEXT2 STRUCTURE TEXT2
        TEXT_FRAME1
        TEXT_FRAME2.
  DATA:
    CHAR53(53).
*
  CASE STATU.
    WHEN STATU_DLI1.
      TEXT_FRAME1 = TEXT1-FRAME_DLI1.
      CHAR53      = TEXT2-FRAME_DLI1.
      REPLACE '&1' WITH PERIOD INTO CHAR53.
      CONDENSE CHAR53.
      TEXT_FRAME2 = CHAR53.
    WHEN STATU_DLI2.
      TEXT_FRAME1 = TEXT1-FRAME_DLI2.
      CHAR53      = TEXT2-FRAME_DLI2.
      REPLACE '&1' WITH PERIOD INTO CHAR53.
      CONDENSE CHAR53.
      TEXT_FRAME2 = CHAR53.
    WHEN STATU_DIFF.
      TEXT_FRAME1 = TEXT1-FRAME_DIFF.
      CHAR53      = TEXT2-FRAME_DIFF.
      REPLACE '&1' WITH PERIOD INTO CHAR53.
      CONDENSE CHAR53.
      TEXT_FRAME2 = CHAR53.
  ENDCASE.
ENDFORM.
