Program listing for: MM61XF95_FCODE_D0300_TC 
*----------------------------------------------------------------------*
* Bearbeiten Bestellvorschlag                                          *
*----------------------------------------------------------------------*


FORM FCODE_D0300_TC CHANGING EV_FOUND TYPE BOOL.
*--> Vorraussetzung: Split-screen
  IF  MDST-ANZEI <> EZSI_ACTIV
  AND MDST-ANZEI <> PSSI_ACTIV
  AND MDST-ANZEI <> PSEZSI_ACTIV.
    EV_FOUND = GC_FALSE. EXIT.
  ENDIF.
  EV_FOUND = GC_TRUE.
*--> Pruefen FCODE
  CASE AM61X-XCODE.
*--> Bearbeitung abbrechen
    WHEN FC-XBAC.
      PERFORM BACK_FROM_BV. EXIT.
*--> Bearbeiten Kontierung
    WHEN FC-BEKT.
      PERFORM FCODE_BEKT. EXIT.
*--> Anzeihen Konfigurierung
    WHEN FC-CONF.
      PERFORM FCODE_CONF. EXIT.
*--> Stückliste auflösen
    WHEN FC-STAL.
      PERFORM FCODE_STAL. EXIT.
*--> MatKomponenten pflegen
    WHEN FC-MKBA.
      PERFORM FCODE_MKBA. EXIT.
*--> MatKomponenten erfassen
    WHEN FC-MKER.
      PERFORM FCODE_MKER. EXIT.
*--> Prüfen Verf.barkeit Mat.Komponneten
    WHEN FC-MKPV.
      PERFORM FCODE_MKPV. EXIT.
*--> Anzeigen Dokument zum Bestellvorschlag
    WHEN FC-AZDK.
      IF MDST-ANZEI = EZSI_ACTIV. "F-Code nur auswerten bei Splitscr.
        PERFORM FCODE_AZDK. EXIT.
      ENDIF.
*--> Umterminieren
    WHEN FC-BVUT.
      PERFORM FCODE_BVUT. EXIT.
*--> Bestellvorschlag loeschen
    WHEN FC-BVDL.
      PERFORM FCODE_BVDL.
      PERFORM BACK_TO_UEBDY. EXIT.
*--> Bestellvorschlag uebernehmen
    WHEN FC-TAKE.
      PERFORM FCODE_TAKE. PERFORM BACK_TO_UEBDY. EXIT.
*--> Bedarfsverursacher
   WHEN FC-BDVR.
      IF MDST-ANZEI = EZSI_ACTIV.
        PERFORM FCODE_BDVR_VR. EXIT.
      ENDIF.
*--> Anzeigen Ausnahmemeldung
    WHEN FC-AZAM.
      PERFORM FCODE_AZAM_TC. EXIT.
*--> Verteilung anzeigen
    WHEN FC-VERT.
      PERFORM FCODE_VERT. EXIT.
*--> Terminierungsdaten des Planauftrags anzeigen
    WHEN FC-AZTG.
      PERFORM FCODE_AZTG USING AM61X-STYPE MPPA-PLNUM. EXIT.
*--> Sichern bei MRP im Hauptspeicher
    WHEN 'SAVE'.
      PERFORM FCODE_TAKE.
      SET SCREEN 0. LEAVE SCREEN.
  ENDCASE.
*--> Sonst: Fcode nicht gefunden
  EV_FOUND = GC_FALSE.
ENDFORM.
