FORM GET_EZ_FROM_MDEZ USING DLART.
  DATA: lv_maybechanged TYPE bool,
        ls_message TYPE messa.                           "note 600940

*--> Zeilenindex für die Tabelle MDEZX ermitteln
  AM61X-ALINE = MDEZX-XLINE + SY-STEPL - 1.
  IF  AM61X-ALINE GT MDEZX-MLINE.
    MESSAGE E112.
  ENDIF.
*--> Tabelleneintrag aus MDEZX nachlesen
  READ TABLE MDEZX INDEX AM61X-ALINE.
  IF SY-SUBRC NE 0.
    MESSAGE E190 WITH AM61X-ALINE 'MDEZX'.
  ENDIF.
*--> Einzelzeile sichern
  MOVE MDEZX TO MDEZS.
  MOVE AM61X-ALINE TO MDEZS-XLINE.
*--> Dispositionszeile aus MDPSX nachlesen
  READ TABLE MDPSX INDEX MDEZS-ALINE.
  IF SY-SUBRC NE 0.
    MESSAGE E190 WITH MDEZS-ALINE 'MDPSX'.
  ENDIF.
*--> check changeability (note 600940)
  PERFORM may_be_changed USING    mdpsx
                                  dlart
                         CHANGING lv_maybechanged
                                  ls_message.
  IF lv_maybechanged = gc_false.
    IF ls_message-msgid IS INITIAL
    OR ls_message-msgno IS INITIAL.
      MESSAGE E111.
    ELSE.
      MESSAGE ID     ls_message-msgid
              TYPE   'E'
              NUMBER ls_message-msgno
              WITH   ls_message-msgv1
                     ls_message-msgv2
                     ls_message-msgv3
                     ls_message-msgv4.
    ENDIF.
  ENDIF.
*--> Dispositionszeile sichern
  MOVE MDPSX TO MDPSS.
  MOVE MDEZS-ALINE TO MDPSS-XLINE.
ENDFORM.
