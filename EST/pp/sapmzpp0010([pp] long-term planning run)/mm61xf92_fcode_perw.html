Program listing for: MM61XF92_FCODE_PERW 
*----------------------------------------------------------------------*
* FCODE: Periodenwechsel                                               *
*----------------------------------------------------------------------*


FORM FCODE_PERW.
  DATA: PRTAB_MLINE TYPE I.
  DESCRIBE TABLE PRTAB LINES PRTAB_MLINE.
  MDST-XLINE = MDST-XLINE + 1.
  IF MDST-XLINE GT PRTAB_MLINE.
    MDST-XLINE = 1.
  ENDIF.
  READ TABLE PRTAB INDEX MDST-XLINE.
  IF PRTAB-FLG01 EQ PKPER.
    IF MT61D-MRPPP EQ SPACE.
      MOVE T399D-MRRPP TO MDST-MRPPP.
    ELSE.
      MOVE MT61D-MRPPP TO MDST-MRPPP.
    ENDIF.
    IF MDST-MRPPP IS INITIAL.
      MOVE MONAT TO PRTAB-FLG01.
    ENDIF.
  ENDIF.
  IF PRTAB-FLG01 EQ PRAST.
    MOVE T399D-PRAST TO MDST-PRAST.
  ENDIF.
  MOVE PRTAB-FLG01 TO MDST-INPER.
*--> Tabelle MDSUX neu aufbauen
  PERFORM PUT_MDEZX_MDSUX.
*--> Maximale Zeilenanzahl MDSUX feststellen
  DESCRIBE TABLE MDSUX LINES MDSUX-MLINE.
*--> Maximaler Ausschnitt
  MDSUX-VLINE = 1.
  MOVE MDSUX-MLINE TO MDSUX-BLINE.
  MDSUX-XLINE = 1.
*--> TC-Topline setzen
  MOVE MDSUX-XLINE TO TC_PS-TOP_LINE.
ENDFORM.
