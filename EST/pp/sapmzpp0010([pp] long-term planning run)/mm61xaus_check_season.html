Program listing for: MM61XAUS_CHECK_SEASON 
*@002-Begin
*----------------------------------------------------------------------
* Prüfen, ob  der Artikel in Aktion ist, wenn ja Kennung setzen
*----------------------------------------------------------------------


FORM CHECK_SEASON USING VALUE(MATNR) LIKE MARA-MATNR
*@004-Anfang
                        VALUE(DISMM) LIKE MDKP-DISMM
                        VALUE(DISVF) LIKE MDKP-DISVF
*@004-Ende
                        KZSEASN TYPE C.
*@004-Anfang
* Ein Artikel kann nur ein Saisonartikel sein wenn das als Dispomerkmal
* VS und als Dispoverfahren 'R' (= Rhytmisch) gepflegt ist.
  IF DISMM <> 'VS' OR
     DISVF <> 'R'.
     CLEAR KZSEASN.
     EXIT.
  ENDIF.
*@004-Ende

  CALL FUNCTION 'SEASON_ON_ARTNR_FIND'
     EXPORTING
          FDISPLAY           = ' '
          FMATNR             = MATNR
     EXCEPTIONS
          SEASON_NOT_FOUND   = 1
          MATERIAL_NOT_FOUND = 2
          OTHER_ERRORS       = 3
          OTHERS             = 4.

  IF SY-SUBRC <> 0.
    CLEAR KZSEASN.
  ELSE.
    KZSEASN = XFLAG.
  ENDIF.
ENDFORM.
