Program listing for: MM61XF32_BEARBEITEN_MATERIAL07 
*----------------------------------------------------------------------*
*  Nächstes Material bei mehrstufiger Planung bearbeiten
*----------------------------------------------------------------------*


FORM BEARBEITEN_MATERIAL_MP USING RDMAT.
*--> Materialabhängige Tabellen zurücksetzen
  CLEAR MDKP.
  CLEAR MDSTA.
  CLEAR STATN.
  PERFORM INIT_SUCHSTEUERUNG.
*--> Lesen und pruefen Materialstamm
  IF RDMAT EQ XFLAG.
    PERFORM READ_CHECK_MATERIAL_MP.
    IF AM61X-RCODE NE CHAR0.
      EXIT.
    ENDIF.
  ENDIF.
*--> Materialdaten ergaenzen
  PERFORM ERGAENZEN_MATERIAL_IP.
*--> Pruefen RESET-KZ
  PERFORM CHECK_RESET_KZ_EP.
*--> Haltepunkt anzeigen
  PERFORM SHOW_NEXT_HALTEPUNKT.
*--> Send Message
*  PERFORM send_message_900 USING cm61d-matnr cm61d-werks cm61d-berid.
*--> Disponieren Material
  PERFORM DISPONIEREN_MATERIAL_BT.
  IF AM61X-RCODE NE CHAR0.
    PERFORM CHECK_RESET_HALTEPUNKT.
    EXIT.
  ENDIF.
*--> Dispositionsergebnis anzeigen
  PERFORM SHOW_DISPO_ERGEBNIS_MP.
*--> Stuecklisten aufloesen nach Dialog
  IF NOT CM61X-ANZDL IS INITIAL.
    PERFORM STUECKLISTE_AUFLOESEN_BT.
    IF AM61X-RCODE NE CHAR0.
      EXIT.
    ENDIF.
  ENDIF.
*--> Dispositionsergebnis verbuchen
  PERFORM CALL_VERBUCHUNG_MP.
  IF AM61X-RCODE NE CHAR0.
    EXIT.
  ENDIF.
*--> Verarbeitungskennzeichen in CM61D sichern (Statistik)
  PERFORM SAVE_KZXXX_CM61D.
*--> Returncode zuruecksetzen
  MOVE CHAR0 TO AM61X-RCODE.
ENDFORM.
