Program listing for: MM61XC01_RESET_AUSSL 
*----------------------------------------------------------------------*
* Entfernen Ausnahmemeldung
*----------------------------------------------------------------------*


FORM RESET_AUSSL USING DELAS LIKE MDPS-AUSSL         "zu entfernende
              CHANGING AKTAS LIKE MDPS-AUSSL         "1. Priorität
                       OLDAS LIKE MDPS-AUSSL.        "2. Priorität
*--> Falls zu entfernende Ausnahme nicht vorhanden: RAUS!
  IF  DELAS NE AKTAS
  AND DELAS NE OLDAS.
    EXIT.
  ENDIF.
*--> Zu entfernende Ausnahmemeldung als zweite Ausnahme
  IF DELAS EQ OLDAS.
    CLEAR OLDAS.
    EXIT.
  ENDIF.
*--> Zu entfernende Ausnahmemeldung als erste Ausnahme
  IF DELAS EQ AKTAS.
    MOVE OLDAS TO AKTAS.
    CLEAR OLDAS.
    EXIT.
  ENDIF.
ENDFORM.
