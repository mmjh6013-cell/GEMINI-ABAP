FORM MDEZ_VORBEREITEN_VR
     USING IV_SELECTED_LINE LIKE SY-TABIX.

  DATA: STORE_MDEZX LIKE MDEZX.

  read table mdezx index iv_selected_line.              "new SA 45B
  MOVE MDEZX TO STORE_MDEZX.           "aktuelle mdezx speichern
*--> Loeschen Formatbyte alt MDEZ
  LOOP AT MDEZX WHERE FBYTE = CHAR2.
    MOVE SPACE TO MDEZX-FBYTE.
    MODIFY MDEZX.
  ENDLOOP.
  MOVE STORE_MDEZX TO MDEZX.
*--> Setzen Formatbyte neu
  MOVE CHAR2 TO MDEZX-FBYTE.
  MODIFY MDEZX INDEX IV_SELECTED_LINE.

*--> Anzeige neu positionieren
  MDEZX-XLINE = IV_SELECTED_LINE - 1.
  IF MDEZX-XLINE LT 1.
    MDEZX-XLINE = 1.
  ENDIF.

*--> Anfangszeile für Tablecontrol setzen
  MOVE MDEZX-XLINE TO TC_EZ-TOP_LINE.

ENDFORM.
