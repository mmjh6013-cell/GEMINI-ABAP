Program listing for: MM61XDBR_MATERIAL_MRP_AREA_CHE 
*---------------------------------------------------------------------*
*       FORM MATERIAL_MRP_AREA_CHECK                                  *
*---------------------------------------------------------------------*
*       checks consistency mrp area / plant                           *
*---------------------------------------------------------------------*
*  -->  BERID       mrp area                                          *
*  -->  WERKS       plant                                             *
*---------------------------------------------------------------------*


FORM MATERIAL_MRP_AREA_CHECK USING MATNR LIKE MT61D-MATNR
                                   BERID LIKE MDLV-BERID.

*--> Wenn Dispobereich oder Material nicht gefüllt --> raus.
  IF BERID      IS INITIAL
  OR MATNR      IS INITIAL.
    EXIT.
  ENDIF.
*--> Pruefung unnoetig bei Werks-DB
  PERFORM READ_MDLV USING BERID CHANGING MDLV.
  IF MDLV-BERTY EQ '01'.               "Werks-DB
    EXIT.
  ENDIF.
*-->Prüfen ob Material zu Dispobereich gehört
  CALL FUNCTION 'MDMA_SINGLE_READ'
       EXPORTING
*         KZRFB      = ' '
*         MAXTZ      = 0
            MATNR      = MATNR
            BERID      = BERID
            MDMA_GEN   = 'X'                              "note 2991587
*    IMPORTING
*         WMDMA      =
       EXCEPTIONS
            WRONG_CALL = 1
            NOT_FOUND  = 2
            OTHERS     = 3.

  IF SY-SUBRC <> 0.
* Material &1 ist für den Dispobereich &2 nicht vorgesehen.
    MESSAGE E319(MD) WITH MATNR BERID.
  ENDIF.
ENDFORM.
