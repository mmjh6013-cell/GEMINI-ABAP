FORM CHECK_DISST USING DISST.
*--> Pruefen maximale Dispositionsstufe
  IF CM61D-DISST EQ MAXDS.
    MOVE CHAR0 TO AM61X-RCODE.
    EXIT.
  ENDIF.
*--> Pruefen aktuelle Dispositionsstufe
  IF CM61D-DISST EQ DISST.
    MOVE CHAR0 TO AM61X-RCODE.
  ELSE.
    MOVE CHAR1 TO AM61X-RCODE.
  ENDIF.
ENDFORM.
