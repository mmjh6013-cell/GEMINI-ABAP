Program listing for: MM61XMEM_ORDER_FIND_MDPSX 
*----------------------------------------------------------------------*
*  ORDER_FIND_MDPSX                                                    *
*----------------------------------------------------------------------*


FORM ORDER_FIND_MDPSX
     USING    IS_MDPS    LIKE MDPS
     CHANGING EV_INDEX   LIKE SY-TABIX
              EV_FOUND   TYPE BOOL.

  DATA: LV_INDEX LIKE SY-TABIX.

*--> Returncode setzen
  EV_FOUND = GC_FALSE.

*--> Aufsetzen
  READ TABLE MDPSX
       WITH KEY PLAAB = IS_MDPS-PLAAB
                PLANR = IS_MDPS-PLANR
                DAT00 = IS_MDPS-DAT00
       BINARY SEARCH TRANSPORTING NO FIELDS.
  IF SY-SUBRC = 8. EXIT. ENDIF.
  LV_INDEX = SY-TABIX.

*--> Von da weitersuchen
  LOOP AT MDPSX FROM LV_INDEX.

*--> Suchen beenden wenn naechster Tag erreicht
    IF MDPSX-PLAAB <> IS_MDPS-PLAAB
    OR MDPSX-PLANR <> IS_MDPS-PLANR.
      EXIT.
    ENDIF.

*--> Pruefen ob richtiger Eintrag erreicht
    CHECK MDPSX-DELKZ = IS_MDPS-DELKZ.
    IF IS_MDPS-DELKZ = FEAUF
    OR IS_MDPS-DELKZ = BAREZ
    OR IS_MDPS-DELKZ = NEAUF.
      CHECK MDPSX-DEL12 = IS_MDPS-DEL12.
    ELSE.
      CHECK MDPSX-DELNR = IS_MDPS-DELNR.
    ENDIF.
    CHECK MDPSX-DELPS = IS_MDPS-DELPS.
    CHECK MDPSX-DELET = IS_MDPS-DELET.
    EV_INDEX = SY-TABIX.
    EV_FOUND = GC_TRUE.
    EXIT.
  ENDLOOP.
ENDFORM.
