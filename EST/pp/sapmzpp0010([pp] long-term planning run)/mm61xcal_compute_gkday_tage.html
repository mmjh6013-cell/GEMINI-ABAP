Program listing for: MM61XCAL_COMPUTE_GKDAY_TAGE 
*----------------------------------------------------------------------*
* Periodenende/Periodenanfang fuer variable Periode bestimmen
*----------------------------------------------------------------------*


FORM COMPUTE_GKDAY_TAGE USING GKDAY TYPE D
                              PERAZ TYPE P
                              FABKL LIKE T001W-FABKL.
  PERFORM CONVERT_GKDAY_FKDAY_MINUS USING GKDAY FABKL.
  MOVE MDCAL-GKDAY TO MDCAL-PRANF.
  MDCAL-FKDAY = MDCAL-FKDAY + PERAZ.
  MDCAL-FKDAY = MDCAL-FKDAY - 1.
  PERFORM CONVERT_FKDAY_GKDAY USING MDCAL-FKDAY FABKL.
  MOVE MDCAL-GKDAY TO MDCAL-PREND.
  CLEAR MDCAL-PRPER.
ENDFORM.
