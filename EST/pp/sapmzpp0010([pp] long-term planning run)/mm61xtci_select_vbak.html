Program listing for: MM61XTCI_SELECT_VBAK 
*-----------------------------------------------------------------------
*   Kunde bei Lieferungen von VBAK (Vertriebsbeleg Kopfdaten) lesen  /
*        Anzeige in MD04 / Auftrag
*-----------------------------------------------------------------------


FORM SELECT_VBAK USING VBELN.
  STATICS: VBELN_OLD LIKE VBAK-VBELN.
  CHECK VBELN_OLD NE VBELN.
  SELECT SINGLE KUNNR FROM VBAK INTO VBAK-KUNNR
        WHERE VBELN EQ VBELN.
  IF SY-SUBRC NE 0.
    CLEAR VBAK-KUNNR.
  ENDIF.
  MOVE VBELN TO VBELN_OLD.
ENDFORM.
