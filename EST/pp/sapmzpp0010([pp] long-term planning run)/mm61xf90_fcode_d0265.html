Program listing for: MM61XF90_FCODE_D0265 
*----------------------------------------------------------------------*
* Bearbeiten Funktionscode 'Uebersicht Bestellvorschlaege'
*----------------------------------------------------------------------*


FORM FCODE_D0265.
*--> Pruefen Funktionscode
  CASE AM61X-XCODE.
*--> Back zum Aufruf
  WHEN FC-XBAC.
    MOVE CHAR1 TO AM61X-RCODE.
    SET SCREEN 0.
    EXIT.
*--> Bestellvorschlag auswaehlen
  WHEN FC-CSEL.
    PERFORM FCODE_CSEL_ID.
    IF AM61X-RCODE EQ CHAR0.
      MOVE MDEZX-DELKZ TO AM61X-DELKZ.
      MOVE PSSI_ACTIV TO MDST-ANZEI.
      SET SCREEN 0.
      LEAVE SCREEN.
    ENDIF.

    EXIT.
*--> Pruefen Blaettern oder ERROR
  WHEN OTHERS.
    IF AM61X-XCODE = FC-PNXT
    OR AM61X-XCODE = FC-PPRE
    OR AM61X-XCODE = FC-PBEG
    OR AM61X-XCODE = FC-PEND.
      PERFORM BLAETTERN_MDIDX.
    ELSE.
      MESSAGE I029 WITH AM61X-XCODE.
    ENDIF.
  ENDCASE.
ENDFORM.
