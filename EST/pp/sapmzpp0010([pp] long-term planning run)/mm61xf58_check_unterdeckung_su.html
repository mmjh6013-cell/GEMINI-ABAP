Program listing for: MM61XF58_CHECK_UNTERDECKUNG_SU 
*----------------------------------------------------------------------*
* Unterdeckung ueberpruefen
*----------------------------------------------------------------------*


FORM check_unterdeckung_su.
*--> Return-Code vorbesetzen
  MOVE char1 TO am61x-rcode.
*--> Extrakt zuruecksetzen
  CLEAR exezx.
*--> TC-Zeile ermitteln (Cursor im Subscreen)
*  GET CURSOR LINE AM61X-BLINE.
  MOVE mdcursor-line TO am61x-bline.               "HW 153219
  IF  am61x-bline EQ 0.
    EXIT.
  ENDIF.
*--> Zeilenindex für die Tabelle MDSUX ermitteln
  am61x-aline = mdsux-xline + am61x-bline - 1.
  IF  am61x-aline GT mdsux-mline.
    EXIT.
  ENDIF.
*--> Tabelleneintrag aus MDSUX nachlesen
  READ TABLE mdsux INDEX am61x-aline.
  IF sy-subrc NE 0.
    MESSAGE e190 WITH am61x-aline 'MDSUX'.
  ENDIF.
*--> Daten fuer Bestellvorschlag ermitteln
  MOVE mdsux-plaab TO exezx-plaab.
  MOVE mdsux-planr TO exezx-planr.
  MOVE mdsux-dat00 TO exezx-dat00.
  IF mdsux-mng04 LT 0.
    MOVE mdsux-mng04 TO exezx-mng01.
  ENDIF.
*--> Unterdeckungstermin ermitteln
  LOOP AT mdezx FROM mdsux-aline TO mdsux-eline.
    IF mdezx-mng02 LT 0.
      MOVE mdezx-dat00 TO exezx-dat00.
      EXIT.
    ENDIF.
  ENDLOOP.
*--> Setzen Return-Code
  MOVE char0 TO am61x-rcode.
ENDFORM.
