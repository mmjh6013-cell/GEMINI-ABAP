FORM BEARBEITEN_MDPMX_MPBA USING CAMOD.
*--> Schnittstellendaten fuellen
  MOVE CAMOD       TO CM61Q-CAMOD.
  MOVE CM61W-FABKL TO CM61Q-FABKL.
  MOVE SPACE       TO CM61Q-AENKZ.
  MOVE SPACE       TO CM61Q-RCODE.
  MOVE BESKZF      TO CM61Q-BESKZ.
  MOVE HERKTM      TO CM61Q-HERKT.
*--> Komponenten Bearbeitung / Erfassung aufrufen
  CALL FUNCTION 'MD_BEARBEITEN_MPBA'
       EXPORTING ECM61Q = CM61Q
                 EMPBA  = MPBA
                 EMATNR = MT61D-MATNR
                 EWERKS = MT61D-WERKS
                 EMAKTX = MT61D-MAKTX
                 ECM61M = CM61M
       IMPORTING ICM61Q = CM61Q
                 IMPBA  = MPBA
       TABLES    MDPMX  = MDPMX
                 MDPML  = MDPML.
*--> Aenderungkennzeichen ueberpruefen
       IF CM61Q-AENKZ NE SPACE.
         MOVE XFLAG TO AM61X-AENAL.
         MOVE XFLAG TO MPBA-FIX01.
       ENDIF.
ENDFORM.
