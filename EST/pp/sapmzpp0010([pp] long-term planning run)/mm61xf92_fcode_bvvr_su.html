Program listing for: MM61XF92_FCODE_BVVR_SU 
*----------------------------------------------------------------------*
* FCODE: Bestellvorschlag im Summenuebersichtsbild veraendern
*----------------------------------------------------------------------*


FORM FCODE_BVVR_SU.

*--> Loeschen Formatbyte alt MDSU
  LOOP AT MDSUX WHERE FBYTE = CHAR2.
    MOVE SPACE TO MDSUX-FBYTE.
    MODIFY MDSUX.
  ENDLOOP.

*--> Bestellvorschlag ermitteln
  PERFORM PICK_UP_SU.
  IF AM61X-RCODE NE CHAR0.
    EXIT.
  ENDIF.
*--> Setzen Verarbeitungssatus
  MOVE VSTATV      TO AM61X-VSTAT.
  MOVE MDEZX-DELKZ TO AM61X-DELKZ.
*--> Bestellvorschlag in Ausgabestruktur uebernehmen
  PERFORM PUT_MDPSX_MPSVIEW.
*--> Summenanzeige neu positionieren
  MDSUX-XLINE = MDSUS-XLINE - 1.
  IF MDSUX-XLINE LT 1.
    MDSUX-XLINE = 1.
  ENDIF.
  MOVE MDSUX-XLINE TO TC_PS-TOP_LINE.

*--> MDEZ vorbereiten
  PERFORM MDEZ_VORBEREITEN_VR USING MDEZS-XLINE.

*--> Setzen Aenderungsscreen
  MDST-ANZEI = PSSI_ACTIV.
  SET SCREEN '0730'. LEAVE SCREEN.
ENDFORM.
