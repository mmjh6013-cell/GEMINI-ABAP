 PROCESS
 This interface is only used internally by SAP, and is used for making
 industry-specific or country-specific substitutions. These substitutions
 are then supplied to IBU customers or delivered as country versions.
 Interface 00001120 makes it possible to make a general substitution.
 This process is always reached when all the final checks have been
 completed before a document is updated. However, at this stage, the
 document number has not yet been assigned.
 
 INTERFACE
 The current document headers (there will be more than one for
 cross-company code transactions, for example) and corresponding line
 items are transferred to the additional component, for information
 purposes only. You must not edit this data. Instead, two additional
 tables (T_BKPFSUB and T_BSEGSUB) are also transferred. The contents of
 the fields that can be substituted are entered in these tables. Field
 TABIX contains a line number which shows from which line in T_BSEG or
 T_BKPF the field contents originate.
 Note: There is no additional check after the substitution. You must not
 overwrite an existing payment lock, for example, due to a workflow
 definition.
EXAMPLE 
 In the second line of table T_BSEG, the field contents from XREF3 (item
 text) should be replaced by the tax code 'T1'. This basically requires a
 statement sequence in the form
 
 READ TABLE T_BSEGSUB WITH KEY TABIX = 2.
 T_BSEGSUB-XREF3 = 'T1'.
 MODIFY T_BSEGSUB INDEX SY-TABIX.
 
 You must code this statement sequence in your own function module.
